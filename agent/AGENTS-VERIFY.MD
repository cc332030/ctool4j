
# 验证规范

以下规范适用于编译/运行验证、多步骤任务的分步验证等验证活动。

## 编译验证

- 编译验证：编译/运行验证耗时较长，不滥运行——仅当确需验证（用户明确要求，或存在仅能靠运行确认的行为）时才执行；多个待验证项能合并时合并为一次执行，不逐项独立验证；运行命令时优先将完整输出重定向到文件（如 `mvn ... > build.log 2>&1`），避免终端/IDE 输出截断或命令中断后无法恢复而需重试；日志文件等临时产物写入 `tmp/` 文件夹（见 AGENTS.md「临时产物」条目）

## 分步验证

- 分步验证：设计、开发、写用例测试等多步骤任务，每个步骤执行完须对涉及的部分做一次隔离上下文的 code review，确保每步正确——前面方向错了，后面做再多也是无用功
