
# 任务与 git 规范

以下规范适用于任务临时产物管理、任务报告与 git 操作。

## 临时产物统一目录

- 临时产物统一目录：测试文件、脚本、文档等临时产物（进度记录、扫描中间结果、日志文件、临时规划文件、结果报告等）统一写入根目录 `tmp/` 文件夹（不存在则新建）；临时产物按任务类型、文件类型等维度（包括但不限于）在 `tmp/` 下分类建子文件夹存放，不得混在一起；不保留、不提交；持久文档不得引用临时产物及其中的内容（如问题编号、问题描述等；临时产物会删除，其内容无出处可追溯）

## 任务报告

- 任务报告：大范围任务（全项目 code review、多模块改造等）完成后必须生成文件形式的结果报告（如 `tmp/check-result-*.md`），内容须含检查范围、问题清单（按分级编号规则）与处理状态；结果报告按"临时产物统一目录"条目处理（不保留、不提交）

## git 操作

- git 操作：新生成且需保留的文件，默认执行 git add 加入暂存区；文件移动必须使用 git mv（文件编辑+移动时须保留跟踪历史，避免 git 将移动识别为删除+新增）；git add/commit 前须检查暂存内容，确认无临时文件（`tmp/` 文件夹临时产物、扫描中间产物、构建产物等）被误提交；若发现临时文件已被提交，直接执行 git rm 删除，不得执行 git commit，由用户最终自行提交确认，不得因此中断任务
