
# 通用编码规范

以下规范适用于所有编程语言。

- 避免重复写相同代码：相同的代码逻辑抽离为公共方法，或移动到下游公共流程统一处理，不复制粘贴
- 警告在某些场景等同于报错：虽然不影响编译甚至不影响运行，但特定场景下与报错无异，必须像解决报错一样解决警告
- DSL 链式调用（builder、配置器等连续 `.xxx(...)` 设置值的写法，不限于 Java，如 Lombok @Builder、Python 方法链、JS 配置链等）中，设置值处只传简单值或已算好的局部变量，不在链式调用处内联复杂逻辑（如三元表达式、方法调用嵌套）；复杂计算先提取为局部变量或私有方法。识别特征：同一表达式内连续换行的 `.method(...)` 链、以 builder/configure 等命名或以返回自身（return this）为特征的构造器方法
- 三元表达式（三段式）只用于简单判断（如单个 null 兜底）；复杂逻辑（嵌套三元、多分支、含长方法调用）改用 if-else，可读性优先于行数
- bean/model/pojo 等纯数据结构类中不写逻辑：仅保留字段与简单的字段读写，不做计算、组装、格式转换、对外部对象（如工具类、请求对象）的访问；需要时下沉到工具类或独立服务。识别特征：以 bean/model/pojo/dto/vo/entity 等结尾的类、或仅使用 @Data 等访问器注解的类，其方法中出现非字段读写的计算/转换/组装逻辑
