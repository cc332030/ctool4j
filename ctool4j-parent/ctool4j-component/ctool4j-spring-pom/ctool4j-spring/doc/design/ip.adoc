= IP 处理 设计文档

模块：ctool4j-spring
状态：已落地
适用范围：IP/IP 段(CIDR)公共解析工具

== 5. 已知缺陷与不足 / 注意事项

按类→方法/字段分层记录，便于定位到代码。

=== 5.1 方法级

- `contains(String ip, String... rules)` / `contains(String ip, Collection<String> rules)`：
  - **易误用**：IPv6 地址或规则会**静默返回 `false`**（无异常）。若调用方意图支持 IPv6，会把"不支持"误判为"不在白名单内"；当前阶段仅在 IPv4 场景使用，勿用本方法判断 IPv6。
  - **易误用**：`rules` 为 `null` 或空集合返回 `false`（空名单=不放行，而非"全放行"）。"白名单为空=全放行"的语义由上层 `CInnerApiConfig`/`CInnerApiInterceptor` 决定，本工具不隐含该策略，调用方需自行决定空名单语义。
  - 返回值即"命中与否"，不区分"IP 非法"与"未命中"，调用方如需区分请自行预校验。
- `match`/`matchCidr`（私有）：对非法规则（含 IPv6 规则、掩码位越界）记录日志并跳过，不中断对其它规则的判断——单个坏配置不致整体失效，但**静默跳过**可能掩盖配置错误，生产建议先对配置规则做合法性校验。

=== 5.2 边界与默认值

- 非法 IP 哨兵值 `INVALID_IP = -1L`：IPv4 最大 `0xFFFFFFFF` 恒小于 `-1`（long），不会与合法值冲突，作为"非法/IPv6"标记安全。
- `maskBit` 范围 [0,32]：hutool `isMaskBitValid` 视 0 为非法，故 `maskBit=0`（`/0`）由本类特判为全量放行（命中所有合法 IPv4）；超出 0~32 的掩码位判为非法规则并跳过。
- IP/规则解析复用 hutool 带默认值 `ipv4ToLong(String, long)`，格式非法返回哨兵，不抛异常。

=== 5.3 性能

- 每次调用即时解析（`Ipv4Util.getBeginIpStr`/`getEndIpStr` 逐条规则计算区间），未做结果缓存。白名单规模很小、调用频次低，开销可忽略；若做高频超大规则集匹配需考虑缓存。

=== 5.4 线程安全与副作用

- `@UtilityClass` 无状态静态方法，线程安全；不持有可变共享状态，无并发问题。
- 每次调用内部解析，无副作用，可重复调用。

=== 5.5 波及影响

- 本工具被 `CInnerApiInterceptor` 用于内部接口 IP 白名单校验：若将来其行为变化（如 IPv6 支持、空名单语义调整），需同步评估对 IP 白名单拦截语义的影响。
