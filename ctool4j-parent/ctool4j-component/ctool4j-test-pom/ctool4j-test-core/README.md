# ctool4j-test-core

> 测试支撑（部分占位）：核心测试辅助能力。

## 简介

`ctool4j-test-core` 规划承载与 Spring 无关的测试辅助（断言扩展、测试数据构造等），
复用 `ctool4j-test-definition` 的测试模型。**当前能力部分占位**。

## 依赖

| 依赖 | 作用域 | 说明 |
|------|--------|------|
| `ctool4j-core` | compile | 核心工具库 |
| `ctool4j-test-definition` | compile | 共享测试模型 |
