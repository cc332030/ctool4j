= 变更日志

本文件为 ctool4j 项目的统一变更日志，按时间**倒序**记录（最新在最上方）。版本号在各源文件的 javadoc `@version` 中维护。

**登记时机：仅在用户明确要求时追加条目**——日常改动不写本文件，不要因"改了代码"顺手补一行。改动意图见各源文件 javadoc 与 `doc/design/`；逐条沿革用 `git log` 回溯。条目格式：`- <项目版本前缀> | <YYYY-MM-DD> | <描述>`（单行）。

- 1.1 | 2026-09-18 | 破坏性变更：`CBeanUtils.copy` 系列集合/Map/数组/Bean/Date 字段由"跳过/共享"改为**深拷贝**（元素与键值递归、环状与跨字段共享引用只拷一份），需要共享引用的调用方改用 `toMap` 或在复制后自行恢复；跨接口容器（源 List → 目标 Set 声明等）按"跳过不写入"处理（此前会先拷贝再写、以 `ClassCastException` 被吞成"字段写入失败"而静默丢字段）
- 1.1 | 2026-09-16 | ctool4j-doc-openapi2：`CEmptyTagBeanPostProcessor` 在 `paths` 为空时不再清理分组声明（无接口信息无法判定引用关系，避免误删业务用 `Docket.tags(...)` 声明的占位分组；类文档兜底表口径已对齐，用例随动）
- 1.1 | 2026-09-16 | ctool4j-doc-openapi2 整理与加固：新增 `CModelPropertyAnnotationUtils`（收敛 model 属性注解查找：annotatedElement 优先、其次 beanPropertyDefinition），合并 `CSchemaAnnotationModelPropertyPlugin` 与 `CTextEnumModelPropertyPlugin` 两份写法不一致的私有实现；`ICAnnotationExpandedParameterBuilderPlugin#isRequired` 由裸 `Annotation` 改为泛型 `T`；三个插件的私有 `hasText`（3 份重复）统一改用 `CValidUtils#isValid`；`CEmptyTagBeanPostProcessor` 补双层异常兜底（代理创建失败回退原 Bean、清理失败仅 warn 后保留原模型），两者均不再可能阻断启动或文档接口，日志降为 debug 并补"knife4j 关文档时无 Bean 匹配、零副作用"的兜底说明；修正 `CDocOpenApi2Config` 文档键名（`c-doc.openapi2` → `doc.openapi2`）与 `CSpringFoxUtils` 空缺的能力目录
- 1.1 | 2026-09-16 | ctool4j-doc-openapi2 修复 swagger "英文空分组"：经查 springfox 的分组名由控制器类名硬编码（`WebMvcRequestHandler#groupName()` → `ControllerNamingUtils.controllerNameAsGroup(handlerMethod)`，类名 splitCamelCase 转 kebab 小写），**不经过 `ResourceGroupingStrategy`**，注解与插件都改不了——故此前新增的 `CTagGroupingStrategy` 方案无效（类与 bean 注册一并删除），接口 tag（`@CTag` 中文）与分组名（英文类名）不一致时会多出无接口引用的空分组；改为新增 `CEmptyTagBeanPostProcessor`：包装容器 bean `ServiceModelToSwagger2Mapper`（MapStruct 生成的抽象类，走 CGLIB 代理），在 `mapDocumentation` 之后清除"无任何接口引用"的分组声明，只删空分组、接口与其 tag 一律不动（`CEmptyTagBeanPostProcessor` 新增，`COpenApi2Configuration` 注册 `cEmptyTagBeanPostProcessor`）；集成用例 3.1 改为断言不残留空分组（`tags_noUnreferencedTag`），配套删除 `CTagGroupingStrategyTests`
