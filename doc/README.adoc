= 项目文档导航

本文件是 ctool4j 的**全项目文档导航入口**（文档目录树即站点导航），逐级指向各模块与功能文档的固定落点。

== 文档分层（先看这里）

* *javadoc 即文档，且按层次分工*：源类**类上写总结**（定位、能力目录、设计思路总述）；**方法上写详细设计与详细步骤**
  （流程步骤、参数/返回值/异常契约、边界与默认值、兜底、易误用点）。测试类**类上写总结**（测试设计思路与依据、覆盖与未覆盖、
  用例总览/分类/编码与逐个用例精简总结）；**测试方法上写详细设计**（引用用例编码、测试意图、测试范围、测试意义、断言取舍）。
* *模块级说明（模块职责、能力清单、核心类）只在模块 README*：各模块目录下的 +README.md+，由根 link:../README.adoc[README] 的模块文档索引汇总。
* *功能级文档（跨类设计）只在 +doc/design/<模块>/+*：方案取舍、兜底策略、适用范围、已知限制与波及影响，按功能命名、不与源文件同名。
* *依赖关系唯一视图*：模块间依赖只写 link:dependency.adoc[dependency.adoc]。
* *不重复内容*：同一事实只有一个落点，其余位置以链接指回；模块 `doc/` 下不再另设索引页（导航以本文件为树根）。

== 约定

* *字段说明*：如无特别说明，文档中的模块名即 Maven 模块目录名（+ctool4j-xxx+）。
* *依赖落点*：模块间增删依赖须在同一提交内同步更新 link:dependency.adoc[dependency.adoc]。
* *版本与变更*：源文件版本在各源码 javadoc 的 +@version+ 中维护；全项目变更记录统一在 link:../CHANGELOG.adoc[CHANGELOG.adoc]。
