== 文档组织约定

* *javadoc 即文档，且按层次分工*：源类**类上写总结**（定位、能力目录、设计思路总述）；**方法上写详细设计与详细步骤**
  （流程步骤、参数/返回值/异常契约、边界与默认值、兜底、易误用点）。测试类**类上写总结**（测试设计思路与依据、覆盖与未覆盖、
  用例总览/分类/编码与逐个用例精简总结）；**测试方法上写详细设计**（引用用例编码、测试意图、测试范围、测试意义、断言取舍）。
* *只放总结与规划性文档*：本目录及其子目录只保留总结性/规划性 adoc 与各级索引页（README），
  不出现逐类文档、逐用例文档；类级/方法级内容一律由源码 javadoc 承载。
* *独立文档承载功能/模块级内容*：跨类/模块的设计（方案取舍、兜底策略、适用范围、已知限制与波及影响）按功能命名成篇，
  存放于 +doc/design/<模块>/+；文档目录树即站点导航，每级目录均有索引页。
* *双向引用*：源码 javadoc 以功能/模块级文档的模块根相对路径引用其设计文档；文档以「对应类/源码文件」链接回指代码。
* *版本与变更*：源文件版本在各源码 javadoc 的 +@version+ 中维护；全项目变更记录统一在 link:../CHANGELOG.adoc[CHANGELOG.adoc]（时间倒序）。
* *模块 README*：各模块使用说明见模块目录下的 +README.md+，根索引见 link:../README.adoc[README]。
