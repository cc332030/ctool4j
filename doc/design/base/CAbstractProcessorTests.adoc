== 用例设计思路与依据

=== 设计思路

- 通过子类 TestProcessor 验证基类约定的支持源版本、注解类型、process 与 init 的默认行为。

=== 设计依据

- 依据功能设计对 Java 8 源版本支持、process/init 约定行为的约定。

=== 覆盖场景与未覆盖

- 覆盖：支持 Java 8；注解类型默认空；process 返回 false；init 不抛异常。
- 未覆盖：真实编译期注解处理流程。

== 1. 注解处理器基类行为

- 1.1 支持 Java 8 源版本（`supportedSourceVersion_RELEASE8`）
- 1.2 注解类型默认空（`supportedAnnotationTypes_empty`）
- 1.3 process 返回 false（`process_returnsFalse`）
- 1.4 init 不抛异常（`init_noException`）
