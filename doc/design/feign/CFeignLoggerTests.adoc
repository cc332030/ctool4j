== 用例设计思路与依据

=== 设计思路

- 按 CFeignLogger 的「请求生命周期」时序组织分类：logRequest（是否记录 + 请求模型构建）→ 响应模型构建 → 异常日志 → 降级返回，使分类与 feign 拦截请求到输出日志的流程顺序对应
- 请求阶段拆为两个维度：一是「记录与否」的开关与白名单/黑名单判定（决定是否产生日志），二是「请求模型构建」的字段填充（决定日志内容），避免把「是否记录」与「记录什么」混在一类
- 每个分类下给出正例/分支/边界，覆盖易错点（如空 body 占位、开关只作用打印层、响应重缓冲可再读）

=== 设计依据

- 依据 CFeignLogger 设计约定：请求头/响应头采集层总是采集、是否输出由打印层 enableHeader 开关控制（故需验证采集与打印解耦）；响应重缓冲后需可再次读取
- 依据需求对可读性与安全的要求：空请求/响应体输出 EMPTY_REQ/EMPTY_RSP 占位避免 `[null]`；白名单优先于黑名单
- 依据测试方法（分支/边界覆盖）：白名单/黑名单/全量各分支、开关关闭的采集分支、响应状态码/响应头的采集

=== 覆盖场景与未覆盖

- 覆盖：白名单/黑名单/全量判定、path/query、请求体文本/非文本/空、请求头采集（开启/关闭）、响应重缓冲与再读、响应状态码/响应头采集、异常 errorMessage、降级返回
- 未覆盖：`toHandleSpecial`（当前无调用方，不作问题提示，暂无用例）

=== 已知取舍

- 请求头/响应头采集层总是采集、是否输出由打印层 enableHeader 开关控制（采集与打印解耦）
- feign 的 `Response.headers()` 统一为小写 header 名（HTTP 头不区分大小写）、值为 Collection 实现，采集直接引用不做转换

== 1. logRequest 开关与白名单/黑名单判定

=== 1.1 名单命中判定
- 1.1.1 host 白名单命中时记录（testLogRequestHostWhiteListHit）
- 1.1.2 path 白名单命中时记录（testLogRequestPathWhiteListHit）
- 1.1.3 api 白名单命中时记录（testLogRequestApiWhiteListHit）
- 1.1.4 白名单优先于黑名单（同时命中时记录）（testLogRequestWhiteListWinsOverBlackList）
- 1.1.5 无任何名单且 logAll=true 时记录（testLogRequestNoListLogAllTrue）
- 1.1.6 黑名单命中且未命中白名单时不记录（testLogRequestHostBlackListHit）
- 1.1.7 无任何名单且 logAll=false 时不记录（testLogRequestNoListLogAllFalse）

== 2. 请求日志模型构建（setRequestLog）

=== 2.1 path 与 query
- 2.1.1 path 含 query 时 path 与 query 分别记录
- 2.1.2 path 无 query 时仅记录 path

=== 2.2 请求体
- 2.2.1 文本 body 按 charset 解码存入 req
- 2.2.2 非文本 body 输出占位符
- 2.2.3 空 body 输出 EMPTY_REQ 占位（避免 [null]）

=== 2.3 请求头
- 2.3.1 enableHeader 开启时深拷贝请求头存储（不可变）
- 2.3.2 enableHeader 关闭时请求头仍总是被采集存储，开关仅作用于打印层（testSetRequestLogHeadersAlwaysCollectedEvenDisabled）

== 3. 响应日志模型构建（logAndRebufferResponse）

=== 3.1 响应体与重缓冲
- 3.1.1 重缓冲响应体后可再次读取，rsp 存响应体文本

=== 3.2 空响应体占位
- 3.2.1 空响应体输出 EMPTY_RSP 占位

=== 3.3 响应状态码与响应头
- 3.3.1 采集响应状态码与响应头（responseStatus/responseHeaders）供响应报文头输出

== 4. 异常日志（logIOException）

- 4.1.1 异常时记录 errorMessage

== 5. 未记录时的降级返回

- 5.1.1 未开启时响应/异常走降级返回，不抛异常（testLogRequestDisabledDoesNothing/testLogAndRebufferResponseNoRequestLogReturnsSame/testLogIOExceptionNoRequestLogReturnsSame）
