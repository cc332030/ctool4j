= CFeignConfiguration 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-feign
类：com.c332030.ctool4j.feign.configuration.CFeignConfiguration
状态：已落地
适用范围：Feign 相关 Bean 配置类

== 1. 功能说明

`CFeignConfiguration`（`@Configuration`）注册 Feign 相关 Bean：

- `cFeignInterceptor()`：`CFeignInterceptor`（请求拦截器）。
- `cFeignClient(client, feignLogConfig)`：`CFeignClient`（带日志客户端，当前注释未启用）。
- `cFeignLoggerLevel()`：`Logger.Level.FULL`（`@ConditionalOnMissingBean`）。
- `cFeignLogger(feignLogConfig)`：`CFeignLogger` 日志实现（`@ConditionalOnMissingBean`）。

== 2. 设计要点

- 拦截器默认注册；日志级别/日志实现按缺省注册（`@ConditionalOnMissingBean` 可被覆盖）。
- `cFeignClient` 方法当前被注释，未注册为 Bean。

== 3. 兜底设计

- 日志级别/日志实现缺失时由本配置提供默认 FULL 级别与 CFeignLogger。

== 4. 适用范围

=== 4.1 适用场景
- 引入 ctool4j-feign 时自动装配拦截器与日志。

=== 4.2 不适用/边界场景
- 用户自定义 Logger/Level 时以用户 Bean 优先（ConditionalOnMissingBean）。

== 5. 已知限制与取舍

- `cFeignClient` 未启用，日志客户端需自行装配；响应日志能力通过 CFeignLogger 提供。
