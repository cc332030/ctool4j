状态：已落地
适用范围：Feign 全局配置（@ConfigurationProperties）

== 1. 功能说明

`CFeignConfig`（`@ConfigurationProperties(value="feign", ignoreInvalidFields=true)`）为 Feign 全局配置：

- `client`：`Map<String, ClientConfig>`，客户端信息（key 为客户端名，value 含 `url` 地址）。

内部 `ClientConfig` 为客户端配置，含 `url` 字段。

== 2. 设计要点

- 前缀 `feign`，忽略格式不一致字段。
- `client` 默认 `CMap.of()`（空不可变 Map）。

== 3. 兜底设计

- 未配置时为空 client Map。

== 4. 适用范围

=== 4.1 适用场景
- 配置多 Feign 客户端地址（按名）。

=== 4.2 不适用/边界场景
- 仅配置载体；具体客户端装配由 Spring 完成。

== 5. 已知限制与取舍

- 仅解析 `url` 字段，其他客户端配置不在此承载。
