适用范围：为指定 Feign 接口绑定自定义请求拦截器

== 1. 功能说明

`CCustomerFeignInterceptor` 为类型级注解，标注在 Feign 接口上，指定该接口使用的
自定义请求拦截器实现类（`value()` 返回 `Class<? extends ICRequestInterceptor>`）。

== 2. 设计要点

- 仅作用于类型（`@Target(TYPE)`）、运行时保留、可继承。
- 通过 `value()` 声明拦截器实现类，供 `CFeignUtils.addInterceptor` 按接口类型注册。

== 3. 兜底设计

- 无（注解本身无逻辑；未标注的接口使用全局拦截器）。

== 4. 适用范围

=== 4.1 适用场景
- 需要为特定 Feign 接口定制请求拦截（加签、透传特殊 header）。

=== 4.2 不适用/边界场景
- 仅声明拦截器类；实例装配由调用方/配置完成。

== 5. 已知限制与取舍

- 每接口单一拦截器；多拦截器需自行组合。
