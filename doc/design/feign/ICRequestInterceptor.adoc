适用范围：Feign 请求拦截器函数式接口

== 1. 功能说明

`ICRequestInterceptor`（`@FunctionalInterface`）扩展 feign `RequestInterceptor` 与 `CConsumer<RequestTemplate>`，
将 `apply(requestTemplate)` 委托给 `accept(requestTemplate)`。

== 2. 设计要点

- `apply` 默认实现委托给 `CConsumer.accept`，支持函数式写法（lambda 直接实现 accept）。

== 3. 兜底设计

- 无（接口默认委托，实现方实现 accept）。

== 4. 适用范围

- 自定义 Feign 请求拦截器（配合 `@CCustomerFeignInterceptor`）。

== 5. 已知限制与取舍

- 仅委托；不提供默认拦截逻辑。
