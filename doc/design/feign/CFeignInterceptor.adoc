== 1. 功能说明

`CFeignInterceptor` 实现 feign `RequestInterceptor`，拦截请求：命中拦截规则时跳过，否则透传请求头。

- `apply(template)`：命中 `CFeignUtils.intercept` 则跳过；否则 `CFeignUtils.transferHeaders` 透传请求头。

== 2. 设计要点

- 委托 `CFeignUtils` 完成拦截判断与请求头透传。
- 拦截/透传异常记录 error 日志，不向上抛出（避免影响请求执行）。

== 3. 兜底设计

- 拦截处理异常时记录日志，不中断请求（透传失败则请求不携带额外 header，但主流程继续）。

== 4. 适用范围

- Feign 全局请求拦截与 header 透传。

== 5. 已知限制与取舍

- 异常静默（仅日志），若透传 header 是业务必需，失败可能影响下游，调用方需注意。
