== 1. 功能说明

`CFeignClientHeaderPropagationModeEnum` 定义 Feign 请求头传播模式：

- `ALL`（"全部"）、`CUSTOM`（"自定义"）、`NONE`（"无"）。

== 2. 设计要点

- 三个模式枚举，`text` 为中文描述；lombok `@Getter`/`@AllArgsConstructor` 生成。

== 3. 兜底设计

- 无。

== 4. 适用范围

- 配置 `CFeignClientHeaderConfig.propagationMode` 决定请求头传播策略。

== 5. 已知限制与取舍

- 模式固定三种，扩展需修改枚举。

测试内容见 `doc/design/feign/CFeignClientHeaderPropagationModeEnumTests.adoc`。
