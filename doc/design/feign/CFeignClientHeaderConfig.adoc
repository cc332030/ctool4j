适用范围：Feign 请求头传播配置（@ConfigurationProperties）

== 1. 功能说明

`CFeignClientHeaderConfig`（`@ConfigurationProperties("feign.client.header")`）为 Feign 请求头传播配置：

- `propagationMode`：传播模式，默认 `ALL`。
- `propagationCustomHeaders`：自定义传播 headers。
- `propagationRequestHeaders`：传播的 request headers。

== 2. 设计要点

- 前缀 `feign.client.header`，供配置文件绑定。
- 集合默认 `CSet.of()`（空不可变集合）。

== 3. 兜底设计

- 未配置时用默认值（ALL 模式 + 空集合）。

== 4. 适用范围

- 配置 Feign 请求头传播模式与自定义 headers（供 `CFeignUtils.transferHeaders` 使用）。

== 5. 已知限制与取舍

- 集合默认不可变，动态修改需重新 set。
