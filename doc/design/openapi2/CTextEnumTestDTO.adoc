== 1. 功能说明

`CTextEnumTestDTO` 为枚举 text 展示集成测试辅助 DTO，含实现 `ICText` 的枚举字段（类型 `CRequestHeaderEnum`）：

- `header`：未标注 @CSchema，验证允许值保持可提交「枚举名」、description 展示「枚举名(text)」。
- `headerWithSchema`：标注 `@CSchema("带描述枚举头")`，验证自定义描述不被 text 说明覆盖。
