== 1. 功能说明

`CNotEmptyAnnotationPlugin` 实现 `ICAnnotationExpandedParameterBuilderPlugin<NotEmpty>`，识别 `@NotEmpty` 注解，命中时将参数标记为必填（`isRequired` 默认 true）。

== 2. 设计要点

=== 2.1 注解识别

- `getAnnotationClass()` 返回 `NotEmpty.class`。
- 通过 `ICAnnotationExpandedParameterBuilderPlugin` 的默认 `apply` 逻辑：命中注解且 `isRequired` 为 true 时标记必填。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未命中 @NotEmpty | 不标记必填 |
| supports 任意文档类型/null | 均返回 true |

== 4. 适用范围

=== 4.1 适用场景

- springfox 文档生成时将 `@NotEmpty` 参数标记为必填。

== 5. 已知限制与取舍

- 仅处理 `@NotEmpty`，其他校验注解由对应插件处理。

测试内容见 `doc/design/openapi2/CNotEmptyAnnotationPluginTests.adoc`。
