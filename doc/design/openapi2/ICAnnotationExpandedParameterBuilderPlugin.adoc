== 1. 功能说明

`ICAnnotationExpandedParameterBuilderPlugin<T extends Annotation>`（extends `ICExpandedParameterBuilderPlugin`）提供基于校验注解的参数展开逻辑：

- `apply(context)`：命中目标注解且 `isRequired` 为 true 时标记参数必填。
- `isRequired(annotation)`：命中时是否必填（默认 true）。
- `getAnnotationClass()`：目标注解类型。

== 2. 设计要点

=== 2.1 apply 默认实现

- 从 context 查目标注解，命中且 `isRequired` 为 true 时 `context.getParameterBuilder().required(true)`。

=== 2.2 isRequired

- 默认 true：无 required 属性的注解（如 `@NotEmpty`）命中即必填。
- 子类可覆写读取注解的 required 属性（如 `@CSchema`）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未命中注解 | 不做处理 |
| isRequired 返回 false | 不标记必填 |

== 4. 适用范围

=== 4.1 适用场景

- 统一处理"校验注解 → 参数必填"的 springfox 插件逻辑。

== 5. 已知限制与取舍

- 默认 isRequired 恒 true，需按 required 属性区分的注解由子类覆写。

无测试类。
