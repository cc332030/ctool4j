== 1. 功能说明

`CParameterAnnotationPlugin` 实现 `ParameterBuilderPlugin`，识别方法参数上 `@CParameter` 注解，将
name/description/required/example 写入 springfox 的 operation 参数（替代原生 `@ApiParam`）。

== 2. 设计要点

=== 2.1 注解读取

- 用 `context.resolvedMethodParameter().findAnnotation(CParameter.class)` 取参数级注解。

=== 2.2 处理

- `@CParameter.value` 非空 → `parameterBuilder.description(...)`。
- name 非空 → `parameterBuilder.name(...)`。
- required=true → `parameterBuilder.required(true)`。
- example 非空 → `parameterBuilder.scalarExample(...)`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| name/description/example 为空 | 不覆盖 |
| required=false | 不标记必填 |
| 无 @CParameter | 不处理 |

== 4. 适用范围

=== 4.1 适用场景

- 用 `@CParameter` 标注方法参数后，springfox 文档展示参数名称/说明/必填/示例。

== 5. 已知限制与取舍

- 依赖 `@CParameter`（web 模块）注解定义。

测试内容见 `doc/design/openapi2/CParameterAnnotationPluginTests.adoc`。
