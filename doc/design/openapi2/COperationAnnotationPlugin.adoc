== 1. 功能说明

`COperationAnnotationPlugin` 实现 `OperationBuilderPlugin`，识别方法上 `@COperation` 注解，将
summary/description/deprecated 写入 springfox 的 operation（替代原生 `@ApiOperation`）。

== 2. 设计要点

=== 2.1 注解读取

- 用 `context.findAnnotation(COperation.class)` 取方法级注解。

=== 2.2 处理

- `@COperation.value` 非空 → `operationBuilder.summary(...)`。
- description 非空 → `operationBuilder.notes(...)`。
- deprecated=true → `operationBuilder.deprecated("true")`。
- 分组 tag 由类级 `CTagAnnotationPlugin` 统一处理，此处不处理 tags。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| summary/description 为空 | 不覆盖 |
| deprecated=false | 不标记废弃 |
| 无 @COperation | 不处理 |

== 4. 适用范围

=== 4.1 适用场景

- 用 `@COperation` 标注接口方法后，springfox 文档展示摘要/说明/废弃标记。

== 5. 已知限制与取舍

- springfox 为 operation 自动生成 id，`operationId` 不在此映射。
- 依赖 `@COperation`（web 模块）注解定义。

测试内容见 `doc/design/openapi2/COperationAnnotationPluginTests.adoc`。
