== 1. 功能说明

`ICExpandedParameterBuilderPlugin`（extends `ExpandedParameterBuilderPlugin`）为 springfox 参数展开插件的扩展接口，默认对所有文档类型都支持。

== 2. 设计要点

=== 2.1 supports

- 默认 `supports(DocumentationType)` 恒返回 true（全部支持，含 null）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 任意文档类型/null | 默认支持 |

== 4. 适用范围

=== 4.1 适用场景

- 作为项目内 springfox 参数展开插件的统一父接口。

== 5. 已知限制与取舍

- 默认全支持，需要特定类型才支持时由子类覆写。
