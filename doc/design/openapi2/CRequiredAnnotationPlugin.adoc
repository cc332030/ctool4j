== 1. 功能说明

`CRequiredAnnotationPlugin` 实现 `ICAnnotationExpandedParameterBuilderPlugin<CRequired>`，识别 `@CRequired` 注解，
标注即必填（无 required 属性），将方法参数（展开）标记为必填。

== 2. 设计要点

=== 2.1 注解识别

- `getAnnotationClass()` 返回 `CRequired.class`。
- `isRequired` 走默认（恒 true）：`@CRequired` 标注即必填。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未命中 @CRequired | 不标记必填 |

== 4. 适用范围

=== 4.1 适用场景

- springfox 文档生成时按 `@CRequired` 标记方法参数（展开）必填。

== 5. 已知限制与取舍

- 依赖 `@CRequired`（web 模块）注解定义。
