== 1. 功能说明

`CDocOpenApi2Config`（`@Data` + `@ConfigurationProperties("c-doc.openapi2")`）承载 OpenAPI2 文档相关配置：

- `pathMapping`：路径映射，一般用于 nginx 反向代理后 knife4j 检测不到路径的情况，默认 `"/"`。

== 2. 设计要点

=== 2.1 pathMapping

- 默认值为 `"/"`。
- 可通过配置文件 `c-doc.openapi2.pathMapping` 覆盖。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| pathMapping 未配置 | 默认 `"/"` |
| pathMapping 显式置 null | 保持 null（由调用方处理） |

== 4. 适用范围

=== 4.1 适用场景

- 反向代理场景下 OpenAPI2 文档的路径映射配置。

== 5. 已知限制与取舍

- 仅承载单一路径映射属性，未做额外校验。

测试内容见 `doc/design/openapi2/CDocOpenApi2ConfigTests.adoc`。
