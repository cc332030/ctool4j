适用范围：实现 ICText 的枚举请求参数 → 允许值保持可提交「枚举名」，text 说明进参数描述

== 1. 功能说明

`CTextEnumParameterPlugin` 实现 `ParameterBuilderPlugin`：对请求参数类型为实现 `ICText` 的枚举，
允许值保持可提交的「枚举名」（如 AUTHORIZATION），并将可读的「枚举名(text)」（如 AUTHORIZATION(鉴权)）
写入参数描述（description），使接口文档枚举值可读。

== 2. 设计要点

=== 2.1 处理时机

- 经 `context.resolvedMethodParameter().getParameterType().getErasedType()` 获取参数类型。
- 由 `CTextEnumUtils.enumAllowableValues` 生成可提交允许值并覆写 parameterBuilder.allowableValues；
  由 `CTextEnumUtils.textEnumDescription` 生成可读说明写入 description。

=== 2.2 描述防覆盖

- 若参数已标注 `@CParameter` 且 `value` 非空（提供自定义说明），则不写入 text 说明，避免覆盖既有描述。

=== 2.3 影响范围

- 仅影响参数文档展示（query/header 等枚举参数）；非 ICText 枚举 / 非枚举参数不受影响。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 非 ICText 枚举 | 不覆写（保持 springfox 默认「枚举名」列表） |
| enumAllowableValues 返回 null | 不覆写 |
| 已标 @CParameter(value) 自定义描述 | 不写 text 说明（description 由 @CParameter 提供） |

== 4. 适用范围

=== 4.1 适用场景

- 接口请求参数为实现 ICText 的枚举，希望文档允许值可直接使用、text 说明可读。

== 5. 已知限制与取舍

- 允许值保持可提交的枚举名（与运行时一致）；text 可读性通过 description 提供，两者兼顾。

无独立测试类（集成测试 CTextEnumIntegrationTests 覆盖）。
