== 1. 功能说明

`CSchemaTestController` 为 `CRequired`/`CSchema` 集成测试辅助 Controller（`@RestController`，标注 `@CTag` 供 Docket 收集）：

- `test(@Valid @RequestBody CSchemaTestDTO dto)`：POST `/c-schema/test`，接收 `@CRequired` 标注的 DTO，`@Valid` 触发字段校验（username `@CRequired` 必填），标注 `@COperation` 供 springfox 生成接口文档

== 4. 适用范围

=== 4.1 适用场景

- `CSchemaIntegrationTests` 集成测试，作为真实接口入口验证 `@CRequired` 必填校验与字段文档生成。

== 5. 已知限制与取舍

- 测试辅助类；仅提供单个测试接口。
