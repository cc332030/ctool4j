适用范围：@CSchema/@CRequired → model 属性描述与必填

== 1. 功能说明

`CSchemaAnnotationModelPropertyPlugin` 实现 `ModelPropertyBuilderPlugin`，识别 model 字段/getter 上的
`@CSchema` 与 `@CRequired` 注解：

- `@CRequired` 标注（即必填）时标记属性必填。
- `@CSchema.value` 非空时写入字段描述（为空则保留已有描述）。
- 描述与必填解耦：`@CSchema` 只管描述、`@CRequired` 只管必填（替代 `@ApiModelProperty + @NotNull`）。

== 2. 设计要点

=== 2.1 注解查找

- 优先从 `context.getAnnotatedElement()` 取注解，其次从 `getBeanPropertyDefinition()` 查找。

=== 2.2 处理

- 命中 `@CRequired`：`required(true)`；兼容 `@Repeatable` 重复标注（多 groups 时注解存于容器
  `@CRequired.List`，同样命中必填）。
- `@CSchema.value` 有内容时 `description(value)`；为空时保留已有描述，避免空串覆盖。

=== 2.3 supports

- 默认支持全部文档类型（含 null）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未标 @CRequired | 不标记必填 |
| @CRequired 重复标注（@CRequired.List 容器） | 仍标记必填 |
| @CSchema.value 为空 | 不写描述（保留已有） |
| 均未标注 | 不处理 |

== 4. 适用范围

=== 4.1 适用场景

- springfox 文档生成时用 `@CSchema`（描述）+ `@CRequired`（必填）标注 model 属性。

== 5. 已知限制与取舍

- 依赖 `@CSchema`（doc-base 模块）与 `@CRequired`（web 模块）注解定义。

测试内容见 `doc/design/openapi2/CSchemaAnnotationModelPropertyPluginTests.adoc`。
