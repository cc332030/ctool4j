== 用例设计思路与依据

=== 设计思路

- 启动真实 Spring 容器（@CTool4jSpringBootTest + @AutoConfigureMockMvc），经 /v2/api-docs 获取文档 JSON
  （response 用 UTF-8 读取，避免 springfox 中文字符按默认编码解码乱码），断言枚举值显示为「枚举名(text)」。
- 测试枚举用 web 模块的 `CRequestHeaderEnum`（实现 ICText：AUTHORIZATION(鉴权) 等）。
- 覆盖 model 字段枚举与 query 参数枚举两条展示路径。

=== 覆盖场景与未覆盖

- 覆盖：model 字段枚举含 AUTHORIZATION(鉴权)、不含裸枚举名；所有枚举值均为「枚举名(text)」形态且数量与常量一致；
  query 参数枚举含 AUTHORIZATION(鉴权)。
- 未覆盖：非 ICText 枚举保持默认（未断言）；运行时绑定不受影响。
