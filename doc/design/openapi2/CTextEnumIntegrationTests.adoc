== 用例设计思路与依据

=== 设计思路

- 启动真实 Spring 容器（@CTool4jSpringBootTest + @AutoConfigureMockMvc），经 /v2/api-docs 获取文档 JSON
  （response 用 UTF-8 读取，避免 springfox 中文字符按默认编码解码乱码），断言枚举允许值保持可提交的
  「枚举名」，可读「枚举名(text)」在 description 中展示。
- 测试枚举用 web 模块的 `CRequestHeaderEnum`（实现 ICText：AUTHORIZATION(鉴权) 等）。
- 覆盖 model 字段枚举与 query 参数枚举两条展示路径。

=== 覆盖场景与未覆盖

- 覆盖：model 字段枚举允许值含 AUTHORIZATION（可提交）、不含 text 形式；description 含 AUTHORIZATION(鉴权)；
  query 参数枚举允许值含 AUTHORIZATION、description 含 AUTHORIZATION(鉴权)；
  已标注 @CSchema 自定义描述的属性（headerWithSchema）description 不被 text 说明覆盖。
- 未覆盖：非 ICText 枚举保持默认（未断言）；运行时绑定不受影响（允许值即枚举名，可直接使用）。

== 1. model 字段枚举

- 1.1 允许值保持可提交枚举名（modelFieldEnum_keepCallableValue）
- 1.2 description 展示「枚举名(text)」（modelFieldEnum_showsTextInDescription）
- 1.3 允许值全为裸枚举名、数量一致且 description 含 text 说明（modelFieldEnum_allValuesCallableAndTextual）
- 1.4 @CSchema 自定义描述不被 text 覆盖（modelFieldEnum_keepCSchemaDescription）

== 2. query 参数枚举

- 2.1 允许值可提交、description 展示 text（queryParamEnum_callableValueAndTextDescription）
