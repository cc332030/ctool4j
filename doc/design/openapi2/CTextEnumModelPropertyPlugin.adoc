适用范围：实现 ICText 的枚举 model 属性 → 枚举值显示「枚举名(text)」

== 1. 功能说明

`CTextEnumModelPropertyPlugin` 实现 `ModelPropertyBuilderPlugin`：对 model 字段类型为实现 `ICText` 的枚举，
将允许值列表由「枚举名」改为「枚举名(text)」（如 AUTHORIZATION(鉴权)），使接口文档枚举值可读。

== 2. 设计要点

=== 2.1 处理时机

- 经 `context.getBeanPropertyDefinition().getRawPrimaryType()` 获取字段类型。
- 由 `CTextEnumUtils.textEnumAllowableValues` 生成新允许值并覆写 builder.allowableValues。

=== 2.2 影响范围

- 仅影响 model 属性文档展示；非 ICText 枚举 / 非枚举属性不受影响。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 非 ICText 枚举 | 不覆写（保持 springfox 默认「枚举名」列表） |
| textEnumAllowableValues 返回 null | 不覆写 |

== 4. 适用范围

=== 4.1 适用场景

- 接口文档 model 字段为实现 ICText 的枚举，希望枚举值带可读文本。

== 5. 已知限制与取舍

- 仅改文档展示（allowableValues），不影响运行时传值（仍用枚举名）。

无独立测试类（集成测试 CTextEnumIntegrationTests 覆盖）。
