== 1. 功能说明

`CTextEnumUtils` 提供枚举 text 展示工具，供 model 属性与参数枚举文档展示复用：

- `isTextEnum(Class)`：判断类型是否为枚举且实现了 `ICText`。
- `enumAllowableValues(Class)`：生成「枚举名」的 `AllowableListValues`（如 AUTHORIZATION），值可提交、与运行时一致。
- `textEnumDescription(Class)`：生成「枚举名(text)」可读说明（如 AUTHORIZATION(鉴权)），供 description 展示。

== 2. 设计要点

=== 2.1 判断条件

- 枚举类（`type.isEnum()`）且实现了 `ICText`（definition 模块接口，`getText()` 提供可读文本）。

=== 2.2 允许值生成

- 遍历枚举常量，允许值用枚举名 `name()`（保证可提交，与运行时传值一致），允许值类型 `LIST`。
- 可读「枚举名(text)」由 `textEnumDescription` 单独生成，避免污染可提交值。
- 非 ICText 枚举或空枚举返回 null（调用方不覆写，保持默认展示）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 非枚举 / 非 ICText | 返回 null |
| 空枚举 | 返回 null |
| 枚举常量 text 为空 | 描述拼接为「枚举名()」 |

== 4. 适用范围

=== 4.1 适用场景

- model 属性枚举与请求参数枚举的文档展示（由 CTextEnumModelPropertyPlugin / CTextEnumParameterPlugin 调用）。

== 5. 已知限制与取舍

- 允许值保持枚举名，保证文档值可直接用于请求；text 可读性通过 description 提供。

无独立测试类（逻辑由集成测试 CTextEnumIntegrationTests 覆盖）。
