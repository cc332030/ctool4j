== 1. 功能说明

`CSchemaTestConfiguration` 为 `CSchema` 集成测试辅助配置（`@Configuration`），标注 `@EnableSwagger2WebMvc` 激活 springfox Swagger2 文档端点（`/v2/api-docs`），供测试验证字段文档生效（springfox 2.10.5 用 `@EnableSwagger2WebMvc` 替代 2.9 的 `@EnableSwagger2`）。

== 4. 适用范围

=== 4.1 适用场景

- `CSchemaIntegrationTests` 集成测试，激活 Swagger2 文档端点以验证字段文档生成。

== 5. 已知限制与取舍

- 测试辅助配置；依赖 springfox 2.10.5 的注解激活方式。
