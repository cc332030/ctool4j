== 1. 功能说明

`CCsvUtils`（`@UtilityClass`）提供 CSV 单元格字符串的处理能力：

- `trim(String)`：去除字符串两端空白，空白字符串返回 `null`；并移除字符串中的退格字符（`\b`）。

== 2. 设计要点

=== 2.1 trim 语义

- 先调用 `CStrUtils.trim` 去除两端空白。
- 空白（blank）字符串返回 `null`（空串、纯空白、仅退格均视为 blank）。
- 非空串去除所有退格字符（`\b`）后返回。

=== 2.2 实现方式

- 依赖 `CStrUtils.trim` 与 hutool 的 `StrUtil.isBlank`。
- 通过 `replaceAll("\b", "")` 移除退格字符。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 入参为 null | 返回 null |
| 空串 / 纯空白 / 仅退格 | 返回 null |
| 普通字符串 | 去除两端空白与退格后返回 |

== 4. 适用范围

=== 4.1 适用场景

- CSV 单元格值的标准化（去空白、去退格）。

=== 4.2 不适用/边界场景

- 不处理字符串内部的常规空白（仅去除退格与两端空白）。

== 5. 已知限制与取舍

- 退格移除使用正则 `\b`，对退格字符 `\u0008` 生效。
- 空串返回 null 的约定需调用方注意区分"空单元格"与"缺失列"。
