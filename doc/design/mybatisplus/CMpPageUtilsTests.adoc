== 用例设计思路与依据

=== 设计思路

- 验证创建 Page 的各路径：默认大小、查询/任务/导出的单次大小、由 ICPage 创建、null orders 边界。

=== 设计依据

- 依据功能设计对不同场景单次分页大小的约定。
- 依据测试方法（等价类/边界）：默认大小、各场景大小、ICPage 转换、null orders。

=== 覆盖场景与未覆盖

- 覆盖：getPage 默认大小；getPageForQuery/Job/Export 各大小；由 ICPage 创建；null orders 边界。
- 未覆盖：真实 MyBatis-Plus 分页拦截器集成。

== 1. 分页创建

- 1.1 getPage 默认大小（`getPageDefaultSize`）
- 1.2 getPage（`getPage`）
- 1.3 查询分页（`getPageForQuery`）
- 1.4 任务分页（`getPageForJob`）
- 1.5 导出版分页（`getPageForExport`）
- 1.6 由 ICPage 创建（`getPageByICPage`）
- 1.7 ICPage null orders 边界（`getPageByICPageNullOrders`）
