== 用例设计思路与依据

=== 设计思路

- 通过 Mockito 模拟 ProcessingEnvironment/RoundEnvironment，验证处理器的源版本、注解类型、模板加载与 process 各分支。

=== 设计依据

- 依据功能设计对处理器源版本、注解类型声明、模板加载、process 返回约定的约定。

=== 覆盖场景与未覆盖

- 覆盖：支持 Java 8；注解类型含 AutoBizService；init 加载模板；process 未 init/空注解返回约定；字段元素跳过生成。
- 未覆盖：真实编译期注解处理生成业务服务的端到端流程。

== 1. 注解处理器行为

- 1.1 支持 Java 8 源版本（`supportedSourceVersion_RELEASE8`）
- 1.2 注解类型含 AutoBizService（`supportedAnnotationTypes_containsAutoBizService`）
- 1.3 init 加载模板（`init_loadsTemplate`）
- 1.4 process 未 init 返回 true（`process_beforeInit_returnsTrue`）
- 1.5 process 空注解返回 true（`process_emptyAnnotations_returnsTrue`）
- 1.6 process 字段元素跳过生成（`process_fieldElement_skipsGeneration`）
