== 1. 功能说明

`CLogSensitive` 为日志脱敏注解。

字段/getter 级注解，日志序列化时按保留前后缀位数脱敏（默认前缀3后缀4），中间 `*` 填充；长度不足全部打码。

== 2. 设计要点

- 注解类为声明式标记；常量类为静态常量。

== 3. 兜底设计

- 注解无默认兜底；常量有默认值。

== 4. 适用范围

- 供业务代码/日志序列化/测试环境判断使用。

== 5. 已知限制与取舍

- 注解仅声明，实际行为由消费方（如 CJsonUtils、日志序列化器）实现。
