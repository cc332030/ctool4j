== 1. 功能说明

`ICIntMsgResult` 为整型编码消息数据结果契约接口。
- 组合语义：编码类型固定为 Integer
- 继承关系：extends ICResult<Integer, DATA>, ICCodeMsgDataResult<Integer, DATA>

== 2. 设计要点

- 契约接口，组合编码/消息/数据等子契约，供各类结果对象实现。

== 3. 兜底设计

- 无（接口仅声明契约）。

== 4. 适用范围

- 作为业务结果对象的公共契约（如含编码、消息、数据的响应体）。

== 5. 已知限制与取舍

- 仅契约；`ICCodeMessageDataResult` 标注 `@CJsonLog`（日志脱敏）。
