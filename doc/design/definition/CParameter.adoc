== 1. 功能说明

`CParameter` 为接口参数级文档描述注解（纯文档，不参与运行时绑定），命名对应 OpenAPI3 中 Swagger/OpenAPI2
`ApiParam` 的替代注解 `Parameter`（前缀 c），标注在接口方法参数上，描述参数的名称、说明、示例。

- `value()`：参数说明，默认 ""，支持简写 `@CParameter("内容")`
  （替代了原先的 `description()`，对应 `Parameter.description` / `ApiParam.value`）
- `name()`：参数名称（对应 `Parameter.name` / `ApiParam.name`），默认 ""
- `example()`：参数示例（对应 `Parameter.example`），默认 ""

不含 required 属性（必填由 SpringMVC `@RequestParam` 或 `@CNotRequired` 表达），也不参与 SpringMVC 参数绑定。

== 2. 设计要点

=== 2.1 替代 OpenAPI2 ApiParam

- `@CParameter` 替代参数级 `@ApiParam`。

=== 2.2 纯文档描述

- 文档侧由 openapi2 的 `CParameterAnnotationPlugin` 读取 name/description/example 写入 springfox；
  必填判定：标注 `@CNotRequired` 即非必填（独立生效，无需同时标注 @CParameter）；
  标注 `@CParameter` 且未标 `@CNotRequired` 时标记必填（默认必填）。

=== 2.3 绑定分离

- 参数绑定与必填由 SpringMVC 原生 `@RequestParam(required = ...)` 控制，`@CParameter` 不驱动绑定。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| name 为空 | 沿用参数既有名称 |
| value/example 为空 | 不覆盖已有内容 |
| 必填表达（文档） | 未标 @CNotRequired 即标记必填；标 @CNotRequired 独立标记非必填 |
| 必填表达（绑定） | 由 @RequestParam.required 控制 |

== 4. 适用范围

=== 4.1 适用场景

- 接口方法参数需要名称/说明/示例时标注 `@CParameter`，由 openapi2 的 `CParameterAnnotationPlugin` 落地文档。

=== 4.2 不适用/边界场景

- 不参与运行时绑定；绑定请用 `@RequestParam`。
