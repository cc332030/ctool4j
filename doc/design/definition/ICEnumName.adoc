`ICEnumName` 为 枚举名契约接口。


== 2. 设计要点

- 契约接口，定义数据访问方法签名，供实体/结果类实现。

== 3. 兜底设计

- 无（接口仅声明契约，无逻辑）。

== 4. 适用范围

- 作为 DTO/实体/枚举/结果对象的公共契约，统一数据访问语义。

== 5. 已知限制与取舍

- 仅契约，无默认实现（除组合接口）。
