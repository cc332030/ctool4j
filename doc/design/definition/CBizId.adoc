== 1. 功能说明

`CBizId` 为业务 ID 字段标记注解。

字段级注解，`value()` 指定业务 ID 字段名（默认空）。

== 2. 设计要点

- 注解类为声明式标记；常量类为静态常量。

== 3. 兜底设计

- 注解无默认兜底；常量有默认值。

== 4. 适用范围

- 供业务代码/日志序列化/测试环境判断使用。

== 5. 已知限制与取舍

- 注解仅声明，实际行为由消费方（如 CJsonUtils、日志序列化器）实现。
