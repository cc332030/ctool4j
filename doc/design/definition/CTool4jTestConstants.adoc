== 1. 功能说明

`CTool4jTestConstants` 为测试环境常量。

`JUNIT_TEST_CLASS_NAME`：JUnit 测试类名；`IS_TEST`：通过能否加载 JUnit 判断是否测试环境。

== 2. 设计要点

- 纯常量类：仅声明静态常量，不含逻辑。

== 3. 兜底设计

- 常量为编译期字面量，无运行时兜底。

== 4. 适用范围

- 供业务代码/日志序列化/测试环境判断使用。

== 5. 已知限制与取舍

- 本类使用 slf4j 原生 `@Slf4j` 而非 `@CustomLog`：本类位于 `ctool4j-definition` 基础模块，
  `ctool4j-core` 依赖本模块，`@CustomLog` 生成的 `CLog` 位于 core 会形成反向依赖（循环依赖），
  故保留 `@Slf4j`。
