`CJsonLog` 为JSON 日志标记注解。

类型级标记注解，无属性，标注在结果/实体类上。

== 2. 设计要点

- 注解类为声明式标记；常量类为静态常量。

== 3. 兜底设计

- 注解无默认兜底；常量有默认值。

== 4. 适用范围

- 供业务代码/日志序列化/测试环境判断使用。
