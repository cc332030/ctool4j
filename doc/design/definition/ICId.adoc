== 1. 功能说明

`ICId<T extends Serializable>` 为通用主键契约接口：

- `getId()`：获取主键
- `setId(T id)`：设置主键

== 2. 设计要点

- 泛型 `T extends Serializable` 限定主键为可序列化类型。
- 供各实体基类/具体主键类型接口（如 ICIntegerId/ICLongId/ICStringId）继承。

== 3. 兜底设计

- 无（接口仅声明契约）。

== 4. 适用范围

- 作为带主键的实体基类公共契约。

== 5. 已知限制与取舍

- 主键类型由子接口/实现决定；仅约定 getter/setter。
