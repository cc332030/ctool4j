适用范围：Redis Service 抽象基类（注入 RedisTemplate）

== 1. 功能说明

`CAbstractRedisService<K, V>` 为 Redis Service 抽象基类，实现 `ICRedisService<K, V>`，
注入 `RedisTemplate<K, V>`，子类直接复用基类的默认键值操作。

== 2. 设计要点

=== 2.1 语义约定

- 通过 `@Autowired` 注入 `RedisTemplate<K, V>`（`@Setter(onMethod_=@Autowired)`）。
- 子类继承全部 `ICRedisService` 默认方法，仅需提供模板。

=== 2.2 实现方式

- lombok `@Getter`/`@Setter` 暴露 `redisTemplate`，实现 `getRedisTemplate()`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| `redisTemplate` 未注入 | 使用时的默认方法将 NPE（依赖 Spring 注入） |

== 4. 适用范围

=== 4.1 适用场景

- 需要基于 `RedisTemplate` 的键值操作 Service 基类（如 `CStringStringRedisService`）。

=== 4.2 不适用/边界场景

- 不提供具体序列化策略，由子类/模板决定。

== 5. 已知限制与取舍

- 注入依赖 Spring 容器；非 Spring 环境无法直接使用。

测试内容见 `doc/design/redis/CStringStringRedisServiceTests.adoc`。
