== 1. 功能说明

`CMinioOkHttpConfig`（`@Data` + `@ConfigurationProperties("minio.okhttp")`）承载 MinIO 客户端 OkHttp 超时配置：

- `connectTimeout`：连接超时（秒），默认 1。
- `writeTimeout`：写超时（秒），默认 3。
- `readTimeout`：读超时（秒），默认 3。

== 2. 设计要点

=== 2.1 默认值

- 连接 1s、写 3s、读 3s，可通过 `minio.okhttp.*` 覆盖。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未配置 | 使用默认超时（1/3/3 秒） |

== 4. 适用范围

=== 4.1 适用场景

- 构建 MinIO 客户端所用 OkHttpClient 的超时参数。

== 5. 已知限制与取舍

- 默认超时较短，大文件/慢网络场景需按需调大。
