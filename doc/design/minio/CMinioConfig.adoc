== 1. 功能说明

`CMinioConfig`（`@Data` + `@ConfigurationProperties("minio")`）承载 MinIO 连接配置：

- `endpoint`：访问地址。
- `accessKey`：访问密钥 ID。
- `secretKey`：访问密钥。

== 2. 设计要点

=== 2.1 配置项

- 三个属性均无默认值，需外部配置 `minio.endpoint`、`minio.accessKey`、`minio.secretKey`。

== 3. 兜底设计

无（配置缺失时由使用方/构建报错）。

== 4. 适用范围

=== 4.1 适用场景

- MinioClient 的连接参数来源。
