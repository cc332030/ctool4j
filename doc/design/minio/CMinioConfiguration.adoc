适用范围：MinIO 客户端 Spring Bean 配置

== 1. 功能说明

`CMinioConfiguration`（`@Configuration`）注册 MinIO 相关 Bean：

- `cMinioOkHttpClient`：按 `CMinioOkHttpConfig` 构建 OkHttpClient（配置连接/写/读超时）。
- `cMinioClient`：按 `CMinioConfig` + OkHttpClient 构建 `MinioClient`。

== 2. 设计要点

=== 2.1 Bean 构建

- OkHttpClient 通过 builder 设置 connect/write/read 超时。
- MinioClient 用 builder 设置 endpoint、credentials、httpClient。

== 3. 兜底设计

无（配置缺失时构建可能失败）。

== 4. 适用范围

=== 4.1 适用场景

- 注入 MinIO 客户端与底层 OkHttpClient。

== 5. 已知限制与取舍

- 依赖 `CMinioConfig`/`CMinioOkHttpConfig` 配置属性。

无测试类。
