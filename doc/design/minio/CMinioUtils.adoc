== 1. 功能说明

`CMinioUtils`（`@UtilityClass`）提供 MinIO 相关工具：

- `getSize(GetObjectResponse)`：从响应头 `Content-Length` 获取对象大小，无法获取时返回 null。

== 2. 设计要点

=== 2.1 getSize

- 对 response 空安全处理，取 `headers().get(CONTENT_LENGTH)` 转 Long；任何环节缺失返回 null。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| response 为 null | 返回 null |
| Content-Length 头缺失 | 返回 null |

== 4. 适用范围

=== 4.1 适用场景

- 获取对象大小。

== 5. 已知限制与取舍

- 依赖响应头的 Content-Length，非所有响应都携带。
