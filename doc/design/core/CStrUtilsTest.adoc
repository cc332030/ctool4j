== 用例设计思路与依据

=== 设计思路

- 白盒原则：围绕 CStrUtils 的关键字符串处理能力设计用例：
  - `format`：模板格式化，缺失参数格式化为空字符串（默认替换值）
  - `incrLastNum`：字符串末尾数字自增
  - `chineseOnly`：提取字符串中的中文（覆盖纯中文、纯英文/数字、混合、特殊字符边界）
  - `toAvailable`：单侧引号处理（Q16 修复：start == end 时保留该非引号字符）
- 边界：`chineseOnly` 覆盖无中文、含特殊字符、混合等；`toAvailable` 覆盖单引号/双引号/空串/仅引号等边界。
