== 用例设计思路与依据

=== 设计思路

- 按「普通正则缓存 / URL 通配符」两个维度组织。
- 普通缓存覆盖：正例匹配、缓存实例复用（assertSame）、自定义编译函数。
- URL 通配符覆盖：`**`（跨层）、`*`（单层）、`.` 转义三个通配符规则分支。

=== 设计依据

- 依据功能设计对缓存复用与通配符规则的约定。
- 依据测试方法（分支覆盖/边界值）：`**` 跨 `/`、`*` 不跨 `/`、`.` 转义。

=== 覆盖场景与未覆盖

- 覆盖：普通正则匹配/缓存复用/自定义编译；URL 通配符 `**`、`*`、`.` 转义分支。
- 未覆盖：`**/` 与占位符替换相互污染的具体回归样本（当前用例覆盖 `**` 后跟 `/` 场景，见
  getUrlCacheDoubleStar 的 `/api/**` 与 `/api/`）。

== 1. 普通正则缓存（getCache）

- 1.1 正例：`^\d+$` 匹配 `123`、不匹配 `12a`（getCache）
- 1.2 缓存复用：同一 regex 返回同一实例（assertSame）（getCacheCached）
- 1.3 自定义编译：`getCache("custom-1", Pattern::compile)` 可匹配（getCacheWithCustom）

== 2. URL 通配符（getUrlCache）

- 2.1 `**`：`/api/**` 匹配 `/api/a/b`、`/api/`，不匹配 `/api`（getUrlCacheDoubleStar）
- 2.2 `*`：`/api/*` 匹配 `/api/a`，不匹配 `/api/a/b`（getUrlCacheSingleStar）
- 2.3 `.` 转义：`/a.*` 匹配 `/a.b`，不匹配 `/axb`（getUrlCacheEscapesDot）
