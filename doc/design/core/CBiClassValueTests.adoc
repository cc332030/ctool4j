== 用例设计思路与依据

=== 设计思路

- 按「取值 / 缓存 / 独立计算」三个维度组织。
- 取值验证组合结果；缓存用计数验证同一组合只计算一次；独立计算验证不同组合分别计算。

=== 设计依据

- 依据功能设计对双类组合惰性计算与缓存的约定。

=== 覆盖场景与未覆盖

- 覆盖：get 组合值；同一组合缓存；不同组合独立计算。
- 未覆盖：remove 后重新计算（未单列）。

== 1. 取值

- 1.1 get：返回双类名组合（get）

== 2. 缓存

- 2.1 同一组合缓存：多次 get 只计算一次（cached）

== 3. 独立计算

- 3.1 不同组合：各自独立计算（differentPairComputeSeparately）
