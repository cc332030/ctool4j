适用范围：项目基础运行时异常基类

== 1. 功能说明

`CException` 为项目基础异常，继承 `RuntimeException`，标注 `@StandardException`
（Lombok 生成完整构造方法集合：无参/消息/原因/消息+原因）。

== 2. 设计要点

=== 2.1 构造方法

- 由 `@StandardException` 生成标准异常构造集合：
  - 无参构造：message/cause 均为 null
  - `(String message)`、`(Throwable cause)`、`(String message, Throwable cause)`

=== 2.2 基类定位

- 作为项目运行时异常的基类，业务异常 `CBusinessException` 继承自它。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无参构造 | message/cause 为 null |
| 带消息构造 | 消息正确设置 |
| 带原因构造 | cause 正确设置 |

== 4. 适用范围

=== 4.1 适用场景

- 项目自定义运行时异常的基类。

=== 4.2 不适用/边界场景

- 业务异常应使用 `CBusinessException`（带错误码）。

== 5. 已知限制与取舍

- 继承 RuntimeException，支持标准异常构造，便于业务异常复用。

测试内容见 `doc/design/core/CExceptionTests.adoc`。
