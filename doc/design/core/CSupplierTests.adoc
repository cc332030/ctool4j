== 用例设计思路与依据

=== 设计思路

- 按「get / 工具方法」两个维度组织。
- get 覆盖正常、null、受检异常；工具覆盖 alwaysNull、静态 get（null/正常）、convert（null/正常）。

=== 设计依据

- 依据功能设计对 @SneakyThrows 包装与工具方法的约定。

=== 覆盖场景与未覆盖

- 覆盖：get 正常/null/受检异常；alwaysNull；静态 get null/正常；convert null/正常。
- 未覆盖：无。

== 1. get

- 1.1 正常：返回值正确（getNormal）
- 1.2 null：返回 null（getNull）
- 1.3 受检异常：抛 IOException（getSneakyThrowsCheckedException）

== 2. 工具方法

- 2.1 alwaysNull：恒返回 null（alwaysNull）
- 2.2 静态 get null：返回 null（staticGetNullSupplier）
- 2.3 静态 get 正常：返回值正确（staticGetNormal）
- 2.4 convert：转 JDK Supplier（convert）
- 2.5 convert null：返回 null（convertNullCSupplier）
