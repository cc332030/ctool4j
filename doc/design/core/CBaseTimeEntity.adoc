== 1. 功能说明

`CBaseTimeEntity<ID>` 为基础时间实体，继承 `CBaseCreateTimeEntity<ID>` 并实现 `ICCreateUpdateTime`，
在创建时间基础上增加 `updateTime` 字段。

== 4. 适用范围

=== 4.1 适用场景

- 需要主键 + 创建/更新时间的实体基类。

== 5. 已知限制与取舍

- updateTime 不可插入/更新（strategy NEVER）。

测试内容见 `doc/design/core/CBaseTimeEntityTests.adoc`。
