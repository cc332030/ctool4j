== 1. 功能说明

`ICBusinessExceptionProvider<T extends Throwable>` 为业务异常提供者接口（SPI 扩展点），提供：

- `getExceptionFunction()`：默认实现——基于 `getMessageExceptionFunction` 创建异常，
  消息经 `CResUtils.formatResMessage(error, errorExtend)` 格式化。
- `getMessageExceptionFunction()`：默认实现抛 `UnsupportedOperationException("No impl")`，
  由实现类覆盖。

== 2. 设计要点

=== 2.1 默认异常函数

- `getExceptionFunction()` 默认经 `formatResMessage` 生成 `[code] msg[: extend]` 消息，再委托
  `getMessageExceptionFunction` 创建异常。
- error 为 null 时消息仅含扩展信息。

=== 2.2 扩展点

- 实现类覆盖 `getMessageExceptionFunction` 以定制异常创建；默认实现抛 UnsupportedOperationException
  强制实现类覆盖。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| getMessageExceptionFunction 默认调用 | 抛 UnsupportedOperationException |
| error 为 null | 消息仅含扩展信息 |

== 4. 适用范围

=== 4.1 适用场景

- 通过 SPI 自定义业务异常类型/创建逻辑。

=== 4.2 不适用/边界场景

- 直接使用默认 getExceptionFunction 需覆盖 getMessageExceptionFunction，否则抛异常。

== 5. 已知限制与取舍

- 默认实现提供消息格式化，异常创建留给实现类，保持 SPI 扩展灵活。
