== 用例设计思路与依据

=== 设计思路

- 验证序列化输出固定占位符，覆盖非空内容与 null 内容两分支。

=== 设计依据

- 依据功能设计对输出 `<BLOB>` 占位符的约定。

=== 覆盖场景与未覆盖

- 覆盖：非空内容输出 `<BLOB>`；null 内容同样输出 `<BLOB>`。
- 未覆盖：无（覆盖了核心行为）。

== 1. 序列化

- 1.1 非空内容：输出 `"<BLOB>"`（serializeBlob）
- 1.2 null 内容：输出 `"<BLOB>"`（serializeNullContent）
