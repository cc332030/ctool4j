== 1. 功能说明

`CCurrencyEnum` 为货币枚举，定义 17 种货币（CNY/USD/EUR/GBP/JPY/KRW/HKD/TWD/AUD/CAD/CHF/SGD/NZD/THB/
MYR/RUB/INR），各带中文描述 `text`。

== 4. 适用范围

=== 4.1 适用场景

- 货币类型的标准化枚举。

== 5. 已知限制与取舍

- 描述为中文文本。
