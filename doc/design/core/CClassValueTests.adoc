== 用例设计思路与依据

=== 设计思路

- 按「取值 / 缓存 / 独立计算」三个维度组织。
- 取值验证返回类名；缓存用 AtomicInteger 计数验证同一类只计算一次；独立计算验证不同类分别计算。

=== 设计依据

- 依据功能设计对惰性计算与按类缓存的约定。

=== 覆盖场景与未覆盖

- 覆盖：get 返回值；同一类缓存（只计算一次）；不同类独立计算。
- 未覆盖：remove 后重新计算（依赖缓存弱关联行为，未单列）。

== 1. 取值

- 1.1 get：返回类简单名（get）

== 2. 缓存

- 2.1 同一类缓存：多次 get 值函数只执行一次（cached）

== 3. 独立计算

- 3.1 不同类：各自计算（differentClassComputeSeparately）
