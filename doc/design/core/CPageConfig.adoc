== 1. 功能说明

`CPageConfig` 为分页配置类，标注 `@ConfigurationProperties("page")`，提供属性：

- `defaultPageSize`：默认分页大小，默认 100

== 2. 设计要点

=== 2.1 配置绑定

- 通过 `@ConfigurationProperties("page")` 绑定 `page.defaultPageSize` 配置项。
- 默认值 100，未配置时生效。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未配置 page.defaultPageSize | 使用默认 100 |

== 4. 适用范围

=== 4.1 适用场景

- Spring Boot 分页默认大小配置注入。

=== 4.2 不适用/边界场景

- 需配合 `@EnableConfigurationProperties` 或组件扫描启用配置绑定。

== 5. 已知限制与取舍

- 简单配置属性类，默认值保证未配置可用。

测试内容见 `doc/design/core/CPageConfigTests.adoc`。
