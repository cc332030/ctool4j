适用范围：敏感字段检测修改器（@CLogSensitive 字段日志脱敏输出）

== 1. 功能说明

`CLogSensitiveSerializerModifier` 为敏感字段序列化修改器，继承 `CLogFieldSerializerModifier<CLogSensitive>`，
检测标注 `@CLogSensitive` 的字段，日志序列化时脱敏输出。

- 仅注册到日志专用 ObjectMapper；全局 mapper 输出真实内容。

== 2. 设计要点

=== 2.1 序列化器创建

- `createSerializer` 按注解 `prefixKeep`/`suffixKeep` 创建 `CSensitiveSerializer`，保留位数可配。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 日志 mapper 序列化 @CLogSensitive 字段 | 脱敏输出 |
| 全局 mapper 序列化 @CLogSensitive 字段 | 输出真实内容 |
| @CLogSensitive 字段为 null | 日志 mapper 不输出 |

== 4. 适用范围

=== 4.1 适用场景

- 敏感字段（手机号等）日志打印脱敏。

== 5. 已知限制与取舍

- 仅日志 mapper 生效，业务输出真实内容。

测试内容见 `doc/design/core/CLogSensitiveSerializerModifierTests.adoc`。
