== 用例设计思路与依据

=== 设计思路

- 验证 `isJsonLog` 的正反判断：命中转 JSON 集合（CResult 实现 ICBaseResult）为 true；
  JDK 基本类（String）与命中不转集合（DataSource）为 false。

=== 设计依据

- 依据功能设计对 JSON 化判断规则（转集合命中 / JDK 类 / 不转集合）的约定。

=== 覆盖场景与未覆盖

- 覆盖：isJsonLog 转 JSON 类型（CResult）、JDK 类（String）、不转类型（DataSource）。
- 未覆盖：包名匹配、注解匹配、setJsonLog 动态配置等其余规则分支（当前测试聚焦基础判断，
  其余分支可后续批次补充）。
