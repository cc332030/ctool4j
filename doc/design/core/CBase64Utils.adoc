适用范围：字节数组与 Base64 字符串互转（编码/解码）

== 1. 功能说明

`CBase64Utils` 为 Base64 编解码工具类，基于 hutool 的 `Base64` 封装，提供字节数组与
Base64 字符串的双向转换。

- `encode(byte[])`：字节数组编码为 Base64 字符串；空数组/null 返回 null
- `decode(String)`：Base64 字符串解码为字节数组；空字符串/null 返回 null

== 2. 设计要点

=== 2.1 语义约定

- 空入参（encode 的空字节数组/null、decode 的空字符串/null）统一返回 null，调用方据此可
  安全判断"未编码/未解码"。
- 编码与解码互为逆操作：`decode(encode(bytes))` 恢复原字节数组。

=== 2.2 实现方式

- 直接委托 hutool `Base64.encode/decode`，本项目不重复实现字符集转换，避免引入与既有库
  不一致的编码结果。
- 入参空值判断前置，避免空入参传入底层库产生非预期行为。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| encode 传入空字节数组/null | 返回 null |
| decode 传入空字符串/null | 返回 null |

== 4. 适用范围

=== 4.1 适用场景

- 二进制数据的文本表示（传输、存储、URL/邮件等需文本化的场景）。
- 需要与 Base64 互操作的数据传输/存储。

=== 4.2 不适用/边界场景

- 仅支持字节数组↔字符串互转，不提供其他语义。
- 非法 Base64 字符串（含非 Base64 字符）解码行为由底层 hutool 决定，本类不额外校验。

== 5. 已知限制与取舍

- 空入参返回 null 与 hutool 底层行为解耦，由本类显式控制，保证空值语义稳定。
