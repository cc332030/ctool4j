= CRefBiClassValue 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.cache.impl.CRefBiClassValue
状态：已落地
适用范围：可设置的双类缓存值（基于 AtomicReference）

== 1. 功能说明

`CRefBiClassValue<T>` 为可设置的双类缓存实现，实现 `ICRefBiClassValue<T>`，提供：

- `of(CBiFunction<Class,Class,T>)`：创建，初始值经值函数计算
- `get(type1, type2)`：获取双类组合缓存值
- `set(type1, type2, T)`：覆盖双类组合缓存值

== 2. 设计要点

=== 2.1 嵌套 AtomicReference

- 基于 `CBiClassValue<AtomicReference<T>>`：每个双类组合对应一个 AtomicReference 存初始计算值。

=== 2.2 可覆盖

- `set` 覆盖指定组合的引用值，`get` 读取当前值；不同组合相互独立。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| set 后 get | 返回覆盖后的值 |
| 不同组合 set | 互不影响 |

== 4. 适用范围

=== 4.1 适用场景

- 双类组合缓存且运行期可覆盖值。

=== 4.2 不适用/边界场景

- 仅需一次性计算缓存时用 `CBiClassValue`。

== 5. 已知限制与取舍

- 通过 AtomicReference 支持原子覆盖，兼顾线程安全。

测试内容见 `doc/design/core/CRefBiClassValueTests.adoc`。
