适用范围：按类型判断值是否有效（isValid）/无效（isNotValid）

== 1. 功能说明

`CValidUtils` 为有效性判断工具类，提供 `isValid` / `isNotValid` 重载：

- `Object`：非 null / null
- `CharSequence`：非空且非空白（isNotBlank）/ 空白
- `Iterable` / `Collection`：非空 / 空
- `Map`：非空 / 空
- 各类型数组（byte/short/char/int/long/float/double/boolean/Object）：非空 / 空

== 2. 设计要点

=== 2.1 按类型选择校验逻辑

- 基于 `CValidateUtils` 支持的数据类型，按类型选择校验：字符串按 blank、集合/Map/数组按 notEmpty、
  其他对象按非 null。
- 调用时传入具体类型变量，由重载自动匹配；传 null 字面量会因多重载产生歧义，应传入具体类型变量。

=== 2.2 判断语义

- 字符串：`isValid = StrUtil.isNotBlank`，`isNotValid = StrUtil.isBlank`。
- 集合/Map/数组：`isValid = CollUtil/MapUtil/ArrayUtil.isNotEmpty`，`isNotValid = ...isEmpty`。
- 对象：`isValid = Objects.nonNull`，`isNotValid = Objects.isNull`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 字符串空白/null | isNotValid 为 true |
| 集合/Map/数组空/null | isNotValid 为 true |
| 对象 null | isNotValid 为 true |

== 4. 适用范围

=== 4.1 适用场景

- 按类型统一判断值有效性，避免逐类型手写判空。

=== 4.2 不适用/边界场景

- 传 null 字面量会因多重载歧义编译失败，需强转具体类型。

== 5. 已知限制与取舍

- 通过重载区分类型，类型安全但需注意 null 字面量的编译歧义。
