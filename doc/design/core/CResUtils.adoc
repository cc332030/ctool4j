适用范围：响应信息（ICRes）格式化

== 1. 功能说明

`CResUtils` 为响应信息格式化工具类，提供：

- `formatMessage(ICRes)` / `formatMessage(ICRes, String msgExtend)`：格式化响应信息
- `formatResMessage(ICRes)` / `formatResMessage(ICRes, String msgExtend)`：带错误码格式化响应信息

== 2. 设计要点

=== 2.1 语义约定

- `formatMessage`：res 为 null 时返回 msgExtend；msgExtend 为空（null/空白）时返回 res.getMsg()；
  否则返回 `res.getMsg() + ": " + msgExtend`。
- `formatResMessage`：res 为 null 时返回 msgExtend；否则返回 `"[code] msg`，msgExtend 非空时
  追加 `": " + msgExtend`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| formatMessage res 为 null | 返回 msgExtend |
| formatMessage msgExtend 为空 | 返回 res.getMsg() |
| formatResMessage res 为 null | 返回 msgExtend |
| formatResMessage msgExtend 为空 | 返回 `[code] msg`（不追加） |

== 4. 适用范围

=== 4.1 适用场景

- 统一格式化接口/异常响应信息，便于日志与错误提示拼接。

=== 4.2 不适用/边界场景

- 仅支持 `ICRes` 接口（getCode/getMsg）；其他响应类型需自行适配。

== 5. 已知限制与取舍

- 空值语义统一（res null 返回扩展信息、扩展空返回 msg），调用方无需重复判空。
