== 1. 功能说明

`CLogBlobSerializer` 为长文本字段序列化器，扩展 `JsonSerializer<Object>`，序列化时跳过真实内容，
输出固定占位符 `BLOB_PLACEHOLDER = "<BLOB>"`。提供单例 `INSTANCE`。

== 2. 设计要点

=== 2.1 脱敏占位

- 无论 value 是否为 null/真实长文本，均输出 `<BLOB>`，避免长文本真实内容出现在日志中。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| value 非空/空/null | 均输出 `<BLOB>` 占位符 |

== 4. 适用范围

=== 4.1 适用场景

- 长文本字段（如日志/请求体）序列化时隐藏真实内容，输出占位符。

== 5. 已知限制与取舍

- 牺牲真实内容可见性换取日志安全（占位符）。

测试内容见 `doc/design/core/CLogBlobSerializerTests.adoc`。
