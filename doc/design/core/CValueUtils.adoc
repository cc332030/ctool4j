= CValueUtils 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CValueUtils
状态：已落地
适用范围：对象经函数取值后的枚举值获取、枚举值消费

== 1. 功能说明

`CValueUtils` 为取值工具类，提供：

- `getValue(E obj, CFunction<E, ICValue<T>> function)`：对象经取值函数获取枚举值（ICValue）
- `getValue(ICValue<T> iValue)`：从枚举值对象获取其值
- `setValue(ICValue<T> iValue, CConsumer<T> consumer)`：枚举值消费（枚举为 null 时跳过）

== 2. 设计要点

=== 2.1 null 语义

- `getValue(E, function)`：对象或函数结果为 null 时返回 null（经 `CObjUtils.convert`）。
- `getValue(ICValue)`：枚举为 null 时返回 null。
- `setValue`：枚举为 null 时不调用 consumer（无操作）。

=== 2.2 取值路径

- 对象重载先经 `CObjUtils.convert(obj, function)` 取到 ICValue，再委托 `getValue(ICValue)`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 对象重载：obj 为 null 或函数返回 null | 返回 null |
| getValue(ICValue)：枚举为 null | 返回 null |
| setValue：枚举为 null | 不调用 consumer |

== 4. 适用范围

=== 4.1 适用场景

- 对实现 `ICValue<T>` 的枚举/值对象统一取值，避免逐处判空。
- 枚举值消费（非空才执行）。

=== 4.2 不适用/边界场景

- 仅支持 `ICValue` 接口语义；非 ICValue 取值用 `CObjUtils.convert` 或原生函数式取值。

== 5. 已知限制与取舍

- null 语义统一为"返回 null / 跳过"，调用方据此可安全链式操作。
