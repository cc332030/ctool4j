== 1. 功能说明

`CDateSerializer` 为 Jackson `Date` 序列化器，扩展 `JsonSerializer<Date>`，将日期序列化为日期时间字符串
（`yyyy-MM-dd HH:mm:ss`）。提供单例 `INSTANCE`。

== 2. 设计要点

=== 2.1 序列化

- `serialize` 经 `DateUtil.formatDateTime(value)` 输出 `yyyy-MM-dd HH:mm:ss` 字符串。

== 4. 适用范围

=== 4.1 适用场景

- 需要 Date 统一序列化为日期时间字符串的 JSON 输出。

== 5. 已知限制与取舍

- 固定 `yyyy-MM-dd HH:mm:ss` 格式，需其他格式时自定义。

测试内容见 `doc/design/core/CDateSerializerTests.adoc`。
