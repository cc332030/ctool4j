== 用例设计思路与依据

=== 设计思路

- 验证枚举数量、CNY/USD 描述与名称，以及未知名抛异常。

=== 设计依据

- 依据功能设计对枚举元素与描述的约定。

=== 覆盖场景与未覆盖

- 覆盖：枚举数量；CNY/USD 描述与名称；未知名抛异常。
- 未覆盖：其余货币（CNY/USD 代表样本，其余结构一致）。
