适用范围：可抛受检异常的任务接口（扩展 JDK Runnable）

== 1. 功能说明

`CRunnable` 为任务接口，扩展 `Runnable`，支持受检异常：

- `run`：默认方法，@SneakyThrows 包装后调用 `runThrowable`
- `runThrowable`：抽象方法，可抛 Throwable
- 工具：`EMPTY`、`run(runnable)`、`convert(runnable)`

== 2. 设计要点

=== 2.1 受检异常包装

- `run` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `run(runnable)`：runnable 为 null 时不做处理；`convert`：转 JDK Runnable。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| run(runnable=null) | 不做处理 |
| EMPTY | 空实现 |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。

测试内容见 `doc/design/core/CRunnableTests.adoc`。
