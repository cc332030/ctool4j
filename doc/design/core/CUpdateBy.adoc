== 1. 功能说明

`CUpdateBy` 为更新人实体，继承 `CCreateBy` 并实现 `ICCreateUpdateBy`，在创建人基础上增加 `updateById` 与
`updateBy` 字段。

== 4. 适用范围

=== 4.1 适用场景

- 需要创建/更新人字段的实体。

== 5. 已知限制与取舍

- 创建人字段不可更新；更新人字段可更新。

测试内容见 `doc/design/core/CUpdateByTests.adoc`。
