适用范围：数组的过滤、元素取值、转换、首元素获取、集合转数组等基础操作

== 1. 功能说明

`CArrUtils` 为数组工具类，提供数组相关的常用操作：

- `filter` / `filterNull` / `filterString`：数组过滤，返回过滤后元素列表
- `get`：按索引取数组元素，支持负索引（从末尾倒数）、越界返回 null
- `convert`：数组元素转换（支持返回 Object[] 或调用方指定的类型化数组）
- `getArr`：泛型可变参数直接返回数组
- `toStrArr`：字符串集合转字符串数组
- `first`：取数组首元素

== 2. 设计要点

=== 2.1 语义约定

- 空数组/null 入参的过滤类方法返回空列表（`CList.of()`），而非 null，调用方可安全遍历。
- `get` 支持负索引（`-1` 表示最后一个元素）；正负索引越界统一返回 null，不抛数组越界异常。
- `convert` 在空数组/null 入参时返回 null（与过滤类方法返回空列表的约定不同，按各方法语义独立约定）。
- `toStrArr` 在集合为空时返回共享空数组常量 `EMPTY_STR_ARR`（复用 `toArray`，非可变集合问题）。

=== 2.2 实现方式

- `filter` 基于 `Arrays.stream` + `predicate` 过滤后收集为 List；空入参前置判断返回空列表。
- `get` 负索引先换算为正向索引（`length + index`），再统一越界判断；负索引越界
  （`index < -length`）同样返回 null。
- `convert` 三参重载由调用方传入数组创建器 `IntFunction<R[]>` 创建目标数组——因 Java 泛型擦除
  后运行期无 `R` 类型信息，原实现构造 Object[] 后强转会在解引用时抛 `ClassCastException`，
  改为由调用方提供数组创建器从源头消除强转（javadoc 已注明该取舍）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| filter/filterNull/filterString 空数组/null | 返回空列表 |
| get 空数组/null / 索引越界（正负） | 返回 null |
| convert 空数组/null | 返回 null |
| toStrArr 空集合/null | 返回空数组常量 EMPTY_STR_ARR |
| first 空数组/null | 返回 null |

== 4. 适用范围

=== 4.1 适用场景

- 数组元素按条件过滤、去空（filterNull/filterString）。
- 按索引取元素（含从末尾倒数取值的负索引场景）。
- 数组元素类型转换（需要类型化数组时用三参 convert）。
- 字符串集合转数组、取数组首元素。

=== 4.2 不适用/边界场景

- `convert` 空入参返回 null（而非空数组），调用方需注意判空。
- `get` 负索引的换算语义为"从末尾倒数"，与 Python 风格负索引一致。

== 5. 已知限制与取舍

- `filter` 返回 List 而非数组，便于调用方使用集合操作。
- `convert` 类型化数组依赖调用方传入创建器，避免运行期强转（`ClassCastException`）隐患。
- `get` 越界返回 null 而非抛异常，牺牲严格越界报错换取无异常取值便利。
