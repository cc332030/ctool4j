适用范围：可设置的按类缓存值（基于 AtomicReference）

== 1. 功能说明

`CRefClassValue<T>` 为可设置的按类缓存实现，实现 `ICRefClassValue<T>`，提供：

- `of(CFunction<Class,T>)`：创建，初始值经值函数计算
- `get(Class<?>)`：获取缓存值
- `set(Class<?>, T)`：覆盖缓存值

== 2. 设计要点

=== 2.1 基于 AtomicReference

- 内部基于 `CClassValue<AtomicReference<T>>`，每个类对应一个 AtomicReference 存初始计算值。

=== 2.2 可覆盖

- `set` 覆盖指定类的引用值，`get` 读取当前引用值；不同类相互独立。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| set 后 get | 返回覆盖后的值 |
| 不同类 set | 互不影响，各自独立 |

== 4. 适用范围

=== 4.1 适用场景

- 按类缓存且运行期可覆盖值（如动态配置）。

=== 4.2 不适用/边界场景

- 仅需一次性计算缓存时用 `CClassValue`。

== 5. 已知限制与取舍

- 通过 AtomicReference 支持原子覆盖，兼顾线程安全。

测试内容见 `doc/design/core/CRefClassValueTests.adoc`。
