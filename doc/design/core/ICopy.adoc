适用范围：对象拷贝接口（默认方法）

== 1. 功能说明

`ICopy` 为对象拷贝接口，提供默认拷贝方法：

- `copyTo(T t)`：拷贝到指定实例（属性覆盖到 t）
- `copyTo(Class<T> tClass)`：拷贝成指定类型新实例

均委托 `CBeanUtils.copy`。

== 2. 设计要点

=== 2.1 委托语义

- `copyTo(Class)`：`CBeanUtils.copy(this, tClass)` 创建目标类型新实例并拷贝同名字段。
- `copyTo(instance)`：`CBeanUtils.copy(this, t)` 将本对象属性拷贝到传入实例。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| copyTo(Class) | 创建目标类型实例并拷贝 |
| copyTo(instance) | 拷贝到指定实例 |

== 4. 适用范围

=== 4.1 适用场景

- 需要便捷拷贝能力的对象（DTO/Entity 转换），实现 `ICopy` 即获得拷贝语义。

=== 4.2 不适用/边界场景

- 依赖 CBeanUtils 拷贝规则（同名属性）。

== 5. 已知限制与取舍

- 统一委托 CBeanUtils，保证拷贝规则一致。

测试内容见 `doc/design/core/ICopyTests.adoc`。
