适用范围：可抛受检异常的三参函数接口

== 1. 功能说明

`CTriFunction<O1, O2, O3, R>` 为三参函数接口，支持受检异常：

- `apply`：默认方法，@SneakyThrows 包装后调用 `applyThrowable`
- `applyThrowable`：抽象方法，可抛 Throwable
- 工具：`apply(function, o1, o2, o3)`、`first()`/`second()`/`third()`

== 2. 设计要点

=== 2.1 受检异常包装

- `apply` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `apply(function, o1, o2, o3)`：function 为 null 返回 null。
- `first()`/`second()`/`third()`：分别返回取第一/第二/第三参数的函数。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| apply(function=null, ...) | 返回 null |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。
