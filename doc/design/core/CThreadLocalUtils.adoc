= CThreadLocalUtils 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CThreadLocalUtils
状态：已落地
适用范围：ThreadLocal 取值（取后移除、默认值）

== 1. 功能说明

`CThreadLocalUtils` 为 ThreadLocal 工具类，提供：

- `getThenRemove(ThreadLocal)`：获取值并立即移除
- `getOrDefault(ThreadLocal, T defaultValue)`：取值，为 null 时返回默认值
- `getOrDefault(ThreadLocal, Supplier<T>)`：取值，为 null 时经 supplier 获取默认值

== 2. 设计要点

=== 2.1 取后移除

- `getThenRemove` 在 `finally` 中调用 `threadLocal.remove()`，保证无论取值是否成功都会移除，
  避免 ThreadLocal 值泄漏（线程池复用场景尤为重要）。

=== 2.2 默认值

- `getOrDefault` 基于 `ObjUtil.defaultIfNull(threadLocal.get(), ...)`：值为 null 时返回默认值。
- supplier 重载仅值为 null 时才调用 supplier（惰性）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| getThenRemove：值为 null | 返回 null（并移除，无副作用） |
| getOrDefault：值为 null | 返回默认值 / 经 supplier 获取 |
| getOrDefault(supplier)：值非 null | 不调用 supplier |

== 4. 适用范围

=== 4.1 适用场景

- 一次性读取 ThreadLocal 并立即清理，防止线程池场景下的值泄漏。
- 需要 ThreadLocal 缺省值语义。

=== 4.2 不适用/边界场景

- 需要保留 ThreadLocal 值跨多次读取时不适用 getThenRemove。

== 5. 已知限制与取舍

- getThenRemove 优先保证不泄漏，牺牲值的持久性。
