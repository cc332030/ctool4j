适用范围：按双类缓存值接口

== 1. 功能说明

`ICBiClassValue<T>` 为按双类缓存值接口，提供 `get(Class<?> type1, Class<?> type2)` 获取双类组合的缓存值。

== 2. 设计要点

=== 2.1 语义

- 按类型对（type1, type2）关联缓存值，实现类 `CBiClassValue` 基于嵌套 `CClassValue`。

== 4. 适用范围

=== 4.1 适用场景

- 需要按双类组合缓存计算结果的场景（实现类提供）。

=== 4.2 不适用/边界场景

- 本接口仅定义 get；需要设置值的能力用 `ICRefBiClassValue`。

== 5. 已知限制与取舍

- 作为双类缓存的抽象接口，统一取值语义。

说明：本接口由 `CBiClassValue` 实现并测试，无独立测试类。
