== 1. 功能说明

`CIntMsgResult<DATA>` 为结果封装，实现 `ICIntResult<DATA>` 与 `ICIntMsgResult<DATA>`，含 `code`/`msg`/`data`
字段，提供：

- `newInstance(code, message, data)`：构造
- `success()` / `success(data)`：成功结果（200）
- `error(message)` / `error(code, message)` 等：失败结果（默认 500）

== 2. 设计要点

=== 2.1 成功/失败工厂

- `success` 用 `HttpStatus.OK`（200）；`error(message)` 默认 500，message 为 null 用 500 原因短语。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| error message 为 null | 使用 500 原因短语 |

== 4. 适用范围

=== 4.1 适用场景

- 服务统一结果封装（code/msg/data）。

== 5. 已知限制与取舍

- 与 CResult 类似，msg 字段命名。

测试内容见 `doc/design/core/CIntMsgResultTests.adoc`。
