== 1. 功能说明

`CBusinessException` 为业务异常，继承 `CException`，携带错误码定义、附加信息与原因。

提供字段：

- `error`（ICRes 错误码定义）
- `msgExtend`（附加信息）

构造重载：

- `(ICRes error)`、`(ICRes error, Throwable cause)`、`(ICRes error, String msgExtend)`、
  `(ICRes error, String msgExtend, Throwable cause)`

== 2. 设计要点

=== 2.1 消息格式化

- 消息经 `CResUtils.formatResMessage(error, msgExtend)` 生成：`[code] msg`，msgExtend 非空追加
  `: msgExtend`。
- error 为 null 时返回 msgExtend。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| error 为 null | 消息仅含 msgExtend |
| msgExtend 为空 | 消息为 `[code] msg` |

== 4. 适用范围

=== 4.1 适用场景

- 业务校验/处理失败，携带错误码便于统一处理。

=== 4.2 不适用/边界场景

- error 为 null 时无法携带错误码，仅作普通消息异常。

== 5. 已知限制与取舍

- 统一经 CResUtils 格式化消息，保证错误码展示一致。

测试内容见 `doc/design/core/CBusinessExceptionTests.adoc`。
