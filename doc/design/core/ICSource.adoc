== 1. 功能说明

`ICSource` 为日志来源接口，继承 `ICText`，表示请求/日志的来源（如 MVC、Feign）。

== 4. 适用范围

=== 4.1 适用场景

- 日志来源枚举/类实现 `ICSource`，统一描述来源（`getText()`）。

=== 4.2 不适用/边界场景

- 为标记接口，无默认行为；具体来源由实现类定义。

== 5. 已知限制与取舍

- 通过继承 ICText 统一来源描述的文本语义。

说明：本类为纯标记接口，无独立测试类。
