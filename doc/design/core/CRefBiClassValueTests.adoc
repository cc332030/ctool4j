== 用例设计思路与依据

=== 设计思路

- 按「初始值 / 设置取值 / 组合独立」三个维度组织。
- 初始值验证 of 计算；设置取值验证 set 覆盖 get；组合独立验证不同组合互不影响。

=== 设计依据

- 依据功能设计对双类组合初始计算与 set 覆盖的约定。

=== 覆盖场景与未覆盖

- 覆盖：初始值；set 后 get 返回覆盖值；不同组合独立。
- 未覆盖：无（覆盖了核心语义）。

== 2. 设置与取值
