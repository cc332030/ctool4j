== 1. 功能说明

`CCountryCodeEnum` 为国家区号枚举，实现 `ICValue<Integer>`，当前含 CHN（86，中国），带 `value` 与 `text`。

== 4. 适用范围

=== 4.1 适用场景

- 国家区号的标准化枚举。

== 5. 已知限制与取舍

- 当前仅含中国，可扩展。
