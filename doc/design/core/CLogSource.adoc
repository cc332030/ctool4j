== 1. 功能说明

`CLogSource` 为日志来源枚举，实现 `ICSource`，定义日志来源标识：

- `MVC`（"mvc"）：服务端 MVC 接口收到的请求
- `FEIGN`（"feign"）：Feign 客户端发起的请求

提供 `getText()` 获取来源标识（日志最前面 `[source]` 前缀）。

== 2. 设计要点

=== 2.1 来源标识语义

- 每个来源对应一个文本标识，作为日志前缀区分请求来源（服务端接口 vs 客户端调用）。

== 4. 适用范围

=== 4.1 适用场景

- 请求日志的来源标记（MVC/Feign），统一 `[source]` 前缀。

=== 4.2 不适用/边界场景

- 仅两类来源；新增来源需扩展枚举。

== 5. 已知限制与取舍

- 标识为固定文本（mvc/feign），作为日志前缀约定。

说明：本类为纯枚举，无独立测试类。
