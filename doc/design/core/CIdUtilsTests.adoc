== 用例设计思路与依据

=== 设计思路

- 按「生成 / 前缀计算 / 前缀解析」三个维度组织：生成类验证 UUID/雪花 ID 的形态与唯一性，前缀计算验证类名前缀约定，前缀解析验证数字前字符的解析规则。
- UUID 形态断言长度与 '-' 有无，雪花 ID 断言为正数且两次不相等（验证递增）。
- 前缀计算以测试类自身（`CIdUtilsTests`）验证类名前缀规则（大写字母去 DO → `CIUT`）。
- 前缀解析覆盖含前缀、纯字母（无数字）、以数字开头、空、null 等分支。

=== 设计依据

- 依据功能设计对前缀计算规则（`@CBizId` 优先、类名大写去 DO、按类缓存）与解析规则（数字前字符）的约定。
- 依据测试方法（等价类/边界值/分支覆盖）：UUID 形态、前缀截取边界（length 超长）、解析各分支。
- 前缀截取覆盖"length 超前缀长度"边界。

=== 覆盖场景与未覆盖

- 覆盖：UUID v7 带/不带连字符形态（`UUID`/`simpleUUID`）、并发多线程下无重复（验证生成器缓存复用后仍线程安全）；雪花 ID 正数且递增；类前缀（含注解优先、类名大写去 DO）、前缀截取边界；
  带前缀雪花 ID（字符串/类/类+长度三种入口）；前缀解析（含前缀、纯字母、数字开头、空、null、转换函数）。
- 未覆盖：`@CBizId` 注解优先路径（测试类无注解，仅覆盖类名回退路径；注解路径依赖注解声明，未在单测中构造）。

== 1. UUID 生成

- 1.1 UUID：36 位且含 '-'，版本位为 7、variant 位为 8/9/a/b（UUID v7 格式特征）（UUID）
- 1.2 simpleUUID：32 位且不含 '-'（simpleUUID）
- 1.3 并发唯一性：8 线程 × 100 次并发生成，无重复且总数正确（UUID_concurrent_unique）

== 2. 雪花 ID 生成

- 2.1 nextId：正数且两次不相等（递增）（nextId）

== 3. 类 ID 前缀计算

- 3.1 getPrefix：类名大写去 DO（`CIdUtilsTests` → `CIUT`）（getPrefix）
- 3.2 getPrefix(Class, length)：截取 2 位 `CI`（getPrefixByLength）
- 3.3 边界：length 超前缀长度时返回完整前缀 `CIUT`（getPrefixByLength）

== 4. 带前缀雪花 ID

- 4.1 nextIdWithPrefix(String)：`P-` 前缀 + 正数雪花 ID（nextIdWithPrefix）
- 4.2 nextIdWithPrefix(Class)：类前缀 `CIUT` + 正数雪花 ID（nextIdWithPrefixByClass）
- 4.3 nextIdWithPrefix(Class, length)：截取前缀 `CI` + 正数雪花 ID（nextIdWithPrefixByClassAndLength）

== 5. 前缀解析

- 5.1 含前缀：`P-123` → `P-`（getPrefixFromId）
- 5.2 纯字母无数字：`ABC` → `ABC`（getPrefixFromId）
- 5.3 以数字开头无前缀：`123abc` → null（getPrefixFromId）
- 5.4 边界：空字符串 → null（getPrefixFromId）
- 5.5 边界：null → null（getPrefixFromId）
- 5.6 转换函数：`P-123` → `P-` / 长度 2（getPrefixFromIdWithFunction）
- 5.7 无前缀时不调用转换函数直接返回 null：`123` → null（getPrefixFromIdWithFunction）
