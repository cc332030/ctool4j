= CCharsets 设计文档

适用范围：项目全局统一字符集常量

== 1. 功能说明

`CCharsets` 为全局字符集常量类，提供：

- `UTF_8`：全局统一编码，值为 `StandardCharsets.UTF_8`

== 2. 设计要点

=== 2.1 统一编码约定

- 项目全局统一使用 UTF-8，避免各模块重复指定字符集或依赖平台默认字符集导致跨环境不一致。
- 常量直接引用 `StandardCharsets.UTF_8`，无冗余定义。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 需要字符集常量 | 统一引用 `CCharsets.UTF_8` |

== 4. 适用范围

=== 4.1 适用场景

- 各模块编解码、文件读写、网络传输需要指定字符集时统一使用。

=== 4.2 不适用/边界场景

- 仅提供 UTF-8 常量；其他字符集需求使用 JDK `StandardCharsets` 或显式指定。

== 5. 已知限制与取舍

- 作为纯常量类（@UtilityClass），仅承载全局统一编码约定，无运行时行为。

说明：本类为纯常量类，无独立测试类。
