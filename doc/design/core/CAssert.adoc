状态：已落地
适用范围：断言工具（条件/相等/null/空值校验，失败抛业务异常）

== 1. 功能说明

`CAssert` 为断言工具类，提供多种断言方法，条件不满足时抛业务异常：

- `isTrue`：条件为 true
- `equals`：两值相等（Objects.equals 语义）
- `isNull` / `notNull`：对象为 null / 非 null
- `notEmpty`：字符串/byte/int/long/Object 数组/Collection/Map 非空
- `notBlank`：字符串非空白

每个断言均有「String message」与「Supplier<String>」两个重载。

== 2. 设计要点

=== 2.1 断言失败语义

- 断言条件不满足时经 `CExceptionUtils.throwBusinessException` 抛 `CBusinessException`，携带指定错误信息。

=== 2.2 相等语义

- `equals` 基于 `Objects.equals`：两个 null 视为相等；null 与非 null 视为不相等。

=== 2.3 空值语义

- `notEmpty`（字符串）用 `StrUtil.isEmpty`（null 或空串视为空）。
- `notBlank` 用 `StrUtil.isBlank`（null、空串、纯空白视为空）。
- `notEmpty`（数组/集合/Map）分别用 `ArrayUtil.isEmpty` / `CollUtil.isEmpty` / `MapUtil.isEmpty`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 断言不满足 | 抛 CBusinessException（携带指定信息） |
| equals null/null | 视为相等，不抛异常 |
| notEmpty/notBlank 空值 | 抛 CBusinessException |

== 4. 适用范围

=== 4.1 适用场景

- 参数校验、前置条件断言，失败时抛出统一业务异常。

=== 4.2 不适用/边界场景

- 抛的是业务异常，非断言类异常（AssertionError）；需严格断言语义时用 JDK assert 或 AssertJ。

== 5. 已知限制与取舍

- 统一抛业务异常，与业务校验语义一致，调用方可按业务异常统一处理。
