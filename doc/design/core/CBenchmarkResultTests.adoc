= CBenchmarkResult 测试用例文档

Version: 1.0
LastModified: 2026-08-21
所属功能：`com.c332030.ctool4j.core.benchmark.CBenchmarkResult`（core benchmark 包）——基准执行结果，保存用例名、迭代次数与总耗时（纳秒），并提供平均耗时与每秒执行次数的指标计算。

对应测试类：`com.c332030.ctool4j.core.test.benchmark.CBenchmarkResultTests`

对应设计文档：`doc/design/core/CBenchmarkResult.adoc`（功能设计，测试内容以本文档为准）。

本文档为 CBenchmarkResult 的测试用例文档，含用例设计思路与依据、覆盖场景，以及测试用例的分类编号索引；测试方法在 javadoc 中标注对应编号（如 `对应测试用例 1.1`），文档与代码互相定位，便于检查覆盖是否有遗漏。

== 用例设计思路与依据

=== 设计思路

- 白盒分析：`avgNanos()` 为 `elapsedNanos * 1.0 / iterations`；`opsPerSecond()` 为
  `iterations * 1.0 / (elapsedNanos / 1_000_000_000.0)`。两者均为 double 运算，需覆盖
  正常值、小数结果、零边界与除零分支。
- 黑盒分析：入参为迭代次数与总耗时，出参为平均耗时（纳秒/次）与每秒执行次数；
  取值代表性覆盖典型值、1 次迭代、0 耗时、0 次迭代（除零）等。
- 错误推测法：double 除零在 Java 中返回 `Infinity`（不抛异常），需显式断言该行为；
  小数结果（如 elapsed=1、iterations=3）验证浮点精度不被截断。

=== 覆盖场景

- 覆盖：`avgNanos` 正例、iterations=1、elapsed=0、iterations=0（除零 → Infinity）、小数结果；
  `opsPerSecond` 正例、elapsed=0（除零 → Infinity）、半耗时；
  getter 对构造字段的原样返回。
- 未覆盖：超长耗时（纳秒溢出）等极端值（`CBenchmarkRunner` 实际传入的迭代次数固定，
  不构造此类输入）。

== 1. avgNanos()

- 1.1 正例：elapsedNanos=5000、iterations=1000 → 5.0
- 1.2 边界：iterations=1 → 返回 elapsedNanos 本身
- 1.3 边界：elapsedNanos=0 → 0.0
- 1.4 边界/除零：iterations=0 → 返回 Infinity（double 除零语义）
- 1.5 边界：elapsedNanos=1、iterations=3 → 约 0.333...（小数精度）

== 2. opsPerSecond()

- 2.1 正例：iterations=1000、elapsedNanos=1_000_000_000 → 1000.0
- 2.2 边界/除零：elapsedNanos=0 → 返回 Infinity（double 除零语义）
- 2.3 边界：iterations=1000、elapsedNanos=2_000_000_000 → 500.0

== 3. 字段取值（getter）

- 3.1 正例：构造后 `getName` / `getIterations` / `getElapsedNanos` 原样返回构造入参
