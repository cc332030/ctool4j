状态：已落地
适用范围：按双类缓存值（基于嵌套 CClassValue）

== 1. 功能说明

`CBiClassValue<T>` 为按双类缓存值实现，实现 `ICBiClassValue<T>`，提供：

- `of(CBiFunction<Class,Class,T>)`：创建，值函数按双类组合惰性计算
- `get(type1, type2)`：获取双类组合缓存值（首次计算并缓存）
- `remove(type1, type2)`：移除缓存值

== 2. 设计要点

=== 2.1 嵌套实现

- 基于 `CClassValue<CClassValue<T>>`：外层按 type1 缓存，内层按 type2 缓存，形成二维组合缓存。

=== 2.2 惰性计算与缓存

- 首次 get 计算并缓存；同一组合只计算一次；不同组合独立缓存。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 同一组合多次 get | 值函数只执行一次 |
| 不同组合 | 各自独立缓存 |

== 4. 适用范围

=== 4.1 适用场景

- 按双类组合缓存计算结果（如两个类间的映射元数据）。

=== 4.2 不适用/边界场景

- 需要运行期覆盖缓存值时用 `CRefBiClassValue`。

== 5. 已知限制与取舍

- 嵌套缓存实现，按组合去重，避免重复计算。

测试内容见 `doc/design/core/CBiClassValueTests.adoc`。
