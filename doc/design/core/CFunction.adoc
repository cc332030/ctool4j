= CFunction 设计文档

Version: 1.1
LastModified: 2026-09-03
模块：ctool4j-definition
类：com.c332030.ctool4j.definition.function.CFunction
状态：已落地
适用范围：可抛受检异常的函数接口（扩展 JDK Function）

== 1. 功能说明

`CFunction<O, R>` 为函数接口，扩展 `Function<O, R>`，支持 lambda 中抛受检异常：

- `apply`：默认方法，经 `@SneakyThrows` 包装受检异常后调用 `applyThrowable`
- `applyThrowable`：抽象方法，可抛 Throwable
- 工具：`SELF`/`self()`、`EMPTY`/`empty()`、`apply(function, o)`

== 2. 设计要点

=== 2.1 受检异常包装

- `apply` 内部用 `@SneakyThrows` 包装，调用方无法从签名感知受检异常，需自行处理实际异常（设计取舍）。

=== 2.2 工具方法

- `self()`：返回自身函数；`empty()`：恒返回 null。
- `apply(function, o)`：function 为 null 返回 null。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| apply(function, null) 且 function 为 null | 返回 null |
| empty() 恒返回 null | 恒返回 null |

== 4. 适用范围

=== 4.1 适用场景

- lambda 中需要抛受检异常的函数式处理。

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理，牺牲异常签名可见性。

测试内容见 `doc/design/core/CFunctionTests.adoc`。
