== 用例设计思路与依据

=== 设计思路

- 按「LinkedHashMap 收集（多个重载）/ 不可变语义 / 键冲突 / 有序 Set」多个维度组织。
- LinkedHashMap 各重载覆盖：仅键、键+冲突合并、键值、键值+冲突合并。
- 不可变语义通过 `assertThrowsExactly(UnsupportedOperationException, () -> map.put(...))` 精确断言。
- 键冲突分支覆盖默认抛 IllegalStateException 与显式合并函数两条路径。
- toLinkedSet 覆盖去重与保持插入顺序。

=== 设计依据

- 依据功能设计对不可变收集（add/put 抛 UnsupportedOperationException）与键冲突（默认抛 IllegalStateException、显式 merge）的约定。
- 依据测试方法（等价类/边界值/分支覆盖）：各重载正例、冲突分支、不可变断言、顺序保持。

=== 覆盖场景与未覆盖

- 覆盖：toUnmodifiableLinkedMap 四个重载正例、冲突默认抛异常、冲突 merge、不可变 put 抛异常；
  toLinkedSet 去重且保持顺序。
- 未覆盖：toUnmodifiableList、toUnmodifiableSet 的收集（本批测试类未单列，属可选扩展）。

== 1. LinkedHashMap 收集（toUnmodifiableLinkedMap）

- 1.1 仅键：`["a","b","c"]` 收集，键值即元素、保持顺序（toUnmodifiableLinkedMapWithKey）
- 1.2 键+冲突合并：`["a","b","a"]` 收集，重复键合并为 `"aa"`（toUnmodifiableLinkedMapWithKeyAndMerge）
- 1.3 键值：`["a","b"]` 收集，值为 `key.toUpperCase()`（toUnmodifiableLinkedMapWithKeyValue）
- 1.4 键值+冲突合并：`[1,2,3]` 收集，值为 `k*10`（toUnmodifiableLinkedMapWithKeyValueMerge）

== 2. 不可变语义

- 2.1 不可变：收集后 `put` 抛 UnsupportedOperationException（toUnmodifiableLinkedMapUnmodifiable）

== 3. 键冲突

- 3.1 默认冲突：重复键未提供 merge 抛 IllegalStateException（toUnmodifiableLinkedMapConflictKey）

== 4. 有序 Set（toLinkedSet）

- 4.1 去重且保持插入顺序：`["a","b","a","c"]` → `[a,b,c]`（toLinkedSet）
