= CPredicate 设计文档

Version: 1.1
LastModified: 2026-09-03
模块：ctool4j-definition
类：com.c332030.ctool4j.definition.function.CPredicate
状态：已落地
适用范围：可抛受检异常的断言接口（扩展 JDK Predicate）

== 1. 功能说明

`CPredicate<T>` 为断言接口，扩展 `Predicate<T>`，支持受检异常：

- `test`：默认方法，@SneakyThrows 包装后调用 `testThrowable`
- `testThrowable`：抽象方法，可抛 Throwable
- 工具：`alwaysTrue`/`alwaysFalse`、`test(predicate, t)`

== 2. 设计要点

=== 2.1 受检异常包装

- `test` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `alwaysTrue()`/`alwaysFalse()`：恒 true/false；`test(predicate, t)`：predicate 为 null 返回 false。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| test(predicate=null, t) | 返回 false |
| alwaysTrue() | 恒 true |
| alwaysFalse() | 恒 false |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。

测试内容见 `doc/design/core/CPredicateTests.adoc`。
