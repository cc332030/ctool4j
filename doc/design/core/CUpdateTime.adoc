== 1. 功能说明

`CUpdateTime` 为更新时间实体，继承 `CCreateTime` 并实现 `ICCreateUpdateTime`，在 createTime 基础上增加
`updateTime` 字段。

== 4. 适用范围

=== 4.1 适用场景

- 需要创建/更新时间的实体。

== 5. 已知限制与取舍

- updateTime 不可插入/更新（strategy NEVER）。

测试内容见 `doc/design/core/CUpdateTimeTests.adoc`。
