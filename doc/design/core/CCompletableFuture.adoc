= CCompletableFuture 设计文档

LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CCompletableFuture
状态：已落地
适用范围：异步执行任务，失败时记录日志但保留异常完成状态

== 1. 功能说明

`CCompletableFuture` 为异步任务工具类，提供：

- `runAsync(Runnable)`：异步执行任务；成功返回 `null` 结果，失败记录日志但 Future 保持异常完成状态。

== 2. 设计要点

=== 2.1 异常语义

- 底层 `CompletableFuture.runAsync(runnable)`，再经 `whenComplete` 仅在异常时记录错误日志。
- **不吞异常**：whenComplete 只记录日志，不改变 Future 的完成状态；任务异常时 Future 仍以
  异常完成，调用方 `get()/join()` 会抛 `ExecutionException`，可感知失败，避免误判成功。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 任务执行成功 | Future 正常完成，get() 返回 null |
| 任务抛异常 | 记录 error 日志，Future 异常完成，get() 抛 ExecutionException |

== 4. 适用范围

=== 4.1 适用场景

- 需要异步执行任务，且需要失败日志记录，同时不丢失失败语义的场景。

=== 4.2 不适用/边界场景

- 仅支持 `runAsync`（无返回值），需要异步结果时需配合外部状态（如 Atomic 变量）。
- 不提供拒绝策略/线程池定制（复用 JDK 默认公共 ForkJoinPool）。

== 5. 已知限制与取舍

- 保留异常完成状态（而非吞掉）是本类核心取舍，保证调用方能感知失败。
- 使用默认线程池，无自定义 executor 重载；高并发需自行管理线程池时用原生 CompletableFuture。

测试内容见 `doc/design/core/CCompletableFutureTests.adoc`。
