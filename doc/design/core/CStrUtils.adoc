== 1. 功能说明

`CStrUtils` 为字符串工具类，提供丰富的字符串操作：

- 常量：`NULL`/`UNDEFINED`、引号、分隔符、`NOT_AVAILABLE_*`、`UTF8_BOM`
- 格式化：`format`（占位符 ${}）/`formatLookup`/`formatByObject`/`formatNullToEmpty`
- 命名转换：`upperUnderscoreToHeaderName`/`upperUnderscoreToLowerCamel`/`upperCamelToUpperUnderscore` 等
- 切割：`splitToList`/`splitToSet`/`splitToIntegerList`/`splitToMap`/`splitThenGetFirst` 等
- 连接：`concat`/`join`
- 可用性：`isAvailable`/`toAvailable`/`convertAvailable`
- 其他：`incrLastNum`/`repeat`/`fillAfter`/`fillSide`/`generateRandomString`/`getPrintWidth`/`chineseOnly`

== 2. 设计要点

=== 2.1 格式化

- `format(template, params)`：替换 `${key}` 占位符；缺失参数经 `defaultValue`（如 `formatNullToEmpty`
  用空串）兜底。

=== 2.2 可用性处理（toAvailable）

- trim 后为空返回 null；命中 `NOT_AVAILABLE_STRINGS`（null/undefined 等）返回 null。
- 删除前后 `NOT_AVAILABLE_CHARACTERS`（引号等）字符；`start == end` 时保留该非引号字符
  （Q16 修复），仅当前后引号完全覆盖（start > end）时视为无可用内容返回 null。

=== 2.3 自增与中文提取

- `incrLastNum`：对 `前缀-数字` 形式的末尾数字自增；无 `-` 或非数字末尾原样返回，解析失败记录日志。
- `chineseOnly`：用正则 `[^\u4e00-\u9fa5]` 移除所有非中文字符，提取纯中文。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| toAvailable trim 后为空 / 命中 NOT_AVAILABLE_STRINGS | 返回 null |
| toAvailable 前后引号完全覆盖（start > end） | 返回 null |
| incrLastNum 无 `-` / 末尾非数字 / 解析失败 | 原样返回 |
| format 缺失参数 | 使用 defaultValue 兜底 |

== 4. 适用范围

=== 4.1 适用场景

- 模板格式化、命名风格转换、字符串切割/连接、可用性清洗、末尾数字自增、中文提取等。

=== 4.2 不适用/边界场景

- toAvailable 基于引号/关键字清洗，复杂清洗规则需自行实现。
- chineseOnly 仅保留 CJK 统一表意文字（\u4e00-\u9fa5），标点/扩展汉字被移除。

== 5. 已知限制与取舍

- 可用性清洗为启发式规则（引号/关键字），覆盖常见脏数据。
- 自增仅支持 `前缀-数字` 形态，其他形态原样返回。
