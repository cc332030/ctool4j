== 1. 功能说明

`CBusinessExceptionProvider` 为默认业务异常提供者，实现 `ICBusinessExceptionProvider<CBusinessException>`。

提供：

- `getExceptionFunction()`：返回创建业务异常的函数，即 `CBusinessException::new` 引用
  （error/msgExtend/cause 三元构造）。

== 2. 设计要点

=== 2.1 默认实现

- `getExceptionFunction()` 直接返回 `CBusinessException::new`，作为默认业务异常创建逻辑。
- 作为 SPI 自定义实现的默认回退。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无自定义 SPI 实现 | 使用本提供者创建 CBusinessException |

== 4. 适用范围

=== 4.1 适用场景

- 项目默认业务异常创建，经 SPI 加载。

=== 4.2 不适用/边界场景

- 需要自定义异常类型时，通过 SPI 提供自定义 `ICBusinessExceptionProvider`。

== 5. 已知限制与取舍

- 作为默认实现，保证无 SPI 配置时业务异常可用。

测试内容见 `doc/design/core/CBusinessExceptionProviderTests.adoc`。
