== 1. 功能说明

`CLongId` 为 Long 类型 ID 实体，继承 `CId<Long>` 并实现 `ICLongId`，固定主键为 Long 类型。

=== 4.1 适用场景

- 主键为 Long 的实体基类。

== 5. 已知限制与取舍
