= CEnumUtils 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CEnumUtils
状态：已落地
适用范围：枚举按名/值/指定字段取值的 Map 构建、枚举值反查、枚举值列表获取

== 1. 功能说明

`CEnumUtils` 为枚举工具类，提供：

- `getNameMap`：枚举名（`name()`）到枚举的 Map
- `getMap`：枚举值（实现 `ICValue`）或指定字段值到枚举的 Map
- `valueOf(map, value)` / `nameOf` / `valueOf(Class, ...)`：从 Map 或枚举类反查枚举（不存在抛异常）
- `values`：获取枚举所有值（不可变列表）

== 2. 设计要点

=== 2.1 枚举值列表缓存（ENUM_VALUES）

- 基于 `ClassValue` 按枚举类缓存所有枚举值的不可变列表（`Collections.unmodifiableList`），
  线程安全、按类弱关联，避免重复 `getEnumConstants`。

=== 2.2 字段值 Map 缓存（VALUE_ENUM_MAP_CLASS_MAP）

- 按枚举类缓存"字段名 → 值 Map"的并发容器；字段值 Map 首次构建后以 `ConcurrentHashMap` 存入，
  避免重复反射遍历。
- 构建规则：`ICName.NAME` 特殊处理（用 `Enum.name()`）；否则按指定字段反射取值，字段值非 null
  才放入 Map（null 值枚举不建立反查项）。
- 加锁采用 `synchronized (enumClass)` 双重检查，保证单例构建。

=== 2.3 反查语义

- `valueOf(map, value)`：`Optional.ofNullable(map.get(value)).orElseThrow(IllegalArgumentException)`，
  值不存在抛 `IllegalArgumentException`。
- `nameOf(Class, name)` / `valueOf(Class, ...)`：先取对应 Map 再反查，异常语义同上。

=== 2.4 前置校验

- `getMap(Class, String)` 校验 `enumClass.isEnum()`，非枚举抛 `IllegalArgumentException`。
- 指定字段名不存在时反射抛 `NoSuchFieldException`（经 `@SneakyThrows` 上抛）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 反查值不存在 | 抛 IllegalArgumentException（"no enum with value: ..."） |
| 非枚举类 | getMap 抛 IllegalArgumentException（"not enum"） |
| 字段不存在 | 反射抛 NoSuchFieldException |
| 字段值为 null 的枚举 | 不建立该值反查项（getMap 构建时过滤） |

== 4. 适用范围

=== 4.1 适用场景

- 按枚举名、枚举值（`ICValue`）、自定义字段值反查枚举。
- 需要枚举所有值的不可变列表。

=== 4.2 不适用/边界场景

- 字段值为 null 的枚举不参与反查 Map（无法用 null 作 Map key 稳定反查）。
- 反查基于 Map 精确匹配，大小写敏感。

== 5. 已知限制与取舍

- 字段值 Map 缓存无失效机制：枚举字段值静态不可变，风险低。
- `valueOf` 对不存在值抛异常而非返回 null，保证调用方明确感知查找失败。
