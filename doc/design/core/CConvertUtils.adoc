状态：已落地
适用范围：类型转换器注册与对象类型转换（基于 CClassConvert 默认转换器）

== 1. 功能说明

`CConvertUtils` 为类型转换工具类，提供：

- 注册：`addConverter(Method)` / `addConverter(fromClass, toClass, converter)`
- 查询：`getConverter` / `getConverterNoObjectFallback`
- 转换：`convert` / `convertOpt`

默认注册 `CClassConvert` 的静态方法为转换器。

== 2. 设计要点

=== 2.1 默认转换器注册

- 静态初始化经 `CReflectUtils.getAllMethodsCached(CClassConvert.class)` 收集静态方法并注册为转换器
  （入参为源类型，返回值为目标类型）。
- 无入参方法无法确定源类型，跳过注册（Q16，避免 getParameterTypes()[0] 越界）。

=== 2.2 转换器查找（findConverter）

- 源为 Collection/Map/数组时直接返回 null（不转换）。
- `ClassUtil.isAssignable(toClass, fromClass)`（含基本类型/包装等价）时返回 `CFunction.SELF`。
- 遍历已注册转换器，源/目标类型匹配即命中；Object 源兜底转换器（Object→String）优先级最低，
  仅在无更精确转换器时命中，避免抢占 Date→String 等特殊转换。

=== 2.3 转换语义

- `convert(from, toClass)`：null 返回 null；无转换器返回 null；否则应用转换器。
- `convertOpt`：Opt 包装转换结果。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| convert null 入参 | 返回 null |
| 无可用转换器（含 Collection/Map/数组源） | 返回 null |
| 无入参方法注册 | 跳过注册并告警 |

== 4. 适用范围

=== 4.1 适用场景

- 类型间转换（字符串/数值/日期等），支持注册自定义转换器。

=== 4.2 不适用/边界场景

- 无匹配转换器返回 null，调用方需判空；Collection/Map/数组源不支持。

== 5. 已知限制与取舍

- 基于 CClassConvert 默认转换器 + 自定义注册，扩展灵活。
- Object 源兜底优先级最低，避免抢占特殊转换（核心取舍）。
