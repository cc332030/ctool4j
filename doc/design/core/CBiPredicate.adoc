适用范围：可抛受检异常的双参断言接口（扩展 JDK BiPredicate）

== 1. 功能说明

`CBiPredicate<T, U>` 为双参断言接口，扩展 `BiPredicate`，支持受检异常：

- `test`：默认方法，@SneakyThrows 包装后调用 `testThrowable`
- `testThrowable`：抽象方法，可抛 Throwable
- 工具：`alwaysTrue`/`alwaysFalse`、`test(predicate, t, u)`、`convert(predicate)`

== 2. 设计要点

=== 2.1 受检异常包装

- `test` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `alwaysTrue()`/`alwaysFalse()`：恒 true/false；`test(predicate, t, u)`：predicate 为 null 返回 false；
  `convert`：转 JDK BiPredicate。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| test(predicate=null, t, u) | 返回 false |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。

测试内容见 `doc/design/core/CBiPredicateTests.adoc`。
