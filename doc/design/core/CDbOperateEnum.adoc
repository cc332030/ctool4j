== 1. 功能说明

`CDbOperateEnum` 为数据库操作枚举，实现 `ICOperate`，定义四种操作（INSERT/SELECT/UPDATE/DELETE），
各带中文描述 `text`，提供 `getText()` 与 `getName()`。

=== 4.1 适用场景
