LastModified: 2026-08-21
模块：ctool4j-core

状态：已落地
适用范围：环境（Profile）枚举（含按名获取、生产环境集合）

== 1. 功能说明

`CProfileEnum` 为环境枚举，定义 6 种环境（DEFAULT/LOCAL/DEV/TEST/UAT/PROD），每种带中文描述。

提供：

- `getText()`：环境描述
- `of(name)`：按环境名获取枚举（忽略大小写，未知名抛 IllegalArgumentException）
- `PROD_PROFILES`：生产环境集合（仅 PROD）
- `PROFILE_MAP`：环境名到枚举的忽略大小写 Map

== 2. 设计要点

=== 2.1 按名获取（of）

- 基于 `PROFILE_MAP`（`TreeMap(String.CASE_INSENSITIVE_ORDER)` 忽略大小写）反查。
- name 为 null 抛 IllegalArgumentException；未知名抛 `IllegalArgumentException("unknown profile: ...")`。

=== 2.2 生产环境集合

- `PROD_PROFILES` 为不可变 `EnumSet.of(PROD)`，仅含生产环境。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| of(null) | 抛 IllegalArgumentException |
| of(未知名) | 抛 IllegalArgumentException |
| 判断是否生产环境 | 用 `PROD_PROFILES.contains` |

== 4. 适用范围

=== 4.1 适用场景

- Spring Profile / 部署环境统一枚举，按环境名解析、生产环境判断。

=== 4.2 不适用/边界场景

- of 依赖精确匹配（忽略大小写），未知名抛异常而非返回 null。

== 5. 已知限制与取舍

- 未知环境名显式抛异常，保证调用方明确感知解析失败。
- PROFILE_MAP 忽略大小写，兼容 `DEV`/`dev` 等写法。

测试内容见 `doc/design/core/CProfileEnumTests.adoc`。
