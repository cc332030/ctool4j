= CClassValue 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.cache.impl.CClassValue
状态：已落地
适用范围：按类缓存值（基于 java.lang.ClassValue）

== 1. 功能说明

`CClassValue<T>` 为按类缓存值实现，实现 `ICClassValue<T>`，提供：

- `of(CFunction<Class<?>,T>)`：创建，值函数按类惰性计算
- `get(Class<?>)`：获取指定类缓存值（首次经值函数计算并缓存）
- `remove(Class<?>)`：移除缓存值，下次 get 重新计算

== 2. 设计要点

=== 2.1 基于 ClassValue

- 内部委托 `java.lang.ClassValue`：线程安全、按类弱关联（类可被 GC），`computeValue` 经值函数计算。

=== 2.2 惰性计算与缓存

- 首次 get 经 `computeValue` 计算并缓存，后续 get 直接返回缓存值（同一类只计算一次）。
- 不同类各自独立计算缓存。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 同一类多次 get | 值函数只执行一次（缓存） |
| remove 后 get | 重新计算 |

== 4. 适用范围

=== 4.1 适用场景

- 按类缓存计算结果（如反射元数据、类相关配置），避免重复计算。

=== 4.2 不适用/边界场景

- 需要运行期覆盖缓存值时用 `CRefClassValue`。

== 5. 已知限制与取舍

- 基于 ClassValue 弱关联，类卸载时缓存自动释放，无内存泄漏。

测试内容见 `doc/design/core/CClassValueTests.adoc`。
