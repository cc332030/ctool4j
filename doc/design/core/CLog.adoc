= CLog 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.log.CLog
状态：已落地
适用范围：SLF4J 日志封装（trace/debug/info/warn/error，参数延迟求值）

== 1. 功能说明

`CLog` 为 SLF4J 日志封装类，提供：

- 构造：按名称（`new CLog("name")`）或按类（`new CLog(Class)`）
- 级别判断：`isTraceEnabled` / `isDebugEnabled` / `isInfoEnabled` / `isWarnEnabled` / `isErrorEnabled`
- 打印：trace/debug/info/warn/error 各级别，支持 msg、msg+throwable、msg+args、msg+Supplier 延迟求值

== 2. 设计要点

=== 2.1 参数处理

- `msg, Object... args`：先经 `CLogUtils.toLogArgs(args)` 将可 JSON 化参数转为 JSON 字符串，再打印。
- `msg, Supplier... args`：先判断级别是否启用，启用才求值参数（延迟求值），避免无用参数开销。

=== 2.2 延迟求值

- Supplier 重载在级别未启用时不调用 supplier，减少无谓的参数构造开销。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 级别未启用 | isXxxEnabled 返回 false，Supplier 参数不求值 |
| 带 throwable | 直接打印日志与堆栈 |

== 4. 适用范围

=== 4.1 适用场景

- 需要统一参数 JSON 化、支持延迟求值的日志场景。

=== 4.2 不适用/边界场景

- 依赖 CLogUtils 的参数转换规则（可 JSON 化类型）。

== 5. 已知限制与取舍

- 统一经 CLogUtils 转换参数，保证日志格式一致；延迟求值提升性能。

测试内容见 `doc/design/core/CLogTests.adoc`。
