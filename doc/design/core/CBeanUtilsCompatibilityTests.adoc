== 用例设计思路与依据

=== 设计思路

- 功能完整性测试（兼容性）：围绕 CBeanUtils 在重构/优化前后的行为一致性设计用例，验证各复制/转 Map/实例化能力在不同输入形态下行为稳定：
  - 5.1 复制兼容性：对象复制（完整字段、基本类型字段、JDK 源、null 源、Map、Entry、数组、列表）、Supplier 经 Map 一致性
  - 5.2 转 Map 兼容性：基础、命名、JDK/null
  - 5.3 实例化兼容性：newInstance
- 覆盖正常路径与边界（null、JDK 类源）。
