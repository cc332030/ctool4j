适用范围：「可变实例 + 不可变视图」容器契约

== 1. 功能说明

`ICView` 为「可变实例 + 不可变视图」容器的公共契约，定义：

- `getMutable`：获取可变实例，供写操作。
- `getImmutable`：获取不可变视图，供读操作，零构建。

各实现类（`CMapView` / `CListView` / `CSetView`）成对创建可变实例与不可变视图，
视图为可变实例的实时视图（live view），底层修改实时反映。

== 2. 设计要点

=== 2.1 契约语义

- 可变实例与不可变视图成对提供；写方改可变实例，读方读不可变视图。
- 视图为实时视图（非快照），底层修改实时反映，无需每次重建。

=== 2.2 实现类

| 实现类 | 可变实例默认 | 不可变视图 |
|--------|-------------|-----------|
| `CMapView` | `HashMap` | `unmodifiableMap` |
| `CListView` | `ArrayList` | `unmodifiableList` |
| `CSetView` | `HashSet` | `unmodifiableSet` |

默认均非线程安全；线程安全场景由调用方显式传入线程安全的集合实现。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无参构造 | 可变实例默认为对应集合的普通实现（HashMap/ArrayList/HashSet） |

== 4. 适用范围

=== 4.1 适用场景

- 需要「内部可变 + 外部只读视图」的集合持有场景（如 MDC 上下文、配置缓存）。

=== 4.2 不适用/边界场景

- 不可变视图为实时视图（非快照），若需「固定快照」应另用副本构造。

== 5. 已知限制与取舍

- 不可变视图为只读视图（非快照），底层可变实例被修改后视图内容随之变化。
- 默认非线程安全；线程安全由调用方按需传入具体实现。
