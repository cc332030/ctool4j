== 用例设计思路与依据

=== 设计思路

- 白盒原则：围绕 CBeanUtils 对象复制/转 Map/类型转换的核心能力，按"复制来源形态、复制边界、列表、转 Map、类型转换"维度组织分类：
  - 1.x 对象复制：1.1 对象→对象、1.2 Map→对象、1.3 边界（null、JDK 类）
  - 2.x 列表/数组复制
  - 3.x 转 Map（基础/下划线/JSON 名/冲突/空/null/含 final/JDK 类）
  - 4.x 类型转换（包装↔基本、数字/字符串/日期/BigDecimal/枚举/数值互转）
- 覆盖正常路径、边界（null、空集合、final 字段）与类型转换分支。
