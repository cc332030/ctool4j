== 用例设计思路与依据

=== 设计思路

- 按「写入/空兜底 / 创建 / 映射 / 过滤 / 合并 / 其他」多个维度组织。
- 空入参统一覆盖（put 任一 null 不写入、defaultEmpty 空返回空、map/filter/merge 空返回空）。
- 映射覆盖键/值/键值转换、null key/value/转换结果 null 过滤。
- 合并覆盖冲突默认取第一、自定义 merge、null value 过滤、不可变。
- 创建覆盖普通类型 LinkedHashMap、枚举 EnumMap、忽略大小写 TreeMap、非枚举抛异常。

=== 设计依据

- 依据功能设计对空值语义、null 过滤、合并冲突、创建类型的约定。
- 依据测试方法（等价类/边界值/异常路径/分支覆盖）：null 入参、空集合、冲突、类型、不可变断言。

=== 覆盖场景与未覆盖

- 覆盖：put（正常/null 各入参）；defaultEmpty（null/空/原引用）；toStringValueMap（null/normal/null 值）；
  newMap（null 抛异常/普通 LinkedHashMap/枚举 EnumMap）；newEnumMap（枚举/非枚举抛异常）；
  newIgnoreCaseMap（大小写）；map（mapKey/mapValue/map、空 map、null key/value、转换 null）；
  filter（filter/filterKey/filterValue、空 map）；merge（空数组/合并/冲突取第一/自定义 merge/null value/
  不可变）；toAvailableStrMap（trim/关键字过滤/null value）；computeIfAbsent（已有值/无值/mappingFunction）。
- 未覆盖：`compare`（打印差异表格，依赖日志输出，单测未直接断言表格内容）。

== 1. 写入与空兜底

- 1.1 put：正常写入；map/key/value 任一 null 不写入（put）
- 1.2 defaultEmpty：null/空返回空 map、非空返回原引用（defaultEmpty）
- 1.3 toStringValueMap：null 返回 null；值转 String、null 值保持 null（toStringValueMap）

== 2. Map 创建

- 2.1 newMap：null object 抛异常；普通类型 LinkedHashMap；枚举 EnumMap（newMap）
- 2.2 newEnumMap：枚举 EnumMap；非枚举抛 IllegalArgumentException（newEnumMap）
- 2.3 newIgnoreCaseMap：TreeMap 且忽略大小写（newIgnoreCaseMap）

== 3. 键值映射（map / mapKey / mapValue）

- 3.1 mapKey/mapValue/map 正例；空 map 返回空；null key/value、转换结果 null 被过滤（map）

== 4. 过滤（filter / filterKey / filterValue）

- 4.1 空 map 返回空；filter/filterKey/filterValue 正例（filter）

== 5. 合并（merge）

- 5.1 空数组返回空；多 map 合并；冲突默认取第一；自定义 merge；null value 过滤；返回不可变（merge）

== 6. 其他

- 6.1 toAvailableStrMap：trim 后保留、`null`/`undefined` 关键字与 null value 过滤（toAvailableStrMap）
- 6.2 computeIfAbsent：已有值直接返回、无值计算写入、mappingFunction 版本（computeIfAbsent）
