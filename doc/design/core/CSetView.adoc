LastModified: 2026-08-31
模块：ctool4j-core

状态：已落地
适用范围：同时持有「可变 Set」与「不可变视图」的容器

== 1. 功能说明

`CSetView` 为「可变 Set + 不可变视图」双实例容器，实现 `ICView<Set<E>>`：

- `getMutable`：获取可变实例，供写操作。
- `getImmutable`：获取不可变视图（`Collections.unmodifiableSet(可变实例)`），供读操作，零构建。

== 2. 设计要点

=== 2.1 双实例

- 构造时同时创建可变实例与不可变视图，视图包装可变实例（非快照）。
- 写方直接改可变实例，读方直接返回视图，避免频繁构建不可变副本。

=== 2.2 构建

- `of()`：默认可变实例为 `HashSet`（非线程安全）。
- `of(Set)`：指定可变 Set，供调用方自定义容器类型。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无参构造 | 可变实例默认为 HashSet |

== 4. 适用范围

=== 4.1 适用场景

- 需要「内部可变 + 外部只读视图」的 Set 持有场景。

=== 4.2 不适用/边界场景

- 不可变视图为实时视图（非快照），若需「固定快照」应另用副本构造。

== 5. 已知限制与取舍

- 不可变视图为只读视图（非快照），底层可变实例被修改后视图内容随之变化。
- 默认非线程安全；线程安全由调用方按需传入具体实现。

测试内容见 `doc/design/core/CSetViewTests.adoc`。
