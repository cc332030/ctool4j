== 性能测试设计思路

=== 对比维度

- 对象复制（copy），对比多类实现方式（满足对比类别 ≥3 类）：
  - CBeanUtilsCopyCase：当前 copy 实现
  - CBeanUtilsCopyOldPathCase：旧路径实现
  - CBeanUtilsCopyReuseTargetCase：复用目标对象实现

=== 执行方式

- 性能测试独立于单元测试，仅在明确命令执行时才运行（显式运行）。
- 排除初始化干扰：测试两次，第二次在全部实现方式初始化完成后进行。
- 结果写入报告，分析性能差异原因并给出方案。
