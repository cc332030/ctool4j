== 1. 功能说明

`ICClassValue<T>` 为按类缓存值接口，提供 `get(Class<?>)` 获取指定类的缓存值。

== 2. 设计要点

=== 2.1 语义

- 按类型关联缓存值，实现类 `CClassValue` 基于 `java.lang.ClassValue`（线程安全、按类弱关联）。

== 4. 适用范围

=== 4.1 适用场景

- 需要按类缓存计算结果的场景（实现类提供）。

=== 4.2 不适用/边界场景

- 本接口仅定义 get；需要设置值的能力用 `ICRefClassValue`。

== 5. 已知限制与取舍

- 作为按类缓存的抽象接口，统一取值语义。

说明：本接口由 `CClassValue` 实现并测试，无独立测试类。
