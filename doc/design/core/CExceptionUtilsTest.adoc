=== 设计思路

- 白盒原则：围绕 `newBusinessException`（创建业务异常）与 `getMessageWithCause`（获取异常链信息）设计用例：
  - `newBusinessException`：返回 `CBusinessException` 类型
  - `getMessageWithCause`：异常为 null 返回 null；含 cause 时拼接展示
- 边界：覆盖异常为 null 的边界场景。
