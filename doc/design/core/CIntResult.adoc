适用范围：Integer 状态码结果封装（code/message/data，实现 ICIntResult）

== 1. 功能说明

`CIntResult<DATA>` 为结果封装，实现 `ICIntResult<DATA>`，含 `code`/`message`/`data` 字段，提供：

- `newInstance(code, message, data)`：构造
- `success()` / `success(httpStatus, data)` / `success(data)`：成功结果
- `error(message)` / `error(code, message)` / `error(httpStatus, message)` 等：失败结果

== 2. 设计要点

=== 2.1 成功/失败工厂

- `success` 用 `HttpStatus.OK`（200），可指定状态与数据。
- `error(message)` 默认 500，message 为 null 用 500 原因短语；支持自定义 code/HttpStatus。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| error message 为 null | 使用 500 原因短语 |

== 4. 适用范围

=== 4.1 适用场景

- 服务统一结果封装（Integer 状态码）。

== 5. 已知限制与取舍

- 与 CResult 类似，但用 message 字段命名。

测试内容见 `doc/design/core/CIntResultTests.adoc`。
