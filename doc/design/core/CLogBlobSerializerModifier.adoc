适用范围：长文本字段检测修改器（@CLogBlob 字段日志输出占位符）

== 1. 功能说明

`CLogBlobSerializerModifier` 为长文本字段序列化修改器，继承 `CLogFieldSerializerModifier<CLogBlob>`，
检测标注 `@CLogBlob` 的字段，日志序列化时替换为固定占位符 `<BLOB>`。

- 仅注册到日志专用 ObjectMapper；全局 mapper 输出真实内容。

== 2. 设计要点

=== 2.1 序列化器创建

- `createSerializer` 返回 `CLogBlobSerializer.INSTANCE`，忽略注解参数，固定输出 `<BLOB>`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 日志 mapper 序列化 @CLogBlob 字段 | 输出 `<BLOB>` 占位符 |
| 全局 mapper 序列化 @CLogBlob 字段 | 输出真实内容 |

== 4. 适用范围

=== 4.1 适用场景

- 长文本字段日志打印脱敏。

== 5. 已知限制与取舍

- 仅日志 mapper 生效，业务输出真实内容（占位符仅用于日志）。

测试内容见 `doc/design/core/CLogBlobSerializerModifierTests.adoc`。
