= CMap 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CMap
状态：已落地
适用范围：构造空/单/双/三键值 Map、复制 Map（不可变）

== 1. 功能说明

`CMap` 为 Map 构造工具类，提供：

- `of()`：空 Map
- `of(K,V)`：单键值 Map
- `of(K,V,K,V)` / `of(K,V,K,V,K,V)`：双/三键值不可变 Map
- `of(Map)` / `of(Map, CSupplier)`：复制 Map 为不可变新 Map（可指定容器类型）

== 2. 设计要点

=== 2.1 不可变语义

- 单键值 `of` 用 `Collections.singletonMap`（不可变）。
- 双/三键值用 `HashMap.put` 后包 `Collections.unmodifiableMap`。
- `of(Map, supplier)`：原 Map 为空（MapUtil.isEmpty）返回空 Map；否则经 supplier 创建新容器
  `putAll` 后包不可变，不修改原 Map。

=== 2.2 容器类型

- `of(Map)` 默认复制为 `LinkedHashMap`（有序）；`of(Map, supplier)` 由调用方指定容器类型。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| of() 空参 | 返回空 Map |
| of(Map) 原 Map 为空/null | 返回空 Map |
| of(Map) 复制结果被修改 | 抛 UnsupportedOperationException（不可变） |

== 4. 适用范围

=== 4.1 适用场景

- 需要不可变 Map、且自动判空的 Map 构造。

=== 4.2 不适用/边界场景

- 返回不可变 Map，需要后续增删时用原生 `new HashMap`。

== 5. 已知限制与取舍

- 自动判空并返回不可变副本，牺牲可修改性换取安全的 Map 构造。

测试内容见 `doc/design/core/CMapTests.adoc`。
