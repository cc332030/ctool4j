= CSet 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-core
类：com.c332030.ctool4j.core.util.CSet
状态：已落地
适用范围：构造空/元素 Set（过滤 null），枚举 Set

== 1. 功能说明

`CSet` 为 Set 构造工具类，提供：

- `of()`：空 Set
- `of(T... ts)`：构造不可变 Set，过滤 null 元素
- `of(T... ts)`（枚举重载）：构造不可变枚举 Set，过滤 null 元素

== 2. 设计要点

=== 2.1 语义约定

- 元素重载过滤 null 元素；全部为 null/空参时返回空 Set（`Collections.emptySet()`）。
- 返回不可变 Set（`Collections.unmodifiableSet`），调用方 add 抛 UnsupportedOperationException。
- 枚举重载基于 `EnumSet.copyOf` 构造（去重、枚举特性），同样不可变。

=== 2.2 实现方式

- 元素重载先经 `CArrUtils.filterNull(ts)` 去空，`ArrayUtil.isEmpty` 时空返回空 Set，否则
  `HashSet.addAll` 后包 `Collections.unmodifiableSet`。
- 枚举重载经 filterNull 后 `EnumSet.copyOf`，再包不可变。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| of() 空参 | 返回空 Set |
| of(T...) 全部为 null / 空参 | 返回空 Set |
| of(T...) 含 null 元素 | 过滤 null，保留非空元素 |
| 返回 Set 被修改 | 抛 UnsupportedOperationException |

== 4. 适用范围

=== 4.1 适用场景

- 需要不可变 Set、且自动过滤 null 元素的集合构造。

=== 4.2 不适用/边界场景

- 返回不可变 Set，需要后续增删时用原生 `new HashSet`。
- 普通元素重载基于 HashSet，不保证顺序；需顺序用 LinkedHashSet 自行构造。

== 5. 已知限制与取舍

- 自动过滤 null，牺牲"保留 null"能力换取安全的集合构造。
