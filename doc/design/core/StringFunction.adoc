适用范围：字符串入参函数接口（扩展 CFunction<String, T>）

== 1. 功能说明

`StringFunction<T>` 为字符串入参函数接口，扩展 `CFunction<String, T>`，固定入参为 String。

== 2. 设计要点

=== 2.1 语义

- 继承 CFunction 的受检异常包装与工具方法，固定入参类型为 String，便于类型约束。

== 4. 适用范围

=== 4.1 适用场景

- 入参为字符串的函数式处理（如解析、格式转换）。

== 5. 已知限制与取舍

- 仅为 CFunction<String, T> 的类型别名，无额外行为。

测试内容见 `doc/design/core/StringFunctionTests.adoc`。
