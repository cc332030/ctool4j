== 用例设计思路与依据

=== 设计思路

- 按「函数创建异常 / 扩展信息为 null」两个分支组织。
- 用 CBusinessExceptionTestsRes（ICRes）提供 code/msg，验证函数创建的异常消息与字段。

=== 设计依据

- 依据功能设计对 getExceptionFunction 返回 CBusinessException::new 的约定。

=== 覆盖场景与未覆盖

- 覆盖：getExceptionFunction 非空且创建异常正确；扩展信息 null 时消息为 `[code] msg`。
- 未覆盖：无（覆盖了函数调用与 null 扩展分支）。

== 1. 创建异常函数

- 1.1 getExceptionFunction：创建 `[100] boom: detail` 异常，cause 与 msgExtend 正确（getExceptionFunction）
- 1.2 null 扩展：msgExtend null 时消息为 `[100] boom`（getExceptionFunction_nullExtend）
