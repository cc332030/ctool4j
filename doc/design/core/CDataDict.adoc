== 1. 功能说明

`CDataDict<T>` 为数据字典，实现 `ICDataDict<T>`，含 `value` 与 `text` 字段。

标注 `@Data`/`@SuperBuilder`/`@NoArgsConstructor`/`@AllArgsConstructor`。

=== 4.1 适用场景

- 数据字典项（值 + 展示文本）。
