适用范围：可抛受检异常的双参函数接口（扩展 JDK BiFunction）

== 1. 功能说明

`CBiFunction<O1, O2, R>` 为双参函数接口，扩展 `BiFunction`，支持受检异常：

- `apply`：默认方法，@SneakyThrows 包装后调用 `applyThrowable`
- `applyThrowable`：抽象方法，可抛 Throwable
- 工具：`apply(function, o1, o2)`、`convert(function)`、`first()`/`second()`

== 2. 设计要点

=== 2.1 受检异常包装

- `apply` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `apply(function, o1, o2)`：function 为 null 返回 null；`convert`：转 JDK BiFunction。
- `first()`/`second()`：分别返回取第一/第二参数的函数。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| apply(function=null, ...) | 返回 null |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。
