适用范围：可抛受检异常的供应器接口（扩展 JDK Supplier）

== 1. 功能说明

`CSupplier<T>` 为供应器接口，扩展 `Supplier<T>`，支持受检异常：

- `get`：默认方法，@SneakyThrows 包装后调用 `getThrowable`
- `getThrowable`：抽象方法，可抛 Throwable
- 工具：`NULL`/`alwaysNull()`、`get(supplier)`、`convert(supplier)`

== 2. 设计要点

=== 2.1 受检异常包装

- `get` 内部 @SneakyThrows 包装（设计取舍）。

=== 2.2 工具方法

- `alwaysNull()`：恒返回 null；`get(supplier)`：supplier 为 null 返回 null；`convert`：转 JDK Supplier。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| get(supplier=null) | 返回 null |
| alwaysNull() | 恒返回 null |

== 5. 已知限制与取舍

- 用 @SneakyThrows 简化受检异常处理。

测试内容见 `doc/design/core/CSupplierTests.adoc`。
