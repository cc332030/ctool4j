== 1. 功能说明

`CDateUtils` 为日期时间工具类，提供：

- 格式化：`format(instant, pattern)`、`formatDate`/`formatTime`/`formatDateTime`/`formatPureDate` 等
- 解析：`parseInstant`/`parseInstantDate`/`parseInstantTime`/`parseInstantDateTime`、`parseMaybeMills`/`parseInstantMaybeMills`
- 转换：`toDate`/`toInstant`/`toLocalDate`/`toLocalTime`/`toLocalDateTime`/`toZonedDateTime`（多种入参）
- 运算：`plus`/`minus`（Instant/Date × Duration/单位/单位数组）
- 常量：`INITIAL_INSTANT`、`DEFAULT_ZONE_ID`、`MIN_MILLS`

== 2. 设计要点

=== 2.1 格式化/解析

- `formatDate`/`formatTime`/`formatDateTime` 分别输出 `yyyy-MM-dd`/`HH:mm:ss`/`yyyy-MM-dd HH:mm:ss`。
- `parseMaybeMills(text)`：先尝试按"毫秒/秒时间戳"解析——数值 `<= MIN_MILLS`（1e10）视为秒并乘 1000，
  否则视为毫秒，负数视为非法输入返回 null；失败回退按日期时间格式解析；支持日期/时间/日期时间/时间戳多种形态。

=== 2.2 类型转换

- `toDate`/`toInstant` 支持 Long（毫秒）/Instant/Date/LocalDateTime/LocalDate 等入参，null 返回 null。
- `toZonedDateTime`：将 Date/LocalDateTime/Instant 转系统默认时区 ZonedDateTime。

=== 2.3 运算

- `plus`/`minus` 支持 Instant/Date × Duration、单位（TemporalUnit）+ amount、单位数组（Pair 列表）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| toDate/toInstant 入参为 null | 返回 null |
| parseMaybeMills 时间戳判定 | 数值 `<= MIN_MILLS` 按秒处理、否则按毫秒；负数返回 null；失败回退日期时间格式 |

== 4. 适用范围

=== 4.1 适用场景

- 日期时间格式化、解析（含时间戳智能识别）、类型互转、加减运算。

=== 4.2 不适用/边界场景

- parseMaybeMills/toMillis 以数值阈值（`MIN_MILLS`=1e10）区分秒/毫秒，该区间存在固有歧义
  （1e10 同时是 2286-11-20 的秒值与 1973-03-03 的毫秒值）；需明确语义时用精确解析方法。

== 5. 已知限制与取舍

- 统一基于系统默认时区（DEFAULT_ZONE_ID）处理，跨时区场景需另行处理。
- 智能时间戳解析牺牲歧义场景的精确性，换取通用便捷。

测试内容见 `doc/design/core/CDateUtilsTests.adoc`。
