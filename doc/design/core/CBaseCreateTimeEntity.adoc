`CBaseCreateTimeEntity<ID>` 为基础创建时间实体，继承 `CId<ID>` 并实现 `ICCreateTime`，在 ID 基础上增加
`createTime` 字段。

=== 4.1 适用场景

- 需要主键 + 创建时间的实体基类。

== 5. 已知限制与取舍

- createTime 不可插入/更新（strategy NEVER）。
