== 用例设计思路与依据

=== 设计思路

- 覆盖 dayJobTime 的正常路径：param 合法时 endTime/startTime 计算（days=1 与 days=3）、param 为空取当前时间、param 为空白取当前时间。
- 覆盖异常路径：param 格式非法抛异常，不静默兜底。

=== 设计依据

- 依据功能设计对"endTime 次日零点、startTime 前移 1 小时+days 天、空参取当前时间、非法抛异常"的约定。
- 依据白盒/黑盒原则与错误推测法：days 参数（1/3）、param 形态（合法/空/空白/非法）均覆盖。

=== 覆盖场景与未覆盖

- 覆盖：days=1、days=3、param 为空、param 空白、param 非法。
- 未覆盖：跨系统默认时区边界的时间计算（依赖 `ZoneId.systemDefault()`，未对特定时区断言）。

== 1. dayJobTime 时间窗口计算

- 1.1 合法 param，days=1，endTime 次日零点、startTime 前移 1 小时+1 天（dayJobTime_validParamDays1）
- 1.2 合法 param，days=3，startTime 相应前移（dayJobTime_validParamDays3）
- 1.3 param 为空使用当前时间（dayJobTime_nullParamUsesNow）
- 1.4 param 纯空白按当前时间处理（dayJobTime_blankParamUsesNow）
- 1.5 param 格式非法抛异常（dayJobTime_invalidParamThrows）
