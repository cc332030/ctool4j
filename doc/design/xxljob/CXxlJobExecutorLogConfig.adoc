== 1. 功能说明

`CXxlJobExecutorLogConfig`（`@Data` + `@ConfigurationProperties("xxl.job.executor.log")`）承载执行器日志配置：

- `logCost`：打印执行耗时，默认 true。
- `logCatchError`：打印捕获的错误信息，默认 true。

== 2. 设计要点

=== 2.1 默认值

- 均默认 true。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未配置 | 默认开启 |

== 4. 适用范围

=== 4.1 适用场景

- 控制 CXxlJobAspect 是否打印耗时/错误日志。

== 5. 已知限制与取舍

- 默认开启，关闭时需显式配置。
