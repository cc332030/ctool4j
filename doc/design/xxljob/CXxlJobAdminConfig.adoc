== 1. 功能说明

`CXxlJobAdminConfig`（`@Data` + `@ConfigurationProperties("xxl.job.admin")`）承载 xxl-job 调度中心配置：

- `addresses`：调度中心根地址（多个用逗号分隔，为空关闭自动注册）。
- `accessToken`：通讯 TOKEN（非空时启用）。
- `timeout`：通讯超时（秒），默认 3。

== 2. 设计要点

=== 2.1 配置项

- addresses/accessToken 为空时关闭对应能力。
- timeout 默认 3 秒。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未配置 timeout | 默认 3 秒 |
| addresses 为空 | 关闭自动注册 |

== 4. 适用范围

=== 4.1 适用场景

- xxl-job 执行器连接调度中心的参数来源。
