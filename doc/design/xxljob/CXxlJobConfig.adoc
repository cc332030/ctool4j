== 1. 功能说明

`CXxlJobConfig`（`@Data` + `@ConfigurationProperties("xxl.job")`）承载 xxl-job 总开关配置：

- `enable`：是否开启，默认开启（本地可关闭）。

== 2. 设计要点

=== 2.1 enable

- 控制 xxl-job 执行器是否注册（`@ConditionalOnProperty` 配合使用）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| enable 未配置 | matchIfMissing 默认开启 |

== 4. 适用范围

=== 4.1 适用场景

- 控制 xxl-job 是否启用。

== 5. 已知限制与取舍

- 默认开启，需关闭时显式配置。

无测试类。
