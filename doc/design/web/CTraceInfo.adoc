== 1. 功能说明

`CTraceInfo` 为跟踪信息实体，实现 `ICTraceInfo`，含 `traceId` 字段。

标注 `@Data`/`@SuperBuilder`/`@NoArgsConstructor`/`@AllArgsConstructor`。

== 4. 适用范围

=== 4.1 适用场景

- 请求链路跟踪信息（traceId）的默认实现。

== 5. 已知限制与取舍
