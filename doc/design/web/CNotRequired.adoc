== 1. 功能说明

`CNotRequired` 为请求参数非必填标记注解（仅 request param / 方法参数级生效），纯标记、无属性。

request param 默认必填（与 `@RequestParam.required` 默认一致），需要非必填时叠加标注 `@CNotRequired`：

- `CParameterMethodArgumentResolver`：标注 `@CNotRequired` 的参数缺参放行（required=false）
- `CParameterAnnotationPlugin`（openapi2）：标注 `@CNotRequired` 的参数文档不标记必填

== 2. 设计要点

=== 2.1 与 CParameter 配合

- `@CParameter` 只管描述，`@CNotRequired` 只声明"非必填"，二者可组合：`@CNotRequired @CParameter("名称")`。

=== 2.2 默认必填

- 未标注 `@CNotRequired` 时 request param 默认必填（与 `@RequestParam` 一致），故命名为"NotRequired"。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无属性 | 纯标记，仅存在性生效 |

== 4. 适用范围

=== 4.1 适用场景

- 简单类型请求参数仅标注 `@CParameter` 时需要非必填。

=== 4.2 不适用/边界场景

- request body 字段必填由 `@CRequired` 表达（非必填默认），本注解不适用。

== 5. 已知限制与取舍

- 与 `@RequestParam` 同时标注时，绑定以 `@RequestParam` 为准，`@CNotRequired` 仅作文档提示。

测试内容见 `doc/design/web/CParameterMethodArgumentResolverTests.adoc` 与
`doc/design/openapi2/CParameterAnnotationPluginTests.adoc`。
