== 1. 功能说明

`ICFilter` 为项目统一的 HTTP Servlet 过滤器接口，继承 `Filter`，
将 `doFilter(ServletRequest, ServletResponse, FilterChain)` 委托给 HTTP 版本
`doFilter(HttpServletRequest, HttpServletResponse, FilterChain)`。

== 2. 设计要点

=== 2.1 统一入口

- 定义 HTTP 版本的 `doFilter`，实现类只需处理 HTTP 请求/响应，无需处理 ServletRequest 强转。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 默认方法强制转换 | 将 ServletRequest/Response 强转为 HTTP 版本 |

== 4. 适用范围

=== 4.1 适用场景

- 项目内所有 Servlet 过滤器实现该接口。

== 5. 已知限制与取舍

- 实现类需实现 HTTP 版本的 `doFilter`。

测试内容：无独立测试类（接口，由实现类测试间接覆盖）。
