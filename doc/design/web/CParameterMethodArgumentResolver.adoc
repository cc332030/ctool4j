== 1. 功能说明

`CParameterMethodArgumentResolver` 为 SpringMVC 参数解析器，继承 `RequestParamMethodArgumentResolver`
（Spring 解析 `@RequestParam` 的标准基类），将「标注 `@CParameter`、未标注 `@RequestParam`、简单类型」
的方法参数按 `@RequestParam` 语义解析绑定：参数名与必填取自 `@CParameter`，使文档注解同时驱动
SpringMVC 绑定，避免重复标注 `@RequestParam(required=...)`。

== 2. 设计要点

=== 2.1 接管范围

- `supportsParameter`：参数标注 `@CParameter`、未标注 `@RequestParam`、类型为简单类型
  （`BeanUtils.isSimpleProperty`，含 Optional 剥离）时接管。
- 已有 `@RequestParam`：返回 false，绑定由 `@RequestParam` 原生解析（`@CParameter` 仅作文档），避免语义冲突。
- 非简单类型（复杂对象）：不接管，由 `@RequestBody`/`@ModelAttribute` 等标准机制处理。

=== 2.2 绑定语义

- `createNamedValueInfo`：参数名取 `@CParameter.name()`（空时由基类按参数名兜底，与 `@RequestParam` 不写 name 一致）；
  required 取 `@CParameter.required()`（默认 true）。
- 复用父类 `resolveName`/`handleMissingValue`：从 request 取参、缺参且必填时抛
  `MissingServletRequestParameterException`（与 `@RequestParam` 行为一致）。

=== 2.3 注册

- 经 `CWebMvcConfigurer#addArgumentResolvers` 注册。Spring 将自定义 resolver 排在
  catch-all 的 `RequestParamMethodArgumentResolver(useDefaultResolution=true)` 之前，
  故标注 `@CParameter` 的简单参数会先由本解析器处理。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未标注 @CParameter | 返回 false，交其他解析器 |
| 已标注 @RequestParam | 返回 false，绑定以 @RequestParam 为准 |
| 非简单类型 | 返回 false，交 @RequestBody/@ModelAttribute 等 |
| name 为空 | 基类按方法参数名兜底 |
| required=true 缺参 | 抛 MissingServletRequestParameterException |

== 4. 适用范围

=== 4.1 适用场景

- 简单类型请求参数只标注 `@CParameter`，需 required 同时驱动 SpringMVC 绑定与文档。

=== 4.2 不适用/边界场景

- 复杂对象参数不接管。
- 已标注 `@RequestParam` 时不接管（避免双绑定冲突）。

== 5. 已知限制与取舍

- 依赖 `@CParameter`（web 模块）注解定义与 `CWebMvcConfigurer` 注册。
- 仅接管简单类型参数；List/数组等多值参数需显式 `@RequestParam`。

测试内容见 `doc/design/web/CParameterMethodArgumentResolverTests.adoc`。
