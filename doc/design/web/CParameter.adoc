== 1. 功能说明

`CParameter` 为接口参数级纯文档注解，命名对应 OpenAPI3 中 Swagger/OpenAPI2 `ApiParam` 的替代注解
`Parameter`（前缀 c），标注在接口方法参数上，描述参数的名称、说明、是否必填、示例。

- `value()`：参数说明，默认 ""，支持简写 `@CParameter("内容")`
  （替代了原先的 `description()`，对应 `Parameter.description` / `ApiParam.value`）
- `name()`：参数名称（对应 `Parameter.name` / `ApiParam.name`），默认 ""
- `required()`：是否必填（对应 `Parameter.required` / `ApiParam.required`），默认 false
- `example()`：参数示例（对应 `Parameter.example`），默认 ""

== 2. 设计要点

=== 2.1 替代 OpenAPI2 ApiParam

- `@CParameter` 替代参数级 `@ApiParam`。

=== 2.2 纯文档

- 仅提供文档元数据，不参与运行时校验。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| name 为空 | 沿用参数既有名称 |
| value/example 为空 | 不覆盖已有内容 |
| required=false | 不标记必填 |

== 4. 适用范围

=== 4.1 适用场景

- 接口方法参数需要名称/说明/必填/示例时标注 `@CParameter`，由 openapi2 的 `CParameterAnnotationPlugin` 落地。
