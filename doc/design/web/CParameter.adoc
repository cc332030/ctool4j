== 1. 功能说明

`CParameter` 为接口参数级文档描述注解，命名对应 OpenAPI3 中 Swagger/OpenAPI2 `ApiParam` 的替代注解
`Parameter`（前缀 c），标注在接口方法参数上，描述参数的名称、说明、示例（不含 required，必填由
`CNotRequired` 反向控制）。

- `value()`：参数说明，默认 ""，支持简写 `@CParameter("内容")`
  （替代了原先的 `description()`，对应 `Parameter.description` / `ApiParam.value`）
- `name()`：参数名称（对应 `Parameter.name` / `ApiParam.name`），默认 ""
- `example()`：参数示例（对应 `Parameter.example`），默认 ""

== 2. 设计要点

=== 2.1 替代 OpenAPI2 ApiParam

- `@CParameter` 替代参数级 `@ApiParam`。

=== 2.2 文档 + 运行时绑定

- 文档侧由 openapi2 的 `CParameterAnnotationPlugin` 读取 name/description/example 写入 springfox；
  参数必填默认 true（未标 `@CNotRequired`）。
- 运行时侧：简单类型参数未标注 `@RequestParam` 时由 `CParameterMethodArgumentResolver` 接管
  （解析器文档见 `CParameterMethodArgumentResolver.adoc`），默认必填；叠加 `@CNotRequired` 时非必填。
- 若参数已标注 `@RequestParam`，则绑定以 `@RequestParam` 为准（`@CParameter` 仅作文档）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| name 为空 | 沿用参数既有名称 |
| value/example 为空 | 不覆盖已有内容 |
| 未标 @CNotRequired | 默认必填（文档 + 绑定） |
| 标注 @CNotRequired | 非必填（缺参放行） |
| 已有 @RequestParam | 绑定以 @RequestParam 为准 |

== 4. 适用范围

=== 4.1 适用场景

- 接口方法参数需要名称/说明/示例时标注 `@CParameter`，由 openapi2 的 `CParameterAnnotationPlugin` 落地文档。
- 简单类型请求参数只标注 `@CParameter`（不写 `@RequestParam`）时，默认必填；非必填叠加 `@CNotRequired`。

=== 4.2 不适用/边界场景

- 复杂对象（非简单类型）参数不做绑定接管，需用 `@RequestBody` 等标准注解。
