== 用例设计思路与依据

=== 设计思路

- 验证 getContentDispositionValue 的拼接行为，覆盖正常/空/null/中文文件名。

=== 设计依据

- 依据功能设计对 `attachment;filename=` 拼接的约定。

=== 覆盖场景与未覆盖

- 覆盖：正常/空/null/中文文件名。
- 未覆盖：writeResponse（依赖容器上下文，未在单测覆盖）。

== 1. Content-Disposition 值

- 1.1 正常：`attachment;filename=report.xlsx`（getContentDispositionValue）
- 1.2 空文件名：`attachment;filename=`（getContentDispositionValue_emptyFilename）
- 1.3 null 文件名：`attachment;filename=null`（getContentDispositionValue_nullFilename）
- 1.4 中文文件名：`attachment;filename=报表.xlsx`（getContentDispositionValue_withChinese）
