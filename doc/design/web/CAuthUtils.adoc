适用范围：认证 token 工具（Bearer 前缀处理）

== 1. 功能说明

`CAuthUtils` 为认证 token 工具类，提供：

- `TOKEN_PREFIX`：默认前缀 "Bearer"
- `removePrefix(token)`：移除 token 前缀
- `getToken()` / `getToken(prefix)` / `getToken(request, prefix)`：从请求 Authorization 头取 token
- `setToken(token)` / `setToken(token, prefix, response)`：设置 Authorization 响应头

== 2. 设计要点

=== 2.1 removePrefix

- token 空白返回 null；长度不大于前缀或未以前缀开头时原样返回；否则去掉前缀。

=== 2.2 getToken

- request 为 null 返回 null；Authorization 头为空、未以前缀开头、长度不大于前缀时返回 null；
  否则返回前缀后的 token。

=== 2.3 setToken

- 设置 `Authorization: {prefix} {token}` 响应头。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| removePrefix token 空白 | 返回 null |
| removePrefix 未以前缀开头 | 原样返回 |
| getToken request null / 头无效 | 返回 null |
| getToken 长度等于前缀 | 返回 null |

== 4. 适用范围

=== 4.1 适用场景

- Bearer token 的请求解析与响应设置。

== 5. 已知限制与取舍

- 前缀匹配大小写敏感；基于 Bearer 前缀约定。
