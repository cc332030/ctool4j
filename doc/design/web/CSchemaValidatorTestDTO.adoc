== 1. 功能说明

`CSchemaValidatorTestDTO` 为 `CSchemaValidatorTests` 集成测试辅助 DTO，字段用 `@CSchema` 标注：

- `username`：必填字符串（`@CSchema(required=true)`，含描述）
- `remark`：非必填字符串（含描述）
- `other`：无描述的非必填字符串

用于在启动 Spring 容器后经真实接口（`CSchemaValidatorTestController` 的 `@Valid @RequestBody`）验证接口必填/非必填生效。

== 4. 适用范围

=== 4.1 适用场景

- `CSchemaValidatorTests` 集成测试，验证 `@CSchema` 注解在真实接口（`CSchemaValidatorTestController`）上的必填校验。

== 5. 已知限制与取舍

- 测试辅助类；字段设计覆盖必填/非必填/有描述/无描述多种形态，对应真实接口必填与非必填场景。
