== 用例设计思路与依据

=== 设计思路

- 按 CRequestLogUtils：请求日志采集与常量 的处理路径/边界组织分类，逐一覆盖正例、反例与边界。
- `isExcludeUri` 的内置静态资源排除分支（先于配置读取、配置无关）纳入覆盖：接口文档静态资源、静态文件扩展名命中即排除，业务 uri 不排除。

=== 覆盖场景与未覆盖

- 覆盖：见下方编号索引。
- 未覆盖：`isExcludeUri` 依赖用户配置 `exclude-uri-patterns` 的部分、`isEnable`/`genRequestLog`/`logWrite` 等依赖容器装配的场景，由集成测试覆盖。
