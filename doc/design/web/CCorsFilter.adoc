== 1. 功能说明

`CCorsFilter` 为跨域（CORS）Servlet Filter，`@Component` + `ICFilter` + `PriorityOrdered`，
`getOrder()` 返回 `Integer.MIN_VALUE`（最高优先级，最先执行）。

核心方法 `doFilter(request, response, chain)`：

- 调用 `CCorsUtils.handle(request, response)` 输出 CORS 头
- 若 `CCorsUtils.handleOptions` 判定为 OPTIONS 预检请求（返回 true），直接 return（以 204 结束预检）
- 否则 `chain.doFilter` 继续请求链

== 2. 设计要点

=== 2.1 最高优先级

- 最先执行，保证跨域头在请求链最前面输出。

=== 2.2 预检处理

- OPTIONS 预检请求由 `CCorsUtils.handleOptions` 以 204 结束，不进入后续业务处理。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| `CCorsUtils.handle`/`handleOptions` 内部异常 | 被 CCorsUtils 内部 try-catch 记录日志，请求继续 |
| 非预检请求 | 正常放行到过滤器链后续 |

== 4. 适用范围

=== 4.1 适用场景

- 跨域请求自动输出 CORS 头并正确处理 OPTIONS 预检。

=== 4.2 不适用/边界场景

- `CCorsConfig.enable=false` 时 `CCorsUtils.handle` 不做任何输出（开关控制）。

== 5. 已知限制与取舍

- 依赖 `CCorsUtils` 的配置注入（Spring 容器初始化后生效）。

测试内容见 `doc/design/web/CCorsFilterTests.adoc`。
