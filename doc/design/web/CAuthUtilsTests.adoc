= CAuthUtils 测试用例文档

Version: 1.1
LastModified: 2026-08-21
所属功能：`com.c332030.ctool4j.web.util.CAuthUtils`（web 工具类）——认证 token 工具。

对应测试类：`com.c332030.ctool4j.web.test.util.CAuthUtilsTests`

本文档为 CAuthUtils 的测试用例文档，含用例设计思路与依据、覆盖场景，以及测试用例的分类编号索引；测试方法在 javadoc 中标注对应编号（如 `对应测试用例 1.1`），文档与代码互相定位，便于检查覆盖是否有遗漏。

== 用例设计思路与依据

=== 设计思路

- 按「removePrefix / getToken / setToken」多个维度组织，覆盖各空值/前缀匹配边界。

=== 设计依据

- 依据功能设计对前缀匹配、空值兜底的约定。

=== 覆盖场景与未覆盖

- 覆盖：removePrefix 正常/空白/等于前缀/短于前缀/无前缀/无空格/大小写；getToken 请求头各形态/自定义前缀/
  null request；setToken 默认/自定义前缀/null response。
- 未覆盖：无。

== 1. removePrefix

- 1.1 正常（removePrefix_normal）
- 1.2 空白返回 null（removePrefix_blank_returnsNull）
- 1.3 等于前缀（removePrefix_equalsPrefix）
- 1.4 短于前缀（removePrefix_shorterThanPrefix）
- 1.5 无前缀（removePrefix_noPrefix）
- 1.6 前缀无空格（removePrefix_bearerNoSpace）
- 1.7 大小写敏感（removePrefix_caseSensitive）

== 2. getToken

- 2.1 请求带前缀（getToken_requestPrefix）
- 2.2 无 Authorization（getToken_noAuthorization）
- 2.3 空前缀（getToken_emptyPrefix）
- 2.4 长度等于前缀（getToken_lengthEqualsPrefix）
- 2.5 null request 返回 null（getToken_nullRequest_returnsNull）
- 2.6 自定义前缀（getToken_customPrefix）

== 3. setToken

- 3.1 响应设置（setToken_response）
- 3.2 自定义前缀（setToken_customPrefix）
- 3.3 null response（setToken_nullResponse）
