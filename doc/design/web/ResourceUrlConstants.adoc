== 1. 功能说明

`ResourceUrlConstants`（`@UtilityClass`）为静态资源 URL 常量类。

常量：

- `FAVICON_ICO_URL = "/favicon.ico"`：favicon 图标地址
- `IGNORE_RESOURCE_URLS`：需要忽略的静态资源地址集合，默认含 `FAVICON_ICO_URL`

== 2. 设计要点

=== 2.1 常量收敛

- 静态资源 URL 集中管理，供 `CResourceFilter` 等判断忽略的资源。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无 | 纯常量类，无行为 |

== 4. 适用范围

=== 4.1 适用场景

- 需要判断/忽略 favicon 等静态资源的过滤器场景。

== 5. 已知限制与取舍

- 集合为不可变快照（`CSet.of`），新增忽略资源需修改常量。

测试内容：无独立测试类（纯常量，由使用方 `CResourceFilter` 测试间接覆盖）。
