== 用例设计思路与依据

=== 设计思路

- 按「create / verify / parse / getJson」多个维度组织，覆盖正常/空值/异常路径。

=== 设计依据

- 依据功能设计对 secret 非空白、jwt 空兜底的约定。

=== 覆盖场景与未覆盖

- 覆盖：create（Map/Object secret/null/空 secret 抛异常）；verify（正确/错误 secret/非法 jwt/空 jwt/
  null/空 secret 抛异常）；parseJwt（正常/空/null）；getJson（正常/null 数组/越界）；getHeaderJson/
  getBodyJson（正常/空 jwt）。
- 未覆盖：无（覆盖了核心行为）。
