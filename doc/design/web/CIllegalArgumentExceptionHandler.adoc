适用范围：`@RestControllerAdvice` 参数不合法异常处理器，统一处理 `IllegalArgumentException`

== 1. 功能说明

`CIllegalArgumentExceptionHandler` 标注 `@RestControllerAdvice`，通过 `@ExceptionHandler(IllegalArgumentException.class)` 处理参数不合法异常：

- 通过 `@ConditionalOnMissingExceptionHandler(IllegalArgumentException.class)` 控制：容器存在其他同类型处理器时本处理器不生效。
- 返回 `CStrResult<Void>` 错误结果（`CStrResult.error(...)`）。
- 记录请求 URI 与异常堆栈（log），保证问题可追溯。

== 2. 设计要点

- 用 `CRequestUtils.getRequestURIDefaultNull()` 记录请求 URI 用于日志。
- 返回 `CStrResult<Void>` 错误结果（`CStrResult.error(...)`）。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 容器已存在同类型处理器 | @ConditionalOnMissingExceptionHandler 使本处理器不生效 |
| 异常对象为 null | 记录日志并返回错误结果 |

== 4. 适用范围

=== 4.1 适用场景

- Web 应用统一参数不合法异常的响应格式。

== 5. 已知限制与取舍

- 依赖 `CStrResult` 响应结构，与项目统一响应格式耦合。
