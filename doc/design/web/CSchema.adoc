== 1. 功能说明

`CSchema` 为接口属性文档描述注解，语义与原生 `@ApiModelProperty` / OpenAPI3 `@Schema` 一致
（仅文档，不参与运行时校验），可标注在字段、getter 方法上。

- `value()`：属性描述（对应 `ApiModelProperty.value` / `Schema.description`），默认 ""

需要必填校验时配合 `CRequired` 注解（见 `CRequired.adoc`），描述与必填解耦。

== 2. 设计要点

=== 2.1 纯文档描述

- 与 `@ApiModelProperty` / `@Schema` 对齐，只承载文档描述；不再含校验相关属性。
- 必填语义迁移至 `CRequired`。

=== 2.2 文档联动

- `value()` 作为文档描述，配合 openapi2 的 `CSchemaAnnotationModelPropertyPlugin` 写入属性 description。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| value 为空 | 不覆盖已有描述 |

== 4. 适用范围

=== 4.1 适用场景

- 接口属性/字段/getter 需要文档描述时标注 `@CSchema`。

=== 4.2 不适用/边界场景

- 不做运行时校验；需必填校验时配合 `@CRequired`。
