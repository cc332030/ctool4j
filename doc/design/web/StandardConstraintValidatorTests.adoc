== 用例设计思路与依据

=== 设计思路

- 启动真实 Spring 容器（`@CTool4jSpringBootTest`），经容器注入的真实 `Validator` 校验标准注解（@NotNull/@NotBlank/@NotEmpty）与 `@CSchema` 共存场景，贴近真实使用场景，不手动 `new` 校验器。
- 验证标准校验注解触发 violation、message 经 getMessage() 正确返回，与 @CSchema 处理逻辑一致。

- 未覆盖：依赖外部 Servlet 容器/Spring 全容器装配的集成场景由集成测试覆盖。
