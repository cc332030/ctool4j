== 用例设计思路与依据

=== 设计思路

- 启动真实 Spring 容器（`@CTool4jSpringBootTest` + `@AutoConfigureMockMvc`），经容器注入的真实 `Validator` 做按类型分发的直接校验，并走真实接口（MockMvc 调 `CSchemaValidatorTestController` 的 `POST /c-schema-validator/test`，`@Valid @RequestBody` 触发校验）验证必填/非必填生效，贴近真实使用场景。
- 覆盖 required=false 跳过校验、required=true 时 null/字符串（notBlank）/集合（notEmpty）/Map（notEmpty）/数组（notEmpty）/其他对象（notNull），以及 message 自定义提示、groups/payload 兼容。
- 分类 1 用容器 `Validator` 直接校验各类型分发分支；分类 2 用 MockMvc 走真实接口验证必填/非必填。

=== 覆盖场景与未覆盖

- 覆盖：见下方编号索引。
- 未覆盖：文档字段生成（description/required）由 openapi2 模块的 `CSchemaIntegrationTests` 集成测试覆盖（见 `doc/design/openapi2/CSchemaIntegrationTests.adoc`）。
