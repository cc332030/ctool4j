== 1. 功能说明

`CWebUtils` 为 Web 工具类，提供：

- `getContentDispositionValue(filename)`：构造 Content-Disposition 响应头值
- `writeResponse(inputStream, filePath)` / `writeResponse(inputStream, contentLength, filePath)`：
  将输入流写出为响应内容（含文件名/MIME/内容长度设置）

== 2. 设计要点

=== 2.1 响应头

- `getContentDispositionValue` 拼接 `attachment;filename=` 前缀。
- `writeResponse` 设置 Content-Disposition（有文件名时）、Content-Type（有 MIME 时，未知则告警）、
  Content-Length（指定时），并拷贝输入流到响应输出流。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 文件名为空 | 不设置 Content-Disposition |
| MIME 未知 | 记录 warn 日志，不设置 Content-Type |
| contentLength 为 null | 不设置 Content-Length |

== 4. 适用范围

=== 4.1 适用场景

- 文件下载响应（附件/内容写出）。

== 5. 已知限制与取舍

- 依赖 CRequestUtils.getResponse()（容器上下文）。
