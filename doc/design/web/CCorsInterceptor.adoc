== 1. 功能说明

`CCorsInterceptor` 为跨域的**备用方案**（`@Component` 已被注释，需使用方手动注册到拦截器链），
实现 `ICHandlerInterceptor`（继承 `HandlerInterceptor`）。

核心方法 `preHandle(request, response, handler)`：

- 调用 `CCorsUtils.handle(request, response)` 输出 CORS 头
- 返回 `!CCorsUtils.handleOptions(request, response)`：
  OPTIONS 预检请求返回 false（停止处理），否则返回 true（继续）

== 2. 设计要点

=== 2.1 备用方案定位

- Filter 已自动生效时无需注册本拦截器；供需要拦截器链场景手动注册。

=== 2.2 预检处理

- OPTIONS 预检由 `CCorsUtils.handleOptions` 处理，preHandle 返回 false 结束。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| `CCorsUtils.handle`/`handleOptions` 内部异常 | 被 CCorsUtils 内部 try-catch 记录日志 |
| OPTIONS 预检 | 返回 false 停止处理（以 204 结束） |

== 4. 适用范围

=== 4.1 适用场景

- 无法使用 Filter 的拦截器链场景手动注册。

=== 4.2 不适用/边界场景

- Filter 已生效时无需使用；未注册则本拦截器不生效。

== 5. 已知限制与取舍

- 需手动注册；跨域处理统一收敛在 `CCorsUtils`。

测试内容见 `doc/design/web/CCorsInterceptorTests.adoc`。
