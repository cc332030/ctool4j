== 1. 功能说明

`CTraceUtils` 为链路追踪工具类，提供：

- `TRACE_ID`：追踪 id 在 MDC 及请求头中的键名（"c-trace-id"）
- `getTraceInfo()` / `removeTraceInfo()`：获取/移除当前线程追踪信息（TransmittableThreadLocal）
- `generateTraceId()`：生成追踪 id（objectId + "-1"）
- `initTrace()`：初始化追踪（优先取请求头追踪 id 自增，否则新生成）
- `getTraceId()` / `setTraceId()` / `removeTraceId()`：追踪 id 获取/设置（写 MDC）/移除

== 2. 设计要点

=== 2.1 提供者

- 追踪信息提供者优先取自定义 SPI 实现，否则默认 `CTraceInfoProvider`。

=== 2.2 线程上下文

- 用 `TransmittableThreadLocal` 保存当前线程追踪信息（支持线程池传递）。

=== 2.3 初始化

- `initTrace` 优先取请求头追踪 id 并自增（`incrLastNum`），否则新生成，再 `setTraceId`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 请求头无追踪 id | 新生成追踪 id |
| 请求头追踪 id | 自增后使用 |

== 4. 适用范围

=== 4.1 适用场景

- 请求链路追踪 id 的生成、传递与 MDC 关联。

== 5. 已知限制与取舍

- 基于 TransmittableThreadLocal 支持线程池传递，依赖 TTL 库。

测试内容见 `doc/design/web/CTraceUtilsTests.adoc`。
