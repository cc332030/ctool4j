== 1. 功能说明

`CRequired` 为必填校验注解（标注即必填，无 required 开关），合并 notNull、notBlank（字符串）、
notEmpty（集合/Map/数组）三类校验，按被标注值的实际类型自动选择校验逻辑（由 `CRequiredValidator` 实现），
替代原生 `@NotNull`/`@NotBlank`/`@NotEmpty` 系列。

适用于 request body / 字段级必填校验（Bean Validation）。`@Target` 与原生 `@NotNull` 一致
（METHOD/FIELD/ANNOTATION_TYPE/CONSTRUCTOR/PARAMETER/TYPE_USE），支持 `@Repeatable`。

- `message()`：校验失败提示消息（默认 "不能为空"），字段名前缀由 `CMethodArgumentNotValidExceptionHandler` 拼接
- `groups()`/`payload()`：Bean Validation 标准分组/载荷

== 2. 设计要点

=== 2.1 标注即必填

- 无 required 属性，标注即执行必填校验；不标注默认非必填（request body 字段默认非必填）。

=== 2.2 文档联动

- openapi2 的 `CRequiredAnnotationPlugin`（参数展开）与 `CSchemaAnnotationModelPropertyPlugin`（model 属性）
  读取 `@CRequired` 将字段/属性标记为必填。

=== 2.3 与 CSchema 解耦

- 描述由 `@CSchema`（纯文档）提供，必填由 `@CRequired` 承担，字段可组合标注。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 标注即校验 | required 恒为必填 |
| message 缺省 | 默认 "不能为空" |

== 4. 适用范围

=== 4.1 适用场景

- request body DTO 字段/getter 需要必填校验与文档必填标记时标注 `@CRequired`。

=== 4.2 不适用/边界场景

- request param 方法参数级非必填由 `@CNotRequired` 表达（见 `CNotRequired.adoc`）。

== 5. 已知限制与取舍

- 校验按类型自动分发，依赖 `CValidUtils` 各类重载。
- `@Target` 与 `@NotNull` 一致，允许标注在参数上；request body 场景实际作用于字段。

测试内容见 `doc/design/web/CRequiredValidatorTests.adoc`（校验逻辑在 CRequiredValidator）。
