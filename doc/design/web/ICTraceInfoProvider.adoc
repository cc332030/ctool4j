== 1. 功能说明

`ICTraceInfoProvider<T extends ICTraceInfo>` 为链路追踪信息提供者接口：

- `getTraceInfo()`：获取链路追踪信息（返回 `T extends ICTraceInfo`）

== 2. 设计要点

=== 2.1 SPI 扩展

- 通过该接口提供链路追踪信息，便于不同链路追踪实现接入。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 无 | 纯接口契约 |

== 4. 适用范围

=== 4.1 适用场景

- 需要向框架提供链路追踪信息的实现方实现本接口。
