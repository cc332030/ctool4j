== 1. 功能说明

`CSchemaValidatorTestController` 为 `CSchemaValidatorTests` 集成测试辅助 Controller（`@RestController` + `@Validated`）：

- `test(@Valid @RequestBody CSchemaValidatorTestDTO dto)`：POST `/c-schema-validator/test`，接收 `@CSchema` 标注的 DTO，`@Valid` 触发字段校验（username required=true 必填）。

作为真实接口入口，校验失败由全局异常处理器 `CMethodArgumentNotValidExceptionHandler` 拼接字段错误并返回 `code=500`。

== 4. 适用范围

=== 4.1 适用场景

- `CSchemaValidatorTests` 集成测试，作为真实接口入口验证 `@CSchema` 必填/非必填校验。

== 5. 已知限制与取舍

- 测试辅助类；仅提供单个测试接口。
