== 1. 功能说明

`CRequestLog` 为请求日志模型，`@Data` + `@SuperBuilder` + `@NoArgsConstructor` + `@AllArgsConstructor`，
承载一次 HTTP 请求/响应的完整日志信息。

字段：

- `source`：日志来源（`ICSource`，如 feign、mvc），用于日志最前面标识请求来源
- `method`：HTTP 方法（GET/POST/PUT/DELETE...）
- `path`：请求路径（不含 query string）
- `token`：认证令牌（Authorization 请求头的值），仅用于日志末尾业务数据区展示
- `traceId`/`tenantId`/`userId`：链路追踪 ID、租户 ID、用户 ID
- `ip`：请求来源 IP（仅用于日志展示的元信息，非 HTTP 请求头）
- `requestHeaders`：完整请求头（headerName → 一个或多个 headerValue），供 feign 等客户端请求日志使用，
  仅包含真实请求头；token/traceId 等业务数据见 `CCommUtils.appendHttpLog`
- `params`：query 参数（仅 GET 时拼接到 URL）
- `req`：请求体（统一为 Object），服务端 MVC 经 Advice 记录请求体对象，feign 记录请求体文本字符串
- `rsp`：响应体，拼接时经 `getPrintAble` 可打印处理后输出
- `responseStatus`：响应状态码（如 200、404），未采集时为 null（不输出状态行）
- `responseHeaders`：响应头，为空时不输出
- `errorMessage`：异常信息
- `beginTimeMillis`/`endTimeMillis`：请求开始/结束时间（毫秒时间戳），`@Builder.Default` 默认 0

== 2. 设计要点

=== 2.1 数据模型

- 请求/响应体统一为 `Object`，兼容 MVC 记录对象与 feign 记录文本，拼接时统一处理。

=== 2.2 默认耗时

- 时间戳默认 0，未测量时 `end - begin` 为 0，由 `CCommUtils` 判断不输出耗时。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| `responseStatus` 为 null | 不输出响应状态行 |
| `responseHeaders` 为空 | 不输出响应头 |
| 时间戳默认 0 | 耗时计算为 0，由拼接层判断 |

== 4. 适用范围

=== 4.1 适用场景

- 服务端 MVC、feign、resttemplate、httpclient 等请求方式构造请求日志统一打印。

== 5. 已知限制与取舍

- `requestHeaders` 仅含真实请求头，业务数据（token/traceId）由 `CCommUtils.appendHttpLog` 业务数据区输出。

测试内容见 `doc/design/web/CRequestLogTests.adoc`。
