状态：已落地

== 1. 功能说明

`COperation` 为接口方法级纯文档注解，命名对应 OpenAPI3 中 Swagger/OpenAPI2 `ApiOperation` 的替代注解
`Operation`（前缀 c），标注在接口方法上，描述单个接口操作的摘要、说明、分组等。

- `value()`：操作摘要，作为接口标题，默认 ""，支持简写 `@COperation("内容")`
  （替代了原先的 `summary()`，对应 `Operation.summary` / `ApiOperation.value`）
- `description()`：操作详细说明（对应 `Operation.description` / `ApiOperation.notes`），默认 ""
- `operationId()`：操作唯一标识（对应 `Operation.operationId`），默认 ""（openapi2 暂不覆盖，见已知限制）
- `tags()`：操作归属分组标签（对应 `Operation.tags`），默认空
- `deprecated()`：是否废弃（对应 `Operation.deprecated`），默认 false

== 2. 设计要点

=== 2.1 替代 OpenAPI2 ApiOperation

- `@COperation` 替代方法级 `@ApiOperation`。

=== 2.2 纯文档

- 仅提供文档元数据，不参与运行时校验。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| value/description 为空 | 不覆盖已有内容 |
| deprecated=false | 不标记废弃 |

== 4. 适用范围

=== 4.1 适用场景

- 接口方法需要摘要/说明/分组时标注 `@COperation`，由 openapi2 的 `COperationAnnotationPlugin` 落地。

== 5. 已知限制与取舍

- springfox 会为 operation 自动生成 id，openapi2 插件暂不覆盖 `operationId`；该属性保留供 OpenAPI3 生成使用。
