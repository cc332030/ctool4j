= CInnerApiInterceptor 设计文档

Version: 1.2
LastModified: 2026-09-09
模块：ctool4j-web
类：com.c332030.ctool4j.web.interceptor.CInnerApiInterceptor
状态：已落地
适用范围：内部接口 IP 白名单拦截器

== 1. 功能说明

`CInnerApiInterceptor`：内部接口 IP 白名单拦截器，实现 `ICHandlerInterceptor`，由 `CWebMvcConfigurer`
收集并全路径注册。对标注 `CInnerApi` 的 Controller 类/方法做 IP 白名单校验：
命中配置 `CInnerApiConfig.allowedIps` 中任一 IP/IP 段(CIDR)则放行，否则拒绝（HTTP 403 + 统一错误体）。

== 2. 设计要点

=== 2.1 生效链路

请求 → `CWebMvcConfigurer.addInterceptors` 注册的全部 `ICHandlerInterceptor` → `preHandle`：
- `handler` 非 `HandlerMethod`（如静态资源）直接放行；
- 方法标注 `CInnerApi`，或类标注 `CInnerApi`（含 `@Inherited` 从抽象父类继承）则视为内部接口；
- 内部接口取客户端 IP（`CRequestUtils.getIp`）→ `CIpUtils.contains` 校验白名单 → 命中放行，否则拒绝。

=== 2.2 注解识别

- 方法级优先：`handlerMethod.getMethodAnnotation(CInnerApi.class)`。
- 类级兜底：`handlerMethod.getBeanType().isAnnotationPresent(CInnerApi.class)`。
  注解 `@Inherited` 使标注在抽象父类类级时，子类 Controller 自动识别。

=== 2.3 白名单来源

- 白名单全部来自 `CInnerApiConfig`（构造注入），注解本身不携带 IP，所有内部接口共用同一份白名单。

=== 2.4 拒绝响应

- 未命中白名单时：HTTP 403 FORBIDDEN + `CStrResult.error(HttpStatus.FORBIDDEN, ...)`，经 `CServletUtils.writeJson` 输出 JSON。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 非内部接口（未标注 `CInnerApi`） | 直接放行 |
| 白名单为空（未配置 `allowed-ips`） | 全部放行 |
| 客户端 IP 非法/为空 | `CIpUtils` 判定不命中，拒绝（安全优先） |
| 白名单规则非法 | `CIpUtils` 记录日志并跳过该规则，不影响其它规则 |

== 4. 适用范围

=== 4.1 适用场景

内部管理接口、继承 `CMpController` 的具体 Controller（在类或方法上标注 `CInnerApi`），限制仅内网 IP 调用。

=== 4.2 不适用/边界场景

- 非 web MVC（无 `HandlerMethod`）调用不适用。
- 对外公开接口不应标注，避免误拦截。

== 5. 已知缺陷与不足 / 注意事项

=== 5.1 安全缺陷（重要）

- **IP 来源可伪造**：依赖 `CRequestUtils.getIp`，其当前无条件信任 `X-Forwarded-For` 首段，客户端直连时可伪造该请求头绕过 IP 白名单（与 `CRequestUtils` 既有已知限制一致，见 `doc/design/spring/CRequestUtils.adoc`）。**生产对外场景必须配合可信代理，并在代理处清理/覆盖 `X-Forwarded-For`，否则本拦截器可能被绕过**。

=== 5.2 易误用点

- **标注≠生效**：仅在标注 `CInnerApi` 且 `CInnerApiConfig.allowed-ips` 非空时校验才真正收紧；忘配白名单则仍全部放行（见 `CInnerApiConfig.adoc`）。
- **`@Inherited` 仅作用于类级**：标在父类类级时子类 Controller 继承识别；方法级标注不随继承传播，需标在具体方法上。
- 非 `HandlerMethod`（如静态资源）一律放行，不影响静态资源访问。

=== 5.3 边界与默认值

- 客户端 IP 非法/为空时按"不命中"拒绝（安全优先），避免空 IP 绕过。
- 拒绝响应：HTTP 403 + `CStrResult.error(FORBIDDEN)`，经 `CServletUtils.writeJson` 写 JSON（不抛异常进异常处理器）。

=== 5.4 性能

- 拦截器全路径注册（由 `CWebMvcConfigurer` 统一收集），对**每个**请求都会进入 `preHandle`；内部仅做一次注解判定 + 命中校验，开销低。注解判定用 `getMethodAnnotation`/`isAnnotationPresent`，非反射调用，可忽略。

=== 5.5 波及影响

- 作为 `@Component implements ICHandlerInterceptor`，凡使用 ctool4j-web 且启用了拦截器收集机制的应用均会注册本拦截器；其行为（识别 `CInnerApi`、拒绝 403）变化会影响所有启用方，需评估兼容。

=== 5.6 测试

- 已提供 `CInnerApiInterceptorTests`（见 `doc/design/web/CInnerApiInterceptorTests.adoc`），覆盖非 HandlerMethod、类/方法级注解识别、`@Inherited` 父类类级继承、白名单空、命中、未命中拒绝(403)、X-Forwarded-For 首段命中/未命中等路径。
- 未覆盖：真实 Spring MVC 容器集成场景、`@Inherited` 在真实代理(如 CGLIB)下的场景。
