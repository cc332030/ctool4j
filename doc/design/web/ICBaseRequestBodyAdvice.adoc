== 1. 功能说明

`ICBaseRequestBodyAdvice` 为请求体处理的基类接口，继承 Spring `RequestBodyAdvice`，
提供默认空实现（不做任何处理、原样透传）。

默认方法：

- `supports(...)`：默认返回 true（所有请求体都支持）
- `beforeBodyRead(...)`：默认原样返回 inputMessage
- `afterBodyRead(...)`：默认原样返回 body
- `handleEmptyBody(...)`：默认原样返回 body

== 2. 设计要点

=== 2.1 默认空实现

- 基类默认全部透传，实现类只需覆写需要介入的节点，简化使用。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 未覆写任何方法 | 请求体原样透传，不介入 |

== 4. 适用范围

=== 4.1 适用场景

- 需要介入请求体读取/转换的 Advice 实现继承本接口。

== 5. 已知限制与取舍

- `supports` 默认 true，实现类若需按条件支持需覆写。
