== 用例设计思路与依据

=== 设计思路

- 通过 `AnnotatedElementUtils.findMergedAnnotation` 验证 `@CTransactional` 标注的类/方法
  能被 Spring 合并解析为等价的 `@Transactional` 语义（元注解映射是否生效）。
- 覆盖默认值（类级不指定属性）、自定义值（类级显式指定属性）、方法级自定义三个维度，
  分别验证 propagation / isolation / readOnly / rollbackFor 是否正确透传。
- 补充验证注解的 `@Retention(RUNTIME)` 与元注解 `@Transactional` 标注，确保运行时可用。

=== 设计依据

- 依据功能设计对四个属性经 `@AliasFor` 映射到 Spring `@Transactional` 的约定。
- 依据功能设计对默认值（REQUIRED / DEFAULT / false / Exception）的约定。
- 依据白盒原则：注解为纯声明，核心风险点是元注解映射是否生效、默认值与自定义值透传，
  以及运行时保留。

=== 覆盖场景与未覆盖

- 覆盖：类级默认值、类级自定义值、方法级自定义值、运行时保留、元注解标注。
- 未覆盖：Spring 容器实际事务拦截行为（需集成环境，本用例仅验证注解元数据层语义）；
  `noRollbackFor`/`timeout` 等未透传属性（本类不提供）。

== 1. 元注解映射解析

- 1.1 类级默认值：`@CTransactional` 解析为 `@Transactional`，默认 REQUIRED/DEFAULT/false/Exception（metaAnnotationResolved_defaultValues）
- 1.2 类级自定义值：REQUIRES_NEW/READ_COMMITTED/true/IllegalStateException（metaAnnotationResolved_customValues）
- 1.3 方法级自定义值：MANDATORY/REPEATABLE_READ/true/IllegalArgumentException（metaAnnotationResolved_methodLevel）

== 2. 注解元信息

- 2.1 运行时保留：类被 `@Transactional` 元注解标注（annotationRetainedAtRuntime）
