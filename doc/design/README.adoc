= 设计文档索引

本文件是**功能级设计文档的导航**。功能级设计文档（跨类/模块的设计：方案与取舍、兜底策略、适用范围、已知限制与波及影响）
**与源码同模块就近存放**，落在各模块的 +<模块>/doc/design/+ 下——javadoc 的 +@see "doc/design/…"+ 按**模块根相对**解析，
文档就近落在模块内才能被 IDE 与 javadoc 解析到；按功能命名、不与源文件同名，类级与方法级内容一律由源码 javadoc 承载。

全项目文档导航入口见 link:../README.adoc[doc/README.adoc]。

== 文档分层

* *javadoc 即文档，且按层次分工*：源类**类上**写定位、能力目录与设计文档链接；**方法/字段上**写该 API 的契约
  （参数语义、返回值、异常、边界与默认值、空值语义、易误用点），不写"为什么这样设计"与备选方案；类级细节不写成单独 adoc。
* *功能级内容按模块就近存放*：跨方法/跨类的设计内容（方案与取舍、兜底、适用范围、已知限制）成篇记录在
  +<模块>/doc/design/<功能>.adoc+，与代码双向互引。
* *测试文档*：测试内容（用例设计思路与依据、覆盖场景与取舍、用例编号索引）随规范落在测试类 javadoc，不再单独成篇。
* *版本与变更*：源文件版本见各源码 javadoc 的 +@version+；全项目变更记录统一在 link:../../CHANGELOG.adoc[CHANGELOG.adoc]。
