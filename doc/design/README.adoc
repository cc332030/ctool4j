= 设计文档索引

本目录（+doc/design/+）存放各模块的**功能/模块级设计文档**，按模块分子目录组织（仅保留确有功能级文档的模块）。

== 文档分层

* *javadoc 即文档，且按层次分工*：源类**类上**写总结（定位、能力目录、设计思路总述）；**方法上**写详细设计与详细步骤
  （流程步骤、参数/返回值/异常契约、边界与默认值、兜底、易误用点）。类级细节不写成单独 adoc。
* *本目录只放功能/模块级内容*：跨类/模块的设计（方案与取舍、兜底策略、适用范围、已知限制与波及影响）成篇记录在
  +doc/design/<模块>/<功能>.adoc+，按功能命名，不与源文件同名。
* *测试文档*：测试内容（用例设计思路与依据、覆盖场景与取舍、用例编号索引）已随规范迁入测试类 javadoc，
  不再单独成篇；跨类的测试组织如需记录，同样放在本目录。
* *版本与变更*：源文件版本见各源码 javadoc 的 +@version+；全项目变更记录统一在 link:../../CHANGELOG.adoc[CHANGELOG.adoc]。
