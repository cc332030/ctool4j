= 设计文档索引

本目录（+doc/design/+）存放各模块的**功能/模块级设计文档**（跨类/模块的设计：方案与取舍、兜底策略、适用范围、已知限制与波及影响），
按模块分子目录组织，按功能命名、不与源文件同名；类级与方法级内容一律由源码 javadoc 承载。

全项目文档导航入口见 link:../README.adoc[doc/README.adoc]。

== 文档分层

* *javadoc 即文档，且按层次分工*：源类**类上**写定位、能力目录与设计文档链接；**方法/字段上**写该 API 的契约
  （参数语义、返回值、异常、边界与默认值、空值语义、易误用点），不写"为什么这样设计"与备选方案；类级细节不写成单独 adoc。
* *本目录只放功能/模块级内容*：跨方法/跨类的设计内容（方案与取舍、兜底、适用范围、已知限制）成篇记录在 +doc/design/<模块>/<功能>.adoc+，与代码双向互引。
* *测试文档*：测试内容（用例设计思路与依据、覆盖场景与取舍、用例编号索引）已随规范迁入测试类 javadoc，
  不再单独成篇；跨类的测试组织如需记录，同样放在本目录。
* *版本与变更*：源文件版本见各源码 javadoc 的 +@version+；全项目变更记录统一在 link:../../CHANGELOG.adoc[CHANGELOG.adoc]（按发布 tag 分组、版本内按模块与变更类型分类）。
