LastModified: 2026-08-31
模块：ctool4j-logback
类：com.c332030.ctool4j.logback.mdc.CMdcLogback
状态：已落地
适用范围：logback 后端的 MDC 适配器（继承 CMdc，实现 slf4j MDCAdapter）

== 1. 功能说明

`CMdcLogback` 实现 SLF4J `MDCAdapter`，继承公共存储基类 `CMdc`，实现日志上下文在线程间传递。

- 基础读写（`put/get/remove/clear`、`containsKey/isEmpty`）：继承自 `CMdc`。
- `getCopyOfContextMap`：返回上下文副本（`LinkedHashMap`）。
- `setContextMap(Map)`：设置整个上下文，null 时清空。

== 2. 设计要点

=== 2.1 存储结构

- 存储与基础读写下沉至父类 `CMdc`（可变实例 + 不可变视图），本类只补充 slf4j 特有语义。

=== 2.2 setContextMap

- 清空可变实例后 `putAll` 拷贝传入内容（null 时仅清空）；符合 slf4j「拷贝传入 map」语义。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| setContextMap(null) | 清空上下文 |
| setContextMap(普通 Map) | 清空后 putAll 拷贝 |
| getCopyOfContextMap | 返回新 LinkedHashMap 副本，修改不影响原 MDC |

== 4. 适用范围

=== 4.1 适用场景

- 需要跨线程传递 MDC 上下文（异步任务、线程池）的 logback 日志场景。

=== 4.2 不适用/边界场景

- `ConcurrentHashMap` 不允许 null key/value，put(null, val) 等会抛 NPE。
- 与 log4j2 版 `CMdcLog4j`（`com.c332030.ctool4j.log4j.mdc`）互斥使用。

== 5. 已知限制与取舍

- 基于 TransmittableThreadLocal，需配合 TTL 依赖与跨线程包装使用。
- 依赖 `ConcurrentHashMap` 的 null 限制。

测试内容见 `doc/design/log/CMdcLogbackTests.adoc`。
