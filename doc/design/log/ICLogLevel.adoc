适用范围：日志级别抽象接口

== 1. 功能说明

`ICLogLevel` 定义日志级别提供能力：

- `Level getLevel()`：返回日志级别（SLF4J `org.slf4j.event.Level`）。

== 2. 设计要点

=== 2.1 接口语义

- 作为日志级别的公共父接口，由实现方/子接口提供具体级别。
- 各子接口（`ICLogLevelTrace`/`ICLogLevelDebug`/`ICLogLevelInfo`/`ICLogLevelWarn`/`ICLogLevelError`）以 default 方法固定返回对应级别。

== 3. 兜底设计

无（接口方法由实现决定）。

== 4. 适用范围

=== 4.1 适用场景

- 声明某组件/类的日志级别，供日志配置、过滤等使用。

=== 4.2 不适用/边界场景

- 不直接提供级别，需子接口或实现指定。

== 5. 已知限制与取舍

- 级别枚举依赖 SLF4J `Level`，不自定义级别集合。

测试内容见 `doc/design/log/ICLogLevelTests.adoc`。
