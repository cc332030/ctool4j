== 1. 功能说明

`ICLogLevelTrace`（extends `ICLogLevel`）以 default 方法固定返回日志级别 `Level.TRACE`。

== 2. 设计要点

=== 2.1 固定级别

- 重写 `getLevel()` 默认返回 `Level.TRACE`。

== 3. 兜底设计

无（default 方法固定返回值）。

== 4. 适用范围

=== 4.1 适用场景

- 声明某组件的日志级别为 TRACE。

=== 4.2 不适用/边界场景

- 不用于动态级别调整。

== 5. 已知限制与取舍

- 级别固定，如需动态级别不应使用本接口。

测试内容见 `doc/design/log/ICLogLevelTests.adoc`。
