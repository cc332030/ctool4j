== 用例设计思路与依据

=== 设计思路

- 覆盖 updateLogLevel 的正常路径：key 合法且 level 有值时级别更新、多次更新可切换级别。
- 覆盖边界：className 为空不生效、level 为空不生效。
- 使用 Mockito mock Environment，避免依赖真实配置源。

=== 设计依据

- 依据功能设计对"类名/级别为空直接返回、仅更新 logback Logger"的约定。
- 依据白盒/黑盒原则与错误推测法：合法 key、空 className、空 level、级别切换均覆盖。

=== 覆盖场景与未覆盖

- 覆盖：正常更新、级别切换、空 className、空 level。
- 未覆盖：`onEvent` 完整流程（含 keys 过滤、空 keys 分支）、非 logback Logger 分支。

== 1. updateLogLevel 级别更新

- 1.1 key 合法且 level 有值时级别更新（updateLogLevel_normal）
- 1.2 多次更新可切换级别（updateLogLevel_switchLevel）

== 2. 边界保护

- 2.1 className 为空不生效（updateLogLevel_blankClassNameNoOp）
- 2.2 level 配置为空不生效（updateLogLevel_blankLevelNoOp）
