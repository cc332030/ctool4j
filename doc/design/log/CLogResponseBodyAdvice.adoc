适用范围：响应体写出前采集响应报文到请求日志

== 1. 功能说明

`CLogResponseBodyAdvice`（`@ControllerAdvice`）实现 `ICBaseResponseBodyAdvice<Object>`，在响应体写出前调用 `CRequestLogUtils.setRsp(body, null, response)` 采集响应体、响应状态码与响应头到请求日志上下文。

== 2. 设计要点

=== 2.1 采集时机

- `beforeBodyWrite` 在响应写出前执行，一次采集响应体 + 响应状态码 + 响应头，供输出响应报文头。

=== 2.2 开关控制

- 受 `CRequestLogUtils.isEnable()` 总开关控制。
- 采集异常捕获后记录 error 日志。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 采集过程抛异常 | 捕获并记录 error 日志，返回原 body |
| 请求日志未启用 | 跳过采集 |

== 4. 适用范围

=== 4.1 适用场景

- Web 接口响应体的统一日志采集。

=== 4.2 不适用/边界场景

- 依赖 `ICBaseResponseBodyAdvice` 的调用链（web 模块）。

== 5. 已知限制与取舍

- 仅采集，日志打印由 `CRequestLogHandlerInterceptor.afterCompletion` 统一执行。
- 采集异常静默（仅记录），响应日志可能缺失而不易察觉。

无测试类，测试相关能力由 web 模块请求日志链路覆盖。
