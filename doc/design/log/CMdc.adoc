= CMdc 设计文档

Version: 1.0
LastModified: 2026-08-21
模块：ctool4j-log
类：com.c332030.ctool4j.logback.mdc.CMdc
状态：已落地
适用范围：基于 TransmittableThreadLocal 的 MDC 适配器（可跨线程传递）

== 1. 功能说明

`CMdc` 实现 SLF4J `MDCAdapter`，用 `TransmittableThreadLocal` 存放 MDC 上下文，实现日志上下文在线程间传递。

- `put/get/remove/clear`：操作当前线程上下文。
- `getCopyOfContextMap`：返回上下文副本（`LinkedHashMap`）。
- `setContextMap(Map)`：设置整个上下文，null 时清空。

== 2. 设计要点

=== 2.1 存储结构

- `TransmittableThreadLocal.withInitial(ConcurrentHashMap::new)` 存键值。
- 用 TransmittableThreadLocal 支持跨线程（如线程池、异步任务）上下文传递。

=== 2.2 setContextMap

- `ConcurrentMap` 直接设置；普通 `Map` 用 `Collections.synchronizedMap` 包装；null 时清空。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| setContextMap(null) | 清空上下文 |
| setContextMap(普通 Map) | synchronizedMap 包装后设置 |
| getCopyOfContextMap | 返回新 LinkedHashMap 副本，修改不影响原 MDC |

== 4. 适用范围

=== 4.1 适用场景

- 需要跨线程传递 MDC 上下文（异步任务、线程池）的日志场景。

=== 4.2 不适用/边界场景

- `ConcurrentHashMap` 不允许 null key/value，put(null, val) 等会抛 NPE。

== 5. 已知限制与取舍

- 基于 TransmittableThreadLocal，需配合 TTL 依赖与跨线程包装使用。
- 依赖 `ConcurrentHashMap` 的 null 限制。

测试内容见 `doc/design/log/CMdcTests.adoc`。
