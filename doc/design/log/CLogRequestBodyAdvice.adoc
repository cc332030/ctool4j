适用范围：请求体读取后采集到请求日志

== 1. 功能说明

`CLogRequestBodyAdvice`（`@ControllerAdvice`）实现 `ICBaseRequestBodyAdvice`，在请求体读取后调用 `CRequestLogUtils.setRequestBodyReq(body)` 采集请求体到请求日志上下文。

== 2. 设计要点

=== 2.1 采集时机

- `afterBodyRead` 在请求体反序列化完成后执行，将 body 存入请求日志上下文。

=== 2.2 开关控制

- 受 `CRequestLogUtils.isEnable()` 总开关控制。
- 采集异常捕获后记录 error 日志，不影响主流程。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 采集过程抛异常 | 捕获并记录 error 日志，返回原 body |
| 请求日志未启用 | 跳过采集 |

== 4. 适用范围

=== 4.1 适用场景

- Web 接口请求体的统一日志采集。

=== 4.2 不适用/边界场景

- 依赖 `ICBaseRequestBodyAdvice` 的调用链（web 模块）。

== 5. 已知限制与取舍

- 采集异常静默（仅记录），请求日志可能缺失请求体而不易察觉。
- 依赖请求日志总开关。

无测试类，测试相关能力由 web 模块请求日志链路覆盖。
