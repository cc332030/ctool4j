== 1. 功能说明

`CFeignLocalClientConfig`（`@Data` + `@ConfigurationProperties("feign.client.local-instance")`）承载本地客户端实例注册配置：

- `urls`：`Map<String, String>`，服务名 → ip:port 映射，默认空 Map。
- 通过 `@ConditionalOnProperty`（`feign.client.local-instance.enabled=true`）启用。

== 2. 设计要点

=== 2.1 urls

- 键为服务名，值为 `ip:port` 字符串。
- 默认 `Collections.emptyMap()`。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| urls 未配置 | 默认空 Map |

== 4. 适用范围

=== 4.1 适用场景

- 将本地 Feign 客户端实例注册到 Nacos 的配置来源。

== 5. 已知限制与取舍

- 依赖 `@ConditionalOnProperty` 启用，未启用时配置不生效。
