适用范围：本地客户端实例注册/注销到 Nacos

== 1. 功能说明

`CFeignLocalClientInit`（`@Component` + `@ConditionalOnProperty`）实现 `ICSpringInit`、`AutoCloseable`，将本地客户端实例注册到 Nacos：

- 构造时基于 Nacos 发现配置创建 `NamingService`。
- `onInit`：Spring 启动时将配置的本地实例注册到 Nacos。
- `close`（`@PreDestroy`）：取消注册并关闭命名服务，防重入。

== 2. 设计要点

=== 2.1 注册/注销

- `doForClient(operateName, consumer)` 遍历 `clientConfig.getUrls()`（服务名→ip:port）。
- 以最后一个冒号拆分 host:port（兼容 IPv6 多冒号）；缺端口或格式错误抛异常由外层 catch 记录。
- 注册成功的实例过滤 null 后收集，记录成功日志。

=== 2.2 生命周期

- 构造时 `NamingFactory.createNamingService(nacosProperties)`。
- Spring 不会调用 `AutoCloseable.close`，须经 `@PreDestroy` 在容器销毁时触发。
- `close` 防重入：`closed` volatile 标记，重复触发直接返回。

== 3. 兜底设计

| 场景 | 兜底行为 |
|------|---------|
| 单个实例注册/注销失败 | 捕获记录 error 日志，返回 null 被过滤 |
| ip:port 格式错误/缺端口 | 抛 IllegalArgumentException，外层 catch 记录 |
| close 重复触发 | `closed` 防重入直接返回 |

== 4. 适用范围

=== 4.1 适用场景

- 本地开发/联调时将本地 Feign 客户端注册到 Nacos。

== 5. 已知限制与取舍

- 依赖 Nacos、Feign 客户端相关组件。
- 注册失败不阻断其他实例（过滤后继续）。
