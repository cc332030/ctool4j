= 使用：ctool4j-core（核心工具库）

坐标：+com.c332030:ctool4j-core+　｜　依赖：无 Spring（任意 Java 项目可用）　｜　与其可用的上层构件：全部

== 一览

[cols="2,4", options="header"]
|===
| 包 | 工具类

| +core.classes+
| `CBeanUtils`（对象/Map 属性拷贝，**集合与嵌套对象为深拷贝**）、`CClassUtils`、`CReflectUtils`、`CMethodHandleUtils`、`CLambdaUtils`、`CObjUtils`、`CConvertUtils`、`CClassConvert`/`CClassConverter`、`CElKeyResolveUtils`
| +core.util+
| `CStrUtils`、`CCollUtils`、`CMapUtils`、`CList`、`CSet`、`CList`/`CMap`/`CSet` 的视图 `CListView`/`CMapView`/`CSetView`、`CCollectors`、`CStreamUtils`、`CDateUtils`、`CNumUtils`、`CAmountUtils`、`CBase62Utils`、`CBase64Utils`、`CJsonUtils`、`CEnumUtils`、`CComparatorUtils`、`COpt`、`CUrlUtils`、`CDesUtils`、`CIdUtils`、`CResultUtils`、`CPageUtils`、`CThreadLocalUtils`、`CThreadUtils`、`CSpiUtils`、`CHttpClientUtils`、`CResUtils`、`CPatternUtils`、`CMediaTypeUtils`、`CLocalCacheUtils`、`CTestUtils`（测试环境判断）
| +core.exception+
| `CException`（受检异常基类）、`CBusinessException`（业务异常）、`CUnauthorizedException`（未认证语义，由 +ctool4j-web+ 转为响应体业务码 401）、`CExceptionUtils`、异常提供者 SPI
| +core.log+
| `CLog`（JSON 结构化日志门面）、`CLogUtils`
| +core.validation+
| `CValidUtils`（有效性判断）、`CAssert`（断言）、`CValidateUtils`（**已废弃**）
| +core.jackson+
| `CJacksonUtils`（ObjectMapper 封装）、日期/`Instant` 序列化器、`@CLogBlob` 的日志序列化器 `CLogBlobSerializer` 与脱敏序列化器
| +core.cache+
| Class 值缓存工具（强/弱引用实现 `CClassValue`、`CRefBiClassValue` 等）
| +core.config+ / +core.enums+ / +core.interfaces+
| 分页配置 `CPageConfig`（`@ConfigurationProperties("page")`，属性 `page.defaultPageSize` 默认 100，relaxed binding 下写 `default-page-size` 亦可）、通用枚举、语义接口
| +core.benchmark+
| 基准测试与报告模型（`CBenchmarkRunner` / `CBenchmarkReport` / `CBenchmarkResult`）
|===

包名均为 +com.c332030.ctool4j.+ 前缀（下表同）。

== 用法

=== 集合 / Map / Optional（推荐写法）

[source,java]
----
// 创建
CList.of();                      // 空集合（不可变）
CList.of("a", "b");              // 变参（自动过滤 null）
CCollUtils.newList(16);          // 指定大小

// 过滤 / 转换 / 分组 / 转 Map
List<String> names = CCollUtils.convert(users, User::getUserName);  // map + 过滤 null 结果（User 为共享测试模型，见 test.adoc）
List<String> valid = CCollUtils.filterString(names);                // 过滤 null / 空 / 空白字符串
Map<Integer, User> byAge = CCollUtils.toMap(users, User::getAge);   // key 冲突且无 merge 时抛 IllegalStateException
Map<String, List<User>> g = CCollUtils.groupingBy(users, User::getUserName);

Map<String, User> byName = CCollUtils.toMap(users, User::getUserName);
Map<String, User> renamed = CMapUtils.mapKey(byName, key -> "u:" + key);
Map<String, User> onlyOn = CMapUtils.filterValue(byName, u -> u.getAge() != null && u.getAge() >= 18);

COpt.ofNullable(user).map(User::getUserName).orElse("默认");    // 空安全链式
----

=== 对象属性拷贝（CBeanUtils）

[source,java]
----
User copy = CBeanUtils.copy(source, User.class);       // 按目标类型新建
CBeanUtils.copy(source, target);                       // 复制到已有实例
CBeanUtils.copy(map, User.class);                      // Map -> 对象
Map<String, Object> map = CBeanUtils.toMap(user);       // 对象 -> Map
List<User> list = CBeanUtils.copyList(sourceList, User.class);
----

* **深拷贝**：集合 / Map / 数组 / 嵌套 Bean / Date 字段一律**深拷贝**（元素与键值递归、环状与跨字段共享引用只拷一份、递归深度上限 64）。
  需要与原对象共享引用时改用 `toMap`，或在复制后自行恢复引用。
* **跨接口容器**（源 `List`、目标字段声明为 `Set` 等）：按"跳过不写入"处理，该字段不赋值（**不报错**，排查字段静默缺失时先看这里）。
* 源为 `null`、字段不存在、目标 `final`/`static`、无可用转换器时**静默跳过**，单个字段失败只记 debug 日志、不影响其余字段。

=== 字符串 / 日期 / 数值

[source,java]
----
CStrUtils.defaultString(name, "默认值");   // 依次取第一个非空字符串（空串/ null 跳过，空白串不跳过）
CStrUtils.notBlackThenGet(name, () -> "默认值"); // 空白兜底（返回 Supplier 计算值）
CDateUtils.format(instant, "yyyy-MM-dd");    // 入参是 Instant，不是 Date
CNumUtils.toInt(1L);                         // 重载只有 toInt(long) / toInt(Long)
----

=== JSON

[source,java]
----
String json = CJsonUtils.toJson(user);            // Long 序列化为字符串，防前端精度丢失
User user = CJsonUtils.fromJson(json, User.class); // 解析失败/入参空白时返回 null
----

=== 异常

[source,java]
----
throw new CBusinessException("用户不存在");   // 由 web 的处理器统一转 JSON（见 web.adoc）
CExceptionUtils.throwBusinessException("业务异常");        // 直接抛业务异常
Throwable wrap = CExceptionUtils.newBusinessException("业务异常");  // 只要异常实例、不抛出
String chain = CExceptionUtils.getMessageWithCause(e);   // 拼接整条异常链信息
CExceptionUtils.ignore(() -> doSomething());             // 忽略回调内异常、不中断流程
----

=== 有效性判断与断言

[source,java]
----
CValidUtils.isValid(str);     // 字符串按 blank、集合/Map/数组按 empty、其他按 null
CValidUtils.isNotValid(list);
CAssert.notNull(obj, "对象不能为空");
CAssert.valid(list, "集合不能为空");
----

* `CValidateUtils` **已废弃**，改用 `CValidUtils`。
* 传 `null` 字面量会因多重载歧义编译失败：传具体类型变量。

=== 日志

[source,java]
----
CLog log = CLogUtils.getLog(getClass());        // CLog 是实例门面，无静态打印方法
log.info("用户操作 {}", CList.of("userId=" + 1L, "action=login"));   // 参数为可 JSON 化对象时自动转 JSON
----

== 语法糖（客户端项目写业务代码时的约定写法）

使用本库的项目，业务代码里上述重复写法统一改用下面对应工具（**客户端项目的代码约定，由引用方自行采纳**）：

[cols="3,3", options="header"]
|===
| 不写 | 改为

| `stream().filter(..).collect(..)` | `CCollUtils.filter(coll, predicate)`
| `stream().map(f).filter(p).collect(toList())` | `CCollUtils.convert(coll, f)`
| `stream().collect(toMap(..))` | `CCollUtils.toMap(coll, toKey[, toValue][, mergeFn])`
| `Collectors.groupingBy(..)` | `CCollUtils.groupingBy(coll, keyFn)`
| `entrySet().stream().collect(..)` | `CMapUtils.mapKey / mapValue / map`
| `x == null`、`StringUtils.isBlank`、`CollUtil.isEmpty` | `CValidUtils.isValid / isNotValid`
| `field.get/set`、`method.invoke`、`constructor.newInstance` | `CMethodHandleUtils` 的 getter/setter/方法/构造器方法句柄
| `List.of` / `Map.of` | `CList.of` / `CMap.of`（本库目标 Java 8）
|===
